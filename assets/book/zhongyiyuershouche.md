## 第一部分 中医对小儿的基本认识——知其所以然

> 养儿不知理，出手必出错。这一部分是整本手册的根基——不讲清小儿为什么容易生病、为什么脾最重要、为什么不能乱补，后面所有操作都是"知其然不知其所以然"。

### 一、小儿生理特点——"稚阴稚阳"与"纯阳之体"

中医儿科有两句话看似矛盾，实则互补，必须同时理解：

| 特点 | 经典依据 | 含义 | 临床意义 |
|------|----------|------|----------|
| **稚阴稚阳** | 清·吴鞠通《温病条辨》："小儿稚阳未充，稚阴未长" | 阴（精血津液）和阳（功能活力）都还不成熟——是"嫩芽"，不是"小树" | 用药量宜轻、不可猛攻猛补；对药物和食物的耐受性都比成人低 |
| **纯阳之体** | 唐·《颅囟经》："小儿纯阳" | 生长发育蓬勃、生机旺盛——像春天的嫩芽，长得快、恢复也快 | 病虽来势急，但只要方向对，转归也好——不必过度焦虑 |

> 📝 **两句话的关系**：稚阴稚阳="底子薄"（容易伤）；纯阳之体="恢复快"（容易好）。底子薄所以防护要到位，恢复快所以不必过度治疗——给身体自愈的机会。

#### 万全五脏特点——0-3岁养育的总纲

明代儿科大家万全在《幼科发挥》中提出小儿五脏特点："肝常有余，脾常不足，肺常娇嫩，肾常虚"，又云"心常有余"。其中与0-3岁养育最直接相关的有四条：

| 特点 | 含义 | 0-3岁具体表现 | 养护要点 |
|------|------|---------------|----------|
| **脾常不足** | 脾胃运化功能弱，最易受伤 | 吃多就积食、吃杂就腹泻、食欲时好时差 | **0-3岁核心问题——十儿九脾虚，喂养是头等大事**。宁可少吃一口，不可多喂一口 |
| **肺常娇嫩** | 肺主皮毛、司呼吸，外邪最易犯 | 感冒、咳嗽是0-3岁第一高频病；一受凉就鼻塞流涕 | 注意保暖但不过度（见第四章穿衣原则）；反复感冒从脾论治（培土生金） |
| **肝常有余** | 小儿肝气偏旺，易化火动风 | 易惊易怒、高热时易惊厥 | 高热及时退热（见第九部分）；肝旺与脾虚互为因果——脾虚则肝旺→健脾则肝自平 |
| **肾常虚** | 肾主骨生髓，发育中肾气未充 | 囟门迟闭、出牙晚、走路晚均与肾虚有关 | 但**0-3岁不可补肾**——补肾药多温燥→小儿纯阳→助火；应通过健脾间接养肾（后天养先天） |

> ⚠️ **0-3岁不可补肾**——这是临床常见误区。家长看孩子出牙晚、走路晚就给补肾（六味地黄丸、杜仲等）→小儿纯阳之体→补肾→化火→流鼻血、烦躁、甚至早熟。正确思路：脾为后天之本→健脾→气血足→肾气自然充→"后天养先天"。

### 二、小儿病理特点——为什么小孩老生病

| 特点 | 含义 | 家长须知的要点 |
|------|------|---------------|
| **发病容易、传变迅速** | 正气未充→邪气易入；病后变化快 | 小儿上午还好好的→下午高烧→不要等"看看再说"，变化可能按小时计 |
| **脾为先受** | 脾常不足→饮食稍有不慎即病 | 积食→发热→咳嗽→一条线，根源在脾（详见第三部分"积食链"） |
| **肺最易伤** | 肺主皮毛→外邪从皮毛入→肺先受 | 感冒是0-3岁最常见病，一年4-6次属正常频率 |
| **易虚易实、易寒易热** | 病性转换快，不可固守一方 | 今天风寒明天可能化热→须随证调整→这就是为什么不能自行长期给药 |
| **脏气清灵、易趋康复** | 小儿生机旺盛→只要方向对→恢复快 | 不必过度用药——给身体自愈的机会；过度治疗反而伤正气 |

```
小儿生病的常见链条：

  外感链：受凉 → 风寒感冒 → 化热 → 咳嗽 → 痰湿 → 迁延不愈
  积食链：吃多了/吃杂了 → 食积 → 郁热 → 发热 → 咳嗽 → 厌食
  脾虚链：反复积食 → 脾气更虚 → 运化更弱 → 更容易积食 → 恶性循环

  三条链的交汇点 = 脾
  → 守住脾胃 = 截断大多数疾病链条的起点
```

### 三、小儿望诊——家长能观察什么

中医诊断讲究"望闻问切"，对小儿而言望诊最重要——小儿不会说，但面色、大便、睡眠都在"说话"。

#### 面色——最直观的"仪表盘"

| 面色 | 提示 | 常见原因 |
|------|------|----------|
| 红润有光泽（白里透红） | 正常、气血充和 | — |
| 面色萎黄（黄而暗淡无光） | 脾虚 | 喂养不当、反复积食、厌食 |
| 面色白（苍白无华） | 气血不足 | 营养不良、反复失血（如反复鼻衄） |
| 面红目赤 | 热证 | 发热、积食化热、外感风热 |
| 面色青 | 寒证/痛证/惊风 | 腹痛剧烈、高热惊厥先兆 |
| 两颧红（午后颧红） | 阴虚内热 | 久病伤阴、长期盗汗 |

> 📝 **注意**：婴儿哭闹时面色暂时发红是正常的，待安静后再观察。运动后、哭闹后的面色不能作为判断依据。

**面色黄的三种鉴别——家长最易混淆**：

| 类型 | 面色特征 | 关键鉴别点 | 处理 |
|------|----------|-----------|------|
| **正常黄（中国人肤色）** | 黄中带红润→有光泽→通透感 | 眼白不黄→手心脚心不黄→精神好食纳佳 | 无需处理→正常肤色 |
| **萎黄（脾虚）** | 黄而暗淡无光→像蒙了一层灰→干枯感 | 精神偏软→食纳差→大便或溏→舌淡苔白 | 健脾调护→捏脊+规律饮食→就医辨证 |
| **胡萝卜素血症（食源性黄）** | 皮肤黄但**眼白不黄**→手心脚心明显黄 | 近期大量吃南瓜/胡萝卜/橙子/红薯→精神好食纳佳 | 停食高胡萝卜素食物2-3周→自行消退→无害 |
| **黄疸（病理性）** | 皮肤黄+**眼白也黄**→全身性 | 新生儿期最常见→成人出现=肝胆问题 | **就医**→新生儿生理性黄疸2周内消退→不退=就医 |

> ⚠️ **最关键的一步**：看眼白。眼白黄=黄疸（就医）；眼白不黄+精神好+最近吃了很多南瓜胡萝卜=胡萝卜素血症（停食即可）；眼白不黄+精神差+食纳差=萎黄（健脾调护）。

#### 舌象——脾胃的"镜子"

| 舌象 | 提示 | 注意 |
|------|------|------|
| 淡红舌、薄白苔 | 正常 | — |
| 舌淡、苔白 | 虚寒（脾虚/阳虚） | — |
| 舌红、苔黄 | 热证 | — |
| 舌苔厚腻（白腻/黄腻） | 积食/湿浊 | **积食最可靠的舌象** |
| 舌苔剥落（花剥苔/地图舌） | 胃阴不足 / 脾虚 | 反复积食伤胃阴→多见 |
| 舌尖红 | 心火 | 烦躁、夜啼 |

> ⚠️ 婴儿不配合看舌很常见，**不强求**。奶后舌苔会被奶覆盖→假象→应在喂奶前或喂奶后2小时观察。食物染色（如吃胡萝卜后舌苔黄）须排除。

#### 指纹——3岁以下的特殊诊法

指纹指食指桡侧浅表络脉，分风、气、命三关：

```
食指掌面桡侧
  ┌────────┐
  │ 命关   │  ← 第二指间关节到指根（近掌端）
  │        │
  │ 气关   │  ← 第一指间关节到第二指间关节
  │        │
  │ 风关   │  ← 指尖到第一指间关节（远端）
  └────────┘
```

| 指纹表现 | 提示 |
|----------|------|
| 淡紫隐隐，不超过风关 | 正常 |
| 鲜红 | 外感表证 |
| 紫红 | 里热 |
| 青色 | 惊风 / 痛证 |
| 黑色 | 血瘀（重证） |
| 达气关 | 邪气深入 |
| 达命关 | 病情危重（"透关射甲"=指甲处可见→极危） |

> 📝 **指纹诊法为医者所用**，家长了解即可，**不自行判断**。观察指纹须在光线充足处，医生用手指从命关向风关轻推，使络脉显现。

#### 大便——脾胃的"晴雨表"

| 大便表现 | 提示 | 详见附录四 |
|----------|------|-----------|
| 母乳喂养：金黄糊状、微酸味 | 正常 | ✅ |
| 奶粉喂养：淡黄成形 | 正常 | ✅ |
| 绿色稀便 | 受凉 / 铁剂未吸收 | 需关注 |
| 白色陶土样 | 胆道阻塞 | ⚠️ **紧急就医** |
| 带血丝 | 过敏 / 肠套叠 / 肛裂 | ⚠️ **就医** |
| 酸臭+奶瓣 | 伤食（消化不良） | 需关注 |
| 泡沫+肠鸣 | 风寒泻 / 乳糖不耐受 | 需关注 |
| 羊屎状干硬 | 肠燥便秘 | 需关注 |

#### 睡眠——脾胃和心神的信号

| 睡眠表现 | 提示 |
|----------|------|
| 安稳、呼吸均匀 | 正常 |
| 趴着睡 | **积食常见体位**——腹部不适→趴着压迫缓解 |
| 翻来覆去、辗转不安 | 积食 / 胃不和则卧不安 |
| 磨牙 | 积食 / 虫积（城市儿童虫积少见） |
| 突然惊醒哭闹 | 夜啼 / 惊恐 |
| 入睡后头颈多汗 | 气虚不固 / 佝偻病可能 |

#### 精神状态——比体温更重要的指标

> ⚠️ **这是家长必须记住的一条铁律：精神状态比体温更重要。**

| 精神状态 | 判断 | 处理 |
|----------|------|------|
| 活泼好动、眼神灵活、对周围有好奇 | 即使发热也不太严重 | 观察+对症处理 |
| 精神萎靡、嗜睡、叫不醒、眼神呆滞 | **重证信号——不管体温多少** | **立即就医** |
| 烦躁哭闹、难以安抚 | 实证 / 疼痛 | 观察伴随症状→必要时就医 |
| 安静但面色苍白 | 可能为低血糖 / 休克先兆 | **就医** |

## 第二部分 0-6月——以母乳为中心

> 0-6月婴儿脾胃极弱（"脾常不足"在此阶段最为突出），母乳是唯一的最佳选择——不是"之一"，是"唯一最佳"。

### 一、母乳——小儿最好的"药"

#### 母乳的中医认识

| 认识 | 经典依据 | 含义 |
|------|----------|------|
| **乳为血化** | 《灵枢·决气》："中焦受气取汁，变化而赤，是谓血"；《诸病源候论》："乳者，血之所化" | 母乳=母血所化→母体气血足→奶质好；母体虚→奶质差→婴儿亦虚 |
| **乳性平和** | 孙思邈《千金要方》："母乳性平，最宜小儿" | 母乳不寒不热、不燥不腻→最合婴儿脾胃→不需要脾胃额外"运化" |
| **乳含母气** | 临床实际观察 | 母亲情绪→影响乳汁成分→焦虑→乳汁中皮质醇↑→婴儿烦躁 |

> 📝 **母乳是"活的"**——初乳含免疫球蛋白（sIgA）=婴儿的第一剂"天然疫苗"；母乳中白细胞、溶菌酶、乳铁蛋白持续提供免疫保护；母乳成分随婴儿月龄自动调整→这是任何配方奶做不到的。

#### 母乳喂养时间线

| 月龄 | 喂养要点 | 中医道理 | 常见误区 |
|------|----------|----------|----------|
| 0-1月 | **按需哺乳**、早开奶（产后30分钟内）；每日8-12次 | 初乳=浊液→助排胎便；频繁吸吮→刺激冲脉→乳汁分泌 | ❌ "初乳脏不能喝"——初乳最珍贵 |
| 1-3月 | 按需→逐步有节奏（约2-3小时一次）；夜间也需哺乳 | 脾胃渐醒→不必太密→给消化间隙 | ❌ "定时3小时喂"——1月内不必强求定时 |
| 4-6月 | 仍以母乳为主；不急着加辅食 | 《诸病源候论》："儿初生，不可早食谷"→脾胃未全→谷食难消→反伤脾胃 | ❌ "4个月就该加辅食"——6月添加更安全（WHO建议） |

#### 正确衔乳——母乳喂养的第一步

> ⚠️ 衔乳不对=乳头疼痛+婴儿吃不够+奶量上不来→这是很多母乳问题的根源。学会正确衔乳，后面的问题少一半。

**正确衔乳的4个标志**：

| 标志 | 说明 | 不对的信号 |
|------|------|-----------|
| 嘴巴张大 | 婴儿嘴张到最大→像打哈欠→含入乳头+大部分乳晕 | 只含乳头→嘴巴半闭→"嘬"乳头 |
| 嘴唇外翻 | 上下嘴唇向外翻→像鱼嘴 | 嘴唇内卷→向内包→摩擦乳头→痛 |
| 下巴贴乳房 | 下巴紧贴乳房→鼻尖可能轻触乳房但不妨碍呼吸 | 下巴与乳房有间隙→衔乳浅 |
| 吸吮节奏 | 慢而深→吸→停→吞→有节奏→每吸1-2次可见吞咽 | 快而浅→只嘬不吞→"吧嗒吧嗒"声→只含乳头 |

**衔乳操作步骤**：

```
1. 先让婴儿鼻尖对着乳头→不是嘴对着乳头→婴儿需要仰头才能含住
2. 等婴儿嘴巴张到最大（像打哈欠时）→迅速将婴儿拉近乳房
3. 婴儿下巴先触乳房→下唇先包住下方乳晕→然后上唇包住上方乳晕
4. 含入的乳晕→下方比上方多→因为舌头在下方的乳晕上挤压出奶
5. 如果含得不对→用小指伸入婴儿嘴角→解除负压→取出→重来→不硬拽→疼

喂完后的乳头形状判断：
  圆形=衔乳正确
  被压扁/尖形/歪斜=衔乳不对→下次调整
```

**衔乳不对的纠正**：

| 问题 | 表现 | 纠正 |
|------|------|------|
| 只含乳头 | 嘴半闭+吸吮快+无吞咽声+乳头疼痛 | 退出重来→等张大嘴→含入更多乳晕 |
| 嘴唇内卷 | 乳头摩擦痛+婴儿吸不饱 | 轻轻拨出嘴唇→外翻→继续喂 |
| 舌头顶乳头 | 婴儿舌头顶住乳头→吸不到奶→乳头被推来推去 | 退出→重新衔乳→确保舌头在乳头下方 |

**判断宝宝吃饱的即时信号**（不用等体重秤）：

| 信号 | 吃饱了 | 没吃饱 |
|------|--------|--------|
| 吃多久 | 单侧10-15分钟后自动松开 | 5分钟内松开→可能没吸到 |
| 吸吮节奏 | 从快变慢→停顿增多→自己松开 | 一直快而浅→不松口→焦躁 |
| 吃完表现 | 手松开→身体放松→表情满足/"醉奶"状→安静或入睡 | 嘴还在找→手握拳→烦躁→哭 |
| 尿布 | 每日≥6片湿尿布→尿色淡黄 | <5片→尿色深黄→吃不够 |
| 大便 | 每日≥2次黄色糊便 | 绿便/量少→可能不够 |

> 📝 **猛长期（cluster feeding）**：3周/6周/3月/6月左右→婴儿突然频繁要吃→每30-60分钟就要→持续2-3天→这是正常生长冲刺→不是奶不够→按需喂→奶量会跟上→不要因此加配方奶。

**喂奶间隔怎么算**：

| 说明 | 内容 |
|------|------|
| 间隔起点 | 从**上顿开始吃的时间**算→不是从吃完算→"2-3小时一次"=开始喂到下次开始喂的间隔 |
| 0-1月 | 按需→不等时间→饿了就喂→每日8-12次 |
| 1-3月 | 约2-3小时（从开始到开始）→夜间可延长至3-4小时 |
| 3-6月 | 约3小时→夜间逐步延长 |

#### 母亲哺乳期常见问题——妈妈也需要被照顾

> 手册一直在讲怎么照顾宝宝，但妈妈的身体也在经历巨大变化。妈妈不好→宝宝也不好。

**乳头皲裂——母乳喂养第一周最常见的痛**：

| 项目 | 内容 |
|------|------|
| 原因 | 衔乳不对→乳头被婴儿牙龈摩擦→破皮→裂口→出血→疼痛 |
| 预防 | 正确衔乳（见上方）→每次喂奶确保含住大部分乳晕→不只含乳头 |
| 轻度皲裂（无出血） | 喂完后挤一滴母乳涂在乳头上→自然风干→母乳含抗体+油脂→天然修复；换侧喂→先喂不痛的一侧→痛的一侧后喂→婴儿吸吮力减弱→痛感减轻 |
| 中度皲裂（有裂口出血） | 羊脂膏（Lanolin）→纯天然→不须擦掉→喂奶前不洗掉→安全→涂厚层；硅胶乳头护罩→暂时减轻疼痛→但不长期用→影响奶量 |
| 重度皲裂（持续出血/剧痛） | 暂停患侧直接哺乳→用吸奶器吸出→瓶喂→乳头休息1-2天→同时纠正衔乳→愈合后恢复 |
| ⚠️ 不该做的 | ❌ 肥皂/酒精擦乳头→洗掉天然油脂→更干更裂；❌ 忍痛继续错误衔乳→越裂越深 |

**涨奶/堵奶/乳腺炎——三层递进**：

| 阶段 | 表现 | 处理 | ⚠️ |
|------|------|------|-----|
| 涨奶 | 乳房胀满→硬→有胀痛→但无局部红热 | 频繁喂奶→让婴儿吸→吸空→冷敷缓解肿胀→不热敷；如婴儿吸不空→手挤/吸奶器排出一部分→排到不胀即可→不排空→排空=刺激更多产奶 | 涨奶≠奶多→有时是出奶不畅→关键是让婴儿正确吸吮→不是猛喝下奶汤 |
| 堵奶 | 乳房局部出现硬块→压痛→皮肤可能微红→无发热 | 热敷硬块处→5分钟→轻柔从硬块向乳头方向按摩→让婴儿下巴对准硬块方向吸吮→下巴的吸力最强→帮助疏通；频繁喂+按摩→多数24-48小时内疏通 | ❌ 不暴力揉搓→揉破→乳腺炎；如果堵了>48小时不缓解→就医 |
| 乳腺炎 | 硬块+局部红热+体温>38.3°C+全身酸痛乏力→像感冒 | **就医**→医生开具抗生素→多数哺乳期可用→不须停奶→继续哺乳→患侧也要喂→帮助引流→热敷+按摩+让婴儿吸 | ❌ 不停止哺乳→停→淤积更重→化脓→须切开引流 |

**乳汁不足的判断与追奶**：

| 项目 | 内容 |
|------|------|
| 真不足的判断 | 每日<5片湿尿布+体重连续2周不增长+大便少+婴儿烦躁→可能是真不足 |
| "假不足" | 婴儿哭≠饿→频繁要吃≠不够→猛长期≠不够→多数"奶不够"是误判 |
| 追奶方法 | ①频繁喂→每日≥10次→刺激→产奶→越吸越多 ②皮肤接触→婴儿趴在妈妈胸口→肌肤相亲→促催产素分泌→奶阵来得快 ③充分排空→每次喂完用手挤/吸奶器排空→告诉身体"还需要更多"→产量↑ ④充分休息+营养+饮水→奶=血化→气血足→奶量足→不熬夜→多喝温水/汤水 ⑤不急于加配方奶→加了→婴儿吸母乳少→刺激少→奶更少→恶性循环 |
| 中医追奶 | 通草6g+王不留行6g→煮猪蹄汤→每周2-3次→通草通乳+王不留行下乳+猪蹄滋阴补血→哺乳期经典；⚠️ 浓汤撇油→太油腻→堵奶 |

**乳汁过多**：

| 项目 | 内容 |
|------|------|
| 表现 | 乳房总是胀满→喷乳反射太强→婴儿呛奶→前奶后奶不均衡→绿色泡沫便 |
| 处理 | 哺乳前手挤出一点前奶→等喷射感减弱再喂→单侧喂→一次只喂一侧→另一侧不排空→只挤到不胀→不刺激过多产奶→逐步减少到供需平衡 |
| 前奶后奶 | 前奶=开始喂的5分钟→水分多+乳糖多→解渴；后奶=5分钟后→脂肪多→耐饿→必须让婴儿吃空一侧再换→否则只吃到前奶→不扛饿+绿色泡沫便 |

**哺乳期常见用药安全速查**：

| 药物 | 哺乳期能否使用 | 说明 |
|------|---------------|------|
| 对乙酰氨基酚（泰诺林） | ✅ 安全 | 首选退烧止痛药→极少量入乳汁→不影响婴儿 |
| 布洛芬 | ✅ 安全 | 第二选择→入乳汁量极少 |
| 阿莫西林/头孢类抗生素 | ✅ 多数安全 | 须医生处方→告知哺乳→选安全品种 |
| 含伪麻黄碱的感冒药 | ⚠️ 可能减少奶量 | 伪麻黄碱→抑制催乳素→奶量↓→哺乳期尽量避免 |
| 咖啡因 | ⚠️ 适量可以 | <200-300mg/天（约1-2杯咖啡）→不过量→不在睡前哺乳前饮用→咖啡因少量入乳汁→大量→婴儿烦躁不睡 |
| 茶（绿茶/红茶） | ⚠️ 适量 | 茶也含咖啡因→浓茶限量→淡茶可 |
| 酒精 | ❌ 应避免 | 酒精入乳汁→影响婴儿发育→偶尔少量（如1小杯红酒）→等2-3小时再哺乳→不等够时间→挤掉一次奶 |
| 中药 | ⚠️ 须医生指导 | 部分中药哺乳期可用→部分禁用（如大黄/番泻叶→通过乳汁→婴儿腹泻）→不自行服中药→告知医生在哺乳 |
| 避孕药（含雌激素） | ⚠️ 可能减少奶量 | 雌激素→抑制催乳素→奶量↓→哺乳期首选纯孕激素避孕药（迷你丸）→不影响奶量→产后6周起可用 |
| 伪麻黄碱 | ⚠️ 可能减少奶量 | 感冒药常见成分→抑制催乳素→奶量↓→哺乳期尽量避免含此成分的感冒药 |
| 甲硝唑 | ⚠️ 单次可用→暂停哺乳12-24h | 常用于妇科感染/口腔感染→单次2g→用药后暂停哺乳12-24小时→期间挤奶丢弃→维持奶量 |
| 华法林 | ✅ 哺乳期可用 | 抗凝药→不入乳汁→安全→但须医生监测INR |
| 放射性碘（¹³¹I） | ❌ **绝对禁用** | 治疗甲亢→通过乳汁→婴儿甲状腺受损→须完全断奶→用药前须停止哺乳 |

#### 母亲饮食如何影响乳汁

| 母亲饮食 | 对乳汁影响 | 婴儿反应 | 调整建议 |
|----------|-----------|----------|----------|
| 过食寒凉（西瓜、冰饮、苦瓜大量） | 乳汁偏凉 | 婴儿腹泻、绿便、腹中响 | 适量寒凉可，不过量；吃后观察婴儿大便 |
| 过食辛辣（辣椒、花椒过量） | 乳汁偏热 | 婴儿烦躁、湿疹加重、便秘 | 微辣可，不大量 |
| 过食肥甘（浓汤、油腻） | 乳汁脂肪含量高→黏稠 | 婴儿消化不良、腹泻带奶瓣 | 汤撇去浮油；不过浓 |
| 情绪波动（怒、悲、忧） | 乳汁中压力激素↑ | 婴儿烦躁哭闹、食乳不安 | 哺乳前调整情绪→安静环境→心情放松→乳汁分泌更好 |
| 适量温和饮食 | 乳汁平和 | 婴儿安和 | 最佳状态 |

#### 无法母乳喂养的情况

> ⚠️ 以下情况**不是母亲的问题**，不应增加母亲的心理负担。无法母乳≠不是好妈妈。

| 情况 | 说明 | 处理 |
|------|------|------|
| 母亲疾病（HIV、活动性结核、正在化疗） | 医学禁忌 | 配方奶喂养——现代配方奶虽不及母乳，但足以保障婴儿营养 |
| 母亲用药 | 部分药物可通过乳汁 | 咨询医生→多数药物哺乳期可用；少数须暂停哺乳 |
| 乳汁不足 | 多数为"以为不足"→实际够 | 判断标准：每天6片以上湿尿布+体重增长正常=够；确实不足→追奶+必要时补充配方奶 |
| 婴儿特殊疾病（半乳糖血症、枫糖尿症） | 代谢疾病须特殊配方奶 | 医生指导下使用特殊配方奶 |

> 📝 **配方奶的中医认识**：牛奶性微寒（《本草经集注》），配方奶经调配后接近母乳性质，但仍偏凉。脾胃虚弱的婴儿喝配方奶→可能出现便溏、绿便→可在医生指导下选择部分水解配方或添加益生菌。

### 二、0-6月常见问题

#### 吐奶/溢奶——0-6月几乎每个婴儿都会经历

**为什么会吐奶？——知其所以然：**

婴儿胃与成人胃有三个关键区别，理解了就不慌：

| 区别 | 婴儿 | 成人 | 意味着什么 |
|------|------|------|-----------|
| 胃的位置 | 水平位（横着放） | 垂直位（立着放） | 奶容易"倒出来" |
| 贲门（胃入口） | 松→关不紧 | 紧→关得牢 | 奶容易从入口回流 |
| 幽门（胃出口） | 紧→排得慢 | 松→排得快 | 奶在胃里待得久→更容易返流 |

结论：**0-6月吐奶是正常生理现象，不是病。** 随着婴儿长大→胃变垂直→贲门变紧→吐奶自然减少→6月后基本消失。

**生理性溢奶 vs 病理性呕吐——家长必须会区分：**

| 鉴别点 | 生理性溢奶（正常） | 病理性呕吐（须就医） |
|--------|-------------------|---------------------|
| 奶的形态 | 原样或略凝乳状 | 喷射状→奶喷出很远 |
| 量 | 少量→嘴角流出 | 大量→反复呕吐 |
| 时间 | 吃奶后或打嗝时 | 与吃奶无关→随时 |
| 婴儿状态 | 吐后精神好→照吃照玩 | 精神差→拒奶→嗜睡→烦躁 |
| 体重 | 正常增长 | 不增或下降 |
| 伴随 | 无 | 发热/腹胀/血便/脱水 |

**减少溢奶的7个方法**：

| 方法 | 具体做法 | 原理 |
|------|----------|------|
| ①喂后拍嗝 | 详见下方"拍嗝三法" | 胃里空气排空→奶不再被"顶"出来 |
| ②喂后竖抱20分钟 | 喂完→竖抱→不立即放平→至少20分钟 | 竖位→重力帮奶往下走→胃排空→不返流 |
| ③喂后不翻动 | 换尿布/洗澡/逗玩→放在喂奶前做→喂后不动 | 翻动→胃受挤压→奶被挤出来 |
| ④少量多次 | 不等太饿才喂→每次少喂点→间隔短一些 | 一次吃太多→胃撑→贲门关不住→溢 |
| ⑤喂奶姿势正确 | 母乳：婴儿头高臀低→45°倾斜；奶瓶：奶液充满奶头→不让婴儿吸入空气 | 减少吞气→胃里空气少→溢奶少 |
| ⑥奶瓶喂注意 | 奶瓶倾斜→奶液充满奶头→不让婴儿吸空奶头→吞空气 | 空气=溢奶的帮凶 |
| ⑦右侧卧位 | 喂后放下时→先右侧卧20-30分钟→再仰睡 | 右侧卧→胃的出口在右侧→奶往下走→不返流；⚠️右侧卧时大人须在场→之后翻回仰睡 |

**溢奶时的紧急处理——防止呛奶窒息**：

> ⚠️ 这一条比"减少溢奶"更重要——婴儿吐奶时最怕的不是吐本身，而是奶呛入气管→窒息。

| 情况 | 正确做法 | 错误做法 | 原因 |
|------|----------|----------|------|
| 婴儿正在吐奶 | 立即将婴儿侧过头→或整个身体侧卧→让奶从嘴角流出 | ❌ 竖抱→奶往下流→呛入气管更严重 | 侧卧→重力让奶往外流→不往气管流 |
| 婴儿面部有奶 | 迅速用纱布/纸巾擦净口鼻→保持气道通畅 | ❌ 慌张→忘记清理→继续呛 | 气道通畅=生命线 |
| 吐后婴儿面色红、哭声响 | 安抚→换干净衣物→观察 | ❌ 过度焦虑→频繁就医 | 正常溢奶→吐后状态好→不需要特殊处理 |
| 吐后婴儿面色青紫/无声/不哭 | 立即侧卧→清理口鼻→拍打足底刺激哭→不哭→立即就医 | ❌ 等一等看看→可能窒息 | 面色青紫=缺氧→必须立即处理 |

**⚠️ 必须就医的呕吐信号**：

| 信号 | 可能问题 |
|------|----------|
| 喷射性呕吐（奶喷出30cm以上） | 幽门肥厚性狭窄→须手术 |
| 呕吐物黄绿色（胆汁） | 肠梗阻→紧急 |
| 呕吐物带血丝或咖啡色 | 消化道出血→紧急 |
| 反复呕吐+精神差+尿少 | 脱水→紧急 |
| 伴发热/腹胀/血便 | 感染/肠套叠→紧急 |

#### 拍嗝——喂奶后的必做步骤

**为什么要拍嗝？——知其所以然：**

婴儿吃奶时会吞入空气→空气进胃→占据空间→奶被"顶"出来=溢奶。空气不排→还引起腹胀→婴儿不舒服→哭闹→更多吞气→恶性循环。拍嗝=把胃里空气赶出来→奶待得住→婴儿舒服→睡得安稳。

**拍嗝三法**——不同婴儿适合不同姿势，三种都试，选最有效的：

**方法一：肩扛式（最常用）**

```
步骤：
1. 铺一块纱布巾在大人肩上（婴儿可能吐奶→保护衣服）
2. 竖抱婴儿→让婴儿下巴靠在大人肩头→身体贴着大人胸
3. 一手托住婴儿臀部→另一手掌呈"杯状"（手心微凹→不是平掌）
4. 从婴儿背部下方（腰部）开始→向上轻拍→到肩胛骨位置
5. 力度：像"轻拍桌面上的灰尘"→不是"拍打"→手腕发力→不使劲
6. 节奏：每秒1-2次→持续2-5分钟→打出嗝为止
7. 如果10分钟未出嗝→放下侧卧→也是安全的→不是每次都能拍出

💡 技巧：拍的同时可以微微上下走动→轻微晃动→帮助气泡上浮→嗝更容易出来
```

**方法二：坐膝式（适合1月以上、头能短暂竖直的婴儿）**

```
步骤：
1. 大人坐稳→让婴儿坐在大人腿上→面朝外侧或微侧
2. 一手呈"C"形→托住婴儿下巴和面颊→支撑头部（不是掐脖子！）
3. 另一手"杯状"→从腰部向上轻拍背部
4. 婴儿身体微微前倾→胃内气泡自然往上走

💡 技巧：托下巴的手掌可以感受到婴儿是否放松→僵硬→可能吞了气→继续拍
```

**方法三：俯卧式（适合经常溢奶的婴儿）**

```
步骤：
1. 大人坐稳→让婴儿俯卧在大人腿上→腹部贴着大人一条腿
2. 婴儿头侧向一边→面朝外→口鼻不被压住
3. 一手托住婴儿头部→另一手轻拍背部

💡 技巧：腹部受到轻微压迫→帮助胃内气泡排出→对容易胀气的婴儿效果好
```

**拍嗝时机**——不只是吃完才拍：

| 时机 | 做法 | 原因 |
|------|------|------|
| 母乳换侧时 | 吃完一侧→拍→再换另一侧 | 减少胃内积气→减少溢奶 |
| 奶瓶喂到一半 | 喂60-90ml→拍→再继续 | 同上 |
| 吃完奶后 | 必拍→拍出嗝再放下 | 最关键的时机 |
| 吃完20分钟内 | 如果放下后又哼唧→抱起来再拍一次 | 有时第一个嗝出来后→第二个嗝跟着→没拍净→又溢奶 |

**拍不出嗝怎么办**：

| 情况 | 处理 |
|------|------|
| 拍了10分钟没出嗝 | 放下侧卧→安全→不是每次都能拍出 |
| 放下后又溢奶 | 抱起来再拍一次→可能还有第二个嗝 |
| 婴儿吃着吃着就睡着了 | 轻轻拍醒→拍嗝→再放下→不要让婴儿含着奶头睡→容易呛奶 |
| 婴儿哭闹不愿被拍 | 先安抚→等平静再拍→哭闹时吞更多气→越哭越胀→先止哭再拍嗝 |

#### 婴儿排气操——0-3月每天必做，预防胀气比治胀气更重要

> 0-3月婴儿脾胃极弱→吃奶吞气+肠道发育不成熟→气排不出→胀气→哭闹→肠绞痛。排气操=主动帮助婴儿排气→比等胀气了再处理更有效→月嫂每天喂奶后30分钟做一遍→排气效果立竿见影。

**排气操4步法（全套约3-5分钟）**：

**第一步：蹬自行车（最常用、最有效）**

```
1. 婴儿仰卧→面带微笑→大人对着婴儿说话→"我们做操啦"
2. 大人双手分别握住婴儿小腿/脚踝
3. 左腿屈曲→膝盖贴向腹部→保持2-3秒→放下
4. 右腿屈曲→膝盖贴向腹部→保持2-3秒→放下
5. 左右交替→像蹬自行车→每侧8-10次
6. 力度：轻柔→不使劲压→婴儿不抗拒=力度合适→抗拒=减力
7. 原理：屈腿→腹部受压→挤压肠道→气体往下走→排气

💡 如果婴儿腿很僵硬抗拒→先轻柔抚摸腿部→放松→再屈→不强掰
```

**第二步：双膝并压（集中排气）**

```
1. 婴儿仰卧→大人双手握住婴儿双脚/小腿
2. 双腿同时屈曲→双膝并拢→轻压向腹部→保持5-8秒
3. 放下→伸直→重复5-8次
4. 注意：不是猛压→是缓缓贴向腹部→像"合拢-打开"

💡 这个动作排气效果最强→经常做到一半婴儿就放屁→是正常→继续做
```

**第三步：I Love You 揉腹法（中医顺时针揉腹的精细化版本）**

```
1. 大人手掌搓热→涂少量婴儿润肤油→减少摩擦
2. 在婴儿腹部→从右下腹开始→向上→向左→向下→画一个倒"U"
3. 路线：升结肠（右侧上行）→横结肠（上方向左）→降结肠（左侧下行）
4. 顺着肠道走行方向推→帮助气体和粪便往肛门方向走
5. 每次做5-8遍→手法极轻→手掌贴着皮肤滑→不按压
6. "I Love You"记忆法：
   从右下→右上→画"I"（竖线）
   从右上→左上→画"L"（横线）
   从左上→左下→画倒"L"
   → 整个轨迹就是沿着大肠走行→顺时针方向

💡 这和顺时针揉腹是同一原理→但方向更精确→不是随意画圈→是跟着肠道走
```

**第四步：轻叩背部（收尾排气）**

```
1. 做完前三步后→竖抱婴儿→拍嗝姿势
2. 手掌呈"杯状"→从腰部向上轻拍→5-10次
3. 上方气体+下方气体都有了出路→拍背帮助上气（嗝）排出

💡 前三步排下气（放屁）→第四步排上气（打嗝）→上下都通了→婴儿舒服
```

> 📝 **排气操什么时候做**：喂奶后30-60分钟→不在刚吃完时做（吐奶）→不在婴儿大哭时做（吞更多气）→每天2-3次→尤其是傍晚肠绞痛高发前做一次→预防效果最佳。

> ⚠️ **排气操禁忌**：脐带未脱落时不按压腹部→只做蹬自行车（轻）→不双膝压腹；饭后30分钟内不做；婴儿腹胀拒按+呕吐+发热→不是普通胀气→就医→不做排气操。

**排气补充手法（排气操效果不佳时使用）**：

**香坐姿（模拟排便姿势）**：

```
1. 大人半卧在床上/沙发→双腿弯曲→脚踩稳
2. 婴儿靠在大人腿上→背贴大人腹部→双脚蹬大人肚皮
3. 婴儿身体微微前倾→呈"蹲坐"姿势
4. 每次5-10分钟→配合轻拍背部
5. 原理：模拟排便姿势→腹压自然增加→促进肠蠕动→排气

⚠️ 不在喂奶后30分钟内做→不在婴儿剧烈哭闹时做
```

**热敷法（放松肠平滑肌）**：

```
1. 40°C温水装储奶袋→排空空气→封口
2. 外包2层干纱布/小毛巾→试温→手腕内侧不烫
3. 平放在婴儿腹部→轻柔固定→敷5分钟
4. 原理：温热→肠平滑肌放松→缓解痉挛→促进排气

⚠️ 温度必须<42°C→婴儿皮肤薄→烫伤风险高→每次必试温
⚠️ 隔衣物敷→不直接接触皮肤
⚠️ 与艾叶热敷（38-40°C隔衣）同理→二选一即可
```

#### 肠绞痛（3周-3月）

| 项目 | 内容 |
|------|------|
| 中医认识 | 脾虚气滞→腑气不通→腹痛 |
| 表现 | 定时哭闹（多在傍晚）、脸红、腿蜷向腹部、排气后缓解 |
| 三三法则 | 哭闹>3小时/天、每周>3天、持续>3周→符合则高度怀疑肠绞痛 |
| 处理 | ✈️飞机抱（俯卧大人前臂）；排气操（见上方）；顺时针揉腹（手法轻柔）；白噪音安抚；艾叶热敷腹部（温度38-40°C，不烫手，隔衣物敷） |
| ⚠️ 就医指征 | 哭闹无法安抚+呕吐+血便+发热→不是肠绞痛→须排查肠套叠等急腹症 |

**肠绞痛处理步骤（按顺序逐一尝试）**：

```
步骤1：检查基本需求 → 尿布湿了？饿了？太热/太冷？→ 先排除这些
步骤2：排气操 → 蹬自行车+双膝压腹→主动排气→比等婴儿自己放屁快得多
步骤3：飞机抱 → 婴儿俯卧在大人前臂→手托胸颈→另一手轻拍背→腹部受压→缓解胀气
步骤4：I Love You揉腹 → 掌根沿肠道走行顺时针推→帮助残余气体排出→每次5-8遍
步骤5：白噪音 → 吹风机声/吸尘器声/手机白噪音APP→音量不大→像子宫环境→安抚
步骤6：艾叶热敷 → 干艾叶装布袋→微波炉加热至38-40°C→隔一层衣服敷腹部→10分钟
步骤7：裹襁褓 → 用薄棉布包裹→手臂贴身→腿可微屈→模拟子宫包裹感→安全感
→ 以上6步逐一试→某一步婴儿安静了→记住→下次先用
→ 6步都无效→持续哭闹>3小时→就医→排查其他原因
```

> 📝 **宝妈自救**：肠绞痛不是你的错→不是奶不好→不是你没照顾好→3月后会自然消退→在此期间→轮换休息→让家人分担→自己的心理健康也很重要→持续崩溃→求助。

#### 湿疹（奶癣）

| 项目 | 内容 |
|------|------|
| 中医认识 | 胎毒外发 / 脾虚湿盛 / 风湿热邪蕴于肌肤 |
| 表现 | 面部、头皮红斑→丘疹→渗出→结痂；瘙痒 |
| 处理 | 母亲忌辛辣腥发（虾蟹羊肉）；婴儿清水洗脸→大量保湿（润肤霜每日3-5次）；穿纯棉衣物 |
| ⚠️ 不该做的 | ❌ 用母乳洗脸→滋生细菌；❌ 不敢保湿→越干越痒越挠越重 |
| ⚠️ 就医指征 | 渗出明显+面积扩大；影响睡眠；反复不愈 |

**湿疹外用激素——家长最常见误区**：

| 误区 | 真相 |
|------|------|
| "激素不能用→有依赖" | 外用激素是湿疹一线治疗→规范使用→安全→不用→湿疹加重→皮肤屏障更差→恶性循环 |
| "用了激素会变胖/影响发育" | 外用激素≠口服激素→皮肤局部吸收→全身作用极微→规范用→不影响生长发育 |
| "见好就停→不按疗程用" | 湿疹好转→仍须逐步减量→突然停→反弹→正确做法：每日用→好转后→隔日→隔两日→停→医生指导减量方案 |

**外用激素使用原则**：

| 项目 | 说明 |
|------|------|
| 强度选择 | 医生根据严重程度选→面部/褶皱处用弱效（如1%氢化可的松）→四肢躯干可用中效→婴儿不用强效/超强效 |
| 用量 | 指尖单位（FTU）=从5mm口径管挤出→食指末节长度的药量→涂**患儿**2个手掌面积→薄涂→不厚涂→⚠️ 用患儿手掌而非成人手掌估算面积 |
| 频率 | 每日1-2次→医生指导→好转后减量→不停药 |
| 润肤霜配合 | 先涂激素→等15分钟→再涂润肤霜→不反过来→润肤霜用量是激素的10倍以上 |
| 疗程 | 急性期5-14天→医生指导→不自行延长>2周 |

> 📝 **湿疹的保湿原则**：中医讲"润则肌肤和"——湿疹不是"湿"所以不保湿，恰恰相反，湿疹皮肤屏障受损→水分流失→干燥→瘙痒加重→必须大量保湿。润肤霜用量=每周150-200g（全身）——家长常见错误是用得太少。

#### 绿便

> 绿便判断顺序——按此顺序逐一排除：

```
1. 先问：在补铁吗？→ 是 → 铁未吸收→正常→不停铁
2. 没补铁→问：大便性状？→ 稀+泡沫+肠鸣 → 前奶后奶不均衡/受凉
3. 不稀→问：量多少？→ 量少+婴儿哭闹觅食 → 饥饿性绿便→加量
4. 量正常→问：有血丝/黏液？→ 有 → 牛奶蛋白过敏→就医
5. 以上都不是→偶尔绿便1-2次→精神好→观察→多能自行恢复
```

| 原因 | 表现 | 处理 |
|------|------|------|
| 受凉 | 绿色稀便+肠鸣 | 注意腹部保暖；母亲少吃寒凉 |
| 铁剂未吸收 | 补铁后绿色便 | 正常反应→不停铁 |
| 前奶后奶不均衡 | 只吃前奶（乳糖多）→绿色泡沫便 | 每次吃空一侧再换另一侧 |
| 饥饿性绿便 | 量少+绿+婴儿哭闹觅食 | 增加哺乳量 |
| 牛奶蛋白过敏 | 绿便+血丝+湿疹+呕吐 | **就医**→须更换深度水解/氨基酸配方奶 |

#### 夜啼

| 证型 | 表现 | 处理 |
|------|------|------|
| 心热 | 面赤唇红、烦躁、大便干 | 灯心草1g煮水少量喂服（**6月以上，须医生指导**） |
| 脾寒 | 面色白、四肢凉、便溏 | 注意腹部保暖；母亲饮食加姜 |
| 伤食 | 口气酸臭、腹胀、趴睡 | 减食+顺时针揉腹（详见第三部分积食） |
| 惊恐 | 睡中惊叫、面色青 | 多抚慰→不吓唬→环境安静 |

> ⚠️ 夜啼持续不缓解→就医排查。**3月内婴儿夜啼多为肠绞痛**，3月后仍持续须排除其他原因（中耳炎、牛奶蛋白过敏等）。

**夜啼操作性指导——夜醒时的处理流程**：

```
夜醒处理流程：
1. 先等1-2分钟→不给立刻回应→让婴儿尝试自己接觉
2. 仍然哭→轻声说话/轻轻拍→不抱起来→不喂奶→先尝试"最小干预"
3. 拍1-2分钟→安静了→退出→成功
4. 拍了还在哭→抱起来安抚→不摇晃→不喂奶（除非距上次喂奶>3小时）
5. 安静后→放下→困但没睡着时放下→让他自己完成入睡
6. 放下又哭→重复步骤2-5→每次增加等待时间→逐步延长
```

## 第三部分 6-12月——辅食添加与脾胃守护

> 6-12月是0-3岁**最关键的饮食过渡期**，也是脾胃最易受伤的时期。此阶段的核心任务：**给脾胃循序渐进的"训练"，而不是一下子给脾胃上"大餐"。**

### 一、辅食添加的铁律——钱乙"脾常不足"的实际应用

```
核心逻辑：
  脾常不足 → 运化力弱 → 辅食=给脾胃"练兵"
    → 练兵要循序渐进 → 不可一上来就上"大餐"
    → 一次只加一种 → 观察3天 → 无异常再加下一种
    → 从稀到稠 → 从少到多 → 从细到粗 → 从素到荤
```

#### 辅食添加月龄表

| 月龄 | 可添加 | 尚不可添加 | 原因 |
|------|--------|-----------|------|
| 满6月 | 强化铁米粉、米汤 | 蛋白、海鲜、坚果、蜂蜜 | 脾胃只能接受最易消化的谷物；蜂蜜含肉毒杆菌芽孢→1岁以下禁用 |
| 7-8月 | 蛋黄（从1/4起，观察3天）、菜泥（胡萝卜/南瓜/土豆）、果泥（苹果/香蕉） | 蛋白、整蛋、粗纤维蔬菜、贝壳类 | 蛋白是常见过敏原；粗纤维难消化 |
| 9-10月 | 蛋全（不过敏前提下）、肉末（猪/鸡）、鱼泥、烂面条、软烂粥 | 坚硬食物、高盐高糖、蜂蜜 | 逐步增加蛋白质种类 |
| 11-12月 | 软烂米饭、碎菜、小块软食 | 整粒坚果、硬糖、圆形食物（葡萄/圣女果整颗） | 坚硬→消化不了；圆形→窒息风险 |

#### 辅食添加的中医顺序——为什么谷物先行

| 顺序 | 食物 | 中医道理 | 首选量 |
|------|------|----------|--------|
| **第一** | 米粉/米汤 | 《素问·脏气法时论》："五谷为养"——谷物性平味甘→最健脾→最易消化→给脾胃最温和的"训练" | 1-2勺起→逐步增加 |
| **第二** | 根茎类蔬菜（山药/胡萝卜/南瓜） | 甘平/甘温→健脾益气→配合谷物夯实脾胃基础 | 1-2勺起 |
| **第三** | 果泥（苹果/香蕉） | 甘平/甘寒→少量即可→过多则偏凉→便溏 | 少量→观察大便 |
| **第四** | 蛋黄 | 甘平→养血→但含异性蛋白→从1/4起试探→过敏则停 | 1/4个→逐步加至1个 |
| **第五** | 肉类 | 最后加→蛋白质虽重要→但最需要脾胃运化力→脾胃基础打好再加 | 少量肉末→逐步增加 |

> ⚠️ **辅食添加最易犯的三个错误**：
> 1. **过早加肉类**——6-7月就加肉→脾胃运化不动→积食→腹泻
> 2. **过多种类同时加**——一天加2-3种新食物→过敏了不知道是哪种→每次只加一种
> 3. **量过多**——第一次就给半碗→脾虚运化不动→呕吐腹泻→从1-2勺开始

#### 每种新辅食的添加流程

```
第1天：1小勺（约5g）→ 观察24小时
  ↓ 无过敏（皮疹/呕吐/腹泻/呼吸急促）
第2天：2小勺 → 继续观察
  ↓ 无异常
第3天：正常量 → 确认耐受
  ↓
第4天起：该食物视为"已接受"→ 可添加下一种新食物

出现异常 → 停止该食物 → 等2周后再试 → 仍异常 → 该食物暂排除 → 就医排查过敏
```

#### 6-12月每日喂养参考

| 月龄 | 奶量 | 辅食次数 | 辅食内容 |
|------|------|----------|----------|
| 6月 | 600-800ml | 1次 | 米粉+菜泥 |
| 7-8月 | 600-800ml | 2次 | 米粉/粥+菜泥+蛋黄+果泥 |
| 9-10月 | 500-700ml | 2-3次 | 软烂粥/面+蛋黄+肉末+碎菜 |
| 11-12月 | 400-600ml | 3次 | 软烂饭+蛋+肉+菜；接近成人餐次 |

> 📝 **奶量仍为主**——6-12月奶仍是主要营养来源，辅食是"补充"和"训练"，不是"替代"。常见误区：加了辅食就猛减奶→营养不足。

### 二、积食——0-3岁第一高频问题

> **积食是0-3岁几乎所有消化问题的根源**，也是许多发热、咳嗽的诱因。理解积食=理解0-3岁小儿疾病的一半。

#### 积食链——病是怎么来的

```
喂多了/吃杂了 → 脾运化不动 → 食积胃肠 →
  → 郁而化热 → 发热（低热为主，手足心热，腹部热）
  → 脾虚生湿 → 湿聚成痰 → 咳嗽（夜间/晨起加重）
  → 胃气上逆 → 呕吐（酸臭味）
  → 腑气不通 → 便秘/腹泻交替
  → 脾虚不运 → 食欲下降 → 不想吃 → 强喂 → 更积 → 恶性循环
```

#### 积食的识别

| 信号 | 表现 | 可靠程度 |
|------|------|----------|
| **口气** | 酸腐臭味——**最可靠的信号** | ⭐⭐⭐ |
| **大便** | 酸臭、带奶瓣/食物残渣、或便秘（羊屎状） | ⭐⭐⭐ |
| **舌苔** | 中后部厚腻（白腻或黄腻） | ⭐⭐⭐ |
| **腹部** | 腹胀、按之不适、趴着睡 | ⭐⭐ |
| **食欲** | 突然不爱吃、含着不咽 | ⭐⭐ |
| **睡眠** | 翻来覆去、趴睡、磨牙 | ⭐⭐ |
| **精神** | 烦躁、手足心热 | ⭐ |

#### 积食的处理

| 方法 | 做法 | 原理 | 注意 |
|------|------|------|------|
| **减食** | 减量3-5成、以粥为主 | 减轻脾胃负担→给运化恢复的时间 | ⚠️ **不是禁食**——粥必须吃，水必须喝 |
| **焦三仙水** | 焦山楂3g+焦麦芽3g+焦神曲3g，煮水100ml，分2-3次服 | 焦山楂消肉食、焦麦芽消米面、焦神曲消面食→三味合消一切食积 | 3味等分→儿科消食经典组合；**不超3天**→消食不健脾→久用反伤脾 |
| **顺时针揉腹** | 掌根围绕肚脐顺时针揉，每次5分钟，每日2-3次 | 顺肠蠕动方向→促进排便→积食出路 | 揉前搓热双手；饭后30分钟再做；手法轻柔 |
| **捏脊** | 从尾骨沿脊柱两侧向上捏至大椎，每日3-5遍 | 督脉+膀胱经→健脾助运→儿科外治第一法 | 详见第五部分小儿推拿 |

> ⚠️ **积食发热≠感染发热**——鉴别要点：

| 鉴别点 | 积食发热 | 感染发热 |
|--------|----------|----------|
| 体温 | 低热为主（37.5-38.5°C） | 可高热（>39°C） |
| 热型 | 手足心热、腹部热 | 全身热 |
| 伴随 | 口气酸臭、腹胀、大便酸臭 | 咽红、咳嗽、流涕 |
| 处理 | 消食+减食 | 可能需要抗感染治疗 |

> 但如果高热>39°C或精神萎靡→可能合并感染→须就医→不可自行判断为"积食热"而延误。

#### 预防积食——比治疗更重要

| 原则 | 做法 | 原因 |
|------|------|------|
| 七分饱 | 每餐不吃到撑→七分饱即止 | 脾运化力有限→七分=运化得动→十分=运化不动→积 |
| 不追喂 | 不吃就收→下顿再吃→不强迫 | 食欲=脾胃的自我调节信号→不想吃=脾胃在休息→强喂=积食 |
| 饭前不加餐 | 正餐前1小时不吃零食水果 | 零食占胃→正餐吃不下→营养不均衡→脾胃节律混乱 |
| 细嚼慢咽 | 鼓励婴儿多嚼→不急于吞 | 口腔咀嚼=消化的第一步→嚼碎→胃的负担减半 |
| 晚餐少吃 | 晚餐量<午餐 | 夜间脾胃应休息→吃多→积食→夜卧不安 |

## 第四部分 1-3岁——从以奶为主到以食为主

> 1岁后婴儿进入幼儿期，饮食从"以奶为主"转为"以食为主"。脾胃功能逐步增强，但仍脆弱——这个阶段的喂养决定3岁后的体质基础。

### 一、1岁后的饮食框架

| 食物类别 | 每日建议 | 中医道理 |
|----------|----------|----------|
| 谷物（米/面/粥） | 主食，占每餐1/2 | "五谷为养"——脾之所喜；谷物性平味甘→最健脾 |
| 蔬菜 | 占每餐1/4 | 甘平蔬菜健脾（胡萝卜/南瓜/山药）；不过多寒凉蔬菜（苦瓜/茭白） |
| 蛋白质（蛋/肉/鱼） | 占每餐1/4 | 适量→过量则积食；1-2岁每日1个蛋+50g肉/鱼 |
| 水果 | 饭后少量（半个苹果/1根香蕉量） | 生食偏凉→少量助消化→过量伤脾阳 |
| 奶 | 1岁后400-600ml→2岁后300-500ml→逐步减量 | 奶性偏凉（中医视牛奶为微寒）→脾胃弱者大量饮→便溏；1岁后奶已非主食 |

### 二、1-3岁最易犯的喂养错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| **追着喂/强迫进食** | 食不消化→积食→厌食 | 定时定点→不吃就收→下顿再吃→不强迫 |
| **零食不断** | 脾胃无休息→始终在运化→脾虚 | 两餐之间最多1次加餐→正餐前1小时不吃零食 |
| **汤泡饭** | 汤稀释胃液+饭不经咀嚼→脾胃运化负担加重 | 饭和汤分开→细嚼慢咽 |
| **睡前吃/喝奶** | 脾胃夜间应休息→进食→运化不停→积食+夜卧不安 | 睡前1小时不进食；若必须喝奶→喝完刷牙→不衔奶瓶入睡 |
| **过度进补**（人参/鹿茸/燕窝/蜂王浆） | 小儿纯阳之体→补→化火→早熟/流鼻血/烦躁 | **小儿不宜补**——健脾即可→山药/莲子/茯苓；1岁以下禁蜂蜜（肉毒杆菌风险） |
| **饮食成人化** | 过咸/过油/过辣→伤脾胃+伤肾 | 3岁前单独做→少盐少油不辣→1岁前不加盐 |

> ⚠️ **关于盐**：1岁前婴儿肾功未完善→加盐→肾脏负担→远期高血压风险。1-3岁可少量加盐（每日<1.5g），但远低于成人口味。**"不吃盐没力气"是错误观念**——天然食物中已含足够钠。

### 三、1-3岁常见病

#### 感冒

| 证型 | 辨证要点 | 家庭调护 | 就医指征 |
|------|----------|----------|----------|
| 风寒感冒 | 清涕+怕冷+舌淡苔白+无汗 | 葱白2段+生姜1片+红糖少许→加水200ml→大火烧开→小火煮5分钟→少量频服→每日2-3次；注意保暖→尤其腹部和足部 | 高热>39°C持续24小时；精神萎靡；呼吸急促 |
| 风热感冒 | 黄涕+咽红+舌红苔黄+有汗 | 薄荷1g（后下→关火前1分钟放入）+菊花2g→开水冲泡→加盖5分钟→少量频服；多饮温水 | 同上 |
| 暑湿感冒（夏季） | 身重困倦+纳呆+舌苔腻 | 藿香正气颗粒/口服液（无醇剂型）→须在医生指导下 | 同上 |

**感冒物理护理**：

| 护理项 | 做法 | 原因 |
|--------|------|------|
| 鼻塞 | 生理盐水滴鼻→软化分泌物→吸鼻器辅助（见2.14鼻塞处理） | 鼻塞→吃奶困难→婴儿拒奶→须处理 |
| 多饮温水 | 少量多次→每次10-20ml→频次>单次量 | 补充水分→稀释痰液→帮助排毒 |
| 保持室内湿度 | 50-60%→加湿器→每天换水 | 湿润→呼吸道舒适→痰易排出 |
| 不捂汗 | 正常穿衣→不刻意加衣加被→发热时反而减衣 | 捂汗→体温更高→婴儿体温调节差→危险 |
| 休息 | 减少外出→不剧烈活动→不强迫进食 | 脾胃在感冒期间运化力差→少吃→让脾胃休息 |

> 📝 **感冒一年4-6次属正常**——小儿肺常娇嫩+免疫系统发育中→频繁感冒≠体弱→不必焦虑。但如果每月1次以上→须从脾论治（培土生金）→健脾→肺气足→抵抗力上来。

> ⚠️ **感冒不可乱用抗生素**：90%以上小儿感冒为病毒感染→抗生素无效→反伤脾胃→导致腹泻/菌群失调。只有医生确认细菌感染（如化脓性扁桃体炎）才用抗生素。

#### 咳嗽

| 证型 | 辨证要点 | 家庭调护 | 就医指征 |
|------|----------|----------|----------|
| 风寒咳嗽 | 痰白稀+流清涕+舌淡 | 陈皮2g+生姜1片→加水150ml→煮10分钟→少量频服 | 咳嗽>2周不愈 |
| 风热咳嗽 | 痰黄稠+咽红+舌红 | 梨1/4个（去核不去皮）+冰糖3g+川贝粉1g→隔水炖30分钟→取汁少量频服 | 伴气促/喘息 |
| 痰湿咳嗽 | 痰多+喉中痰鸣+舌苔白腻 | 减食+顺时针揉腹（化痰先消食） | 夜间咳醒多次 |
| 积食咳嗽 | 食后咳+口气酸臭+腹胀 | 焦三仙水+减食 | — |
| 阴虚咳嗽 | 干咳无痰+舌红少苔+手足心热 | 百合5g+梨半个→加水200ml→小火煮20分钟→取汁少量频服 | — |

> ⚠️ **犬吠样咳嗽**（声音像小狗叫）+声音嘶哑+吸气困难→急性喉炎→**紧急就医**→可迅速窒息→不可等待。

**拍背排痰法——帮助婴儿排出痰液**：

| 项目 | 做法 |
|------|------|
| 时机 | 晨起+睡前+喂奶前30分钟→不在刚吃完奶时拍→防吐 |
| 姿势 | 婴儿俯卧在大人腿上→或侧卧→臀部略高于头部 |
| 手法 | 大人手掌呈"杯状"（手心微凹）→利用腕力→从背部下方→由外向内→由下向上→叩击 |
| 力度 | 像"拍鼓"→发出"空空"声→不是"啪啪"打→手腕发力→不用力 |
| 频率 | 每秒2-3次→每侧拍1-2分钟→两侧交替→总计3-5分钟 |
| 效果 | 拍后婴儿可能咳嗽→咳出痰→是好事→小婴儿不会吐痰→痰吞下去→随大便排出→正常 |

**咳嗽期间饮食禁忌**：

| 禁忌 | 原因 |
|------|------|
| 甜食/巧克力/蛋糕 | 甜→生痰→"甜腻助湿"→痰更多 |
| 冷饮/冰淇淋 | 寒→伤脾阳→脾虚→运化水湿差→痰更多 |
| 油炸食品 | 油腻→难消化→积食→积食生痰 |
| 过咸食物 | 咸→刺激咽喉→咳嗽加重 |
| 牛奶（痰多时） | 牛奶性微寒+滋腻→痰湿咳嗽时→助湿→痰更黏→可以喝但量减半；风寒/阴虚咳嗽不受限 |

#### 腹泻

| 证型 | 辨证要点 | 家庭调护 | 就医指征 |
|------|----------|----------|----------|
| 伤食泻 | 酸臭+奶瓣/食物残渣+腹痛 | 焦三仙水+减食 | — |
| 风寒泻 | 泡沫+肠鸣+恶寒 | 注意腹部保暖；姜汤少量 | — |
| 湿热泻 | 水样+臭秽+肛门红 | 马齿苋10g煮水（须医生指导） | — |
| 脾虚泻 | 完谷不化+迁延不愈+面色萎黄 | 山药粥+莲子粥+捏脊 | — |

> ⚠️ **腹泻最危险的不是"泻"而是"脱水"**——小儿体液比例高→腹泻→迅速脱水→循环衰竭。

**脱水识别与处理**：

| 脱水程度 | 表现 | 处理 |
|----------|------|------|
| 轻度 | 口渴、尿稍少、精神尚可 | 口服补液盐（ORS）→少量多次→每次腹泻后补充50-100ml |
| 中度 | 皮肤弹性差、眼窝凹陷、口唇干、尿明显减少 | 口服补液盐+就医评估 |
| 重度 | 精神萎靡/嗜睡、前囟凹陷、哭时无泪、6小时以上无尿 | **紧急就医→可能需静脉补液** |

**口服补液盐（ORS）使用方法**：

| 项目 | 说明 |
|------|------|
| 选择 | ORSⅢ（口服补液盐散Ⅲ）→WHO推荐配方→最安全→药店有售 |
| 冲泡 | 按说明书→整袋冲入指定量温开水→不自行加减水量→不半袋冲→浓度不对→无效或有害 |
| 喂法 | 少量多次→每1-2分钟喂1勺（5ml）→不要一次喂太多→呕吐→更脱水 |
| 量 | 轻度脱水→50ml/kg/4小时；每次腹泻后→50-100ml补充；预防脱水→每次稀便后10ml/kg |
| ⚠️ | 不用运动饮料/果汁/白水替代→电解质比例不对→可能加重腹泻；ORS冲泡后→室温保存≤4小时→冷藏保存≤24小时→超时倒掉 |

**腹泻饮食指导（BRAT原则+中国化）**：

| 食物 | 说明 | 适合月龄 |
|------|------|----------|
| B-香蕉 | 含钾→补充腹泻丢失的电解质→熟透的香蕉压泥 | 6月+ |
| R-米汤/米粥 | 最易消化→淀粉→提供能量→米汤比粥更易消化 | 所有月龄 |
| A-苹果泥 | 苹果含果胶→收敛→蒸熟后压泥→止泻 | 6月+ |
| T-吐司/馒头干 | 淀粉→提供能量→不加黄油/果酱 | 8月+ |
| 补充：山药粥 | 山药健脾→收敛→中医健脾止泻 | 6月+ |
| 补充：胡萝卜泥 | 含果胶→大便成形 | 6月+ |

> ⚠️ **腹泻期间禁忌**：牛奶（乳糖难消化→加重腹泻→轮状病毒腹泻时可暂时换无乳糖配方）、高糖饮料/果汁（渗透性腹泻→加重）、油腻食物、粗纤维蔬菜。

#### 发热

| 类型 | 辨证要点 | 处理 |
|------|----------|------|
| 外感发热 | 伴鼻塞/咳嗽/咽红 | 38.5°C以下且精神好→多饮温水→正常穿衣→不必刻意降温；38.5°C以上或不舒服→对乙酰氨基酚（按体重算剂量；**3月以上可用**）/布洛芬（**6月以上可用**）+中医辨证 |
| 积食发热 | 手足心热+口气酸臭+腹部热 | 减食+焦三仙水+顺时针揉腹 |
| 出疹性发热 | 发热3-4天后出疹 | 可能是幼儿急疹→见下方详述 |

> ⚠️ **发热的铁律**：
> - **<3月龄任何发热（腋温≥38°C）→立即就医**——不可自行退烧→须排查严重感染
> - **3-6月龄发热→对乙酰氨基酚；6月龄以上→对乙酰氨基酚或布洛芬（选一种，不常规交替）**——按体重算剂量，不按年龄
> - **精神状态比体温更重要**——39°C但精神好→相对安全；38°C但精神萎靡→更危险
> - **不捂汗**——"捂汗退烧"是错误→婴儿体温调节中枢不完善→捂→体温更高→高热惊厥→危险

**发热处理核心原则——退热目的是让患儿舒适，不是降数字**：

> AAP 2022、NICE 2019指南明确：**不推荐常规温水擦浴等物理降温**。温水擦浴可引起寒战反而升温，且增加不适感。退热唯一指征=让患儿舒服。

| 体温 | 精神状态 | 处理 |
|------|----------|------|
| <38.5°C | 精神好→照玩照吃 | 多饮温水→正常穿衣→观察→不必刻意降温 |
| <38.5°C | 不舒服→烦躁 | 可给退烧药→目的是让患儿舒适 |
| ≥38.5°C | — | 给退烧药→30-60分钟后评估→降1-1.5°C即有效→不必降到正常 |
| 退烧药无效且极度不适 | — | 就医→**仅在医生指导下**可考虑温水擦浴辅助→非常规→非首选 |

**⚠️ 绝对禁止**：酒精擦浴→酒精经皮肤吸收→中毒风险；冰敷→寒战→产热更多→体温反升。

**发热时穿衣指导**：

| 错误做法 | 正确做法 | 原因 |
|----------|----------|------|
| 捂汗→穿多盖厚 | 正常穿衣→偏薄→散热 | 捏汗→体温更高→惊厥 |
| 冰敷→退热贴 | 正常穿衣→偏薄→散热 | 退热贴→局部冰冷→血管收缩→反而不散热；冰敷→寒战→产热更多 |
| 光着不穿 | 穿薄棉衣→不露 | 完全不穿→不舒服+寒战→不好 |

**幼儿急疹——"热退疹出"的典型经过**：

| 阶段 | 表现 | 处理 |
|------|------|------|
| 第1-3天 | 突然高热→39-40°C→但精神好→吃玩正常→"热高但精神好"→幼儿急疹最特征 | 按体重给退烧药→多饮水→观察→**精神好→不必恐慌** |
| 第3-4天 | 体温突然降至正常→同时/稍后→躯干出现玫瑰色皮疹→按压褪色→不痒 | 皮疹不需要任何处理→1-2天自行消退→不留痕迹→不脱皮→不色素沉着 |
| 恢复 | 皮疹消退→完全恢复→不复发 | — |

> 📝 **幼儿急疹判断要点**：高热3天+精神好+无明显咳嗽流涕+热退后出疹→高度怀疑幼儿急疹。但**高热期间不能确定是幼儿急疹**→须医生排除其他感染→确诊靠回顾→"事后确认"。

#### 厌食

| 证型 | 辨证要点 | 调护 | 就医指征 |
|------|----------|------|----------|
| 脾虚厌食 | 长期不爱吃+面色萎黄+便溏+舌淡 | 山药莲子粥+捏脊+不强迫进食 | 体重下降+持续>2周 |
| 积食厌食 | 突然不爱吃+口气酸臭+腹胀 | 焦三仙水+减食+顺时针揉腹 | 伴发热/呕吐 |
| 缺锌 | 异食癖（吃土/吃纸）+生长缓慢+地图舌 | 就医检查微量元素→食补：牡蛎/瘦肉/蛋黄 | 确认后补充锌剂 |

> 📝 **厌食最常见的原因不是"病了"，而是"喂错了"**——追喂/强迫/零食太多/饮食不规律→脾胃节律被打乱→不想吃→强喂→更不想吃→恶性循环。**破局的关键是：不吃就收，不追不逼，下一顿再吃。**

**脾虚厌食食疗方**：

| 食疗 | 做法 | 适用 |
|------|------|------|
| 山药莲子粥 | 山药15g+莲子10g+大米30g→煮烂粥→每日1次→连用7-10天 | 脾虚厌食首选 |
| 茯苓大枣粥 | 茯苓粉5g+大枣2枚（去核）+大米30g→煮粥 | 脾虚+湿重（便溏+舌苔白腻） |
| 山楂麦芽饮 | 山楂3g+麦芽5g→开水冲泡→少量频服 | 厌食+微有积滞（口气微酸） |

**厌食行为干预——比药物更重要**：

| 原则 | 做法 | 原因 |
|------|------|------|
| 定时定点 | 每日3餐+1-2次加餐→固定时间→固定位置→20分钟内结束→不吃就收 | 建立饮食节律→脾胃按时"上班"→按时"休息" |
| 不追喂 | 不吃→平静地说"不吃就收了"→收走→不哄→不威胁→不奖励→下顿再吃 | 追喂→注意力在"被追"不在"吃"→越追越不吃 |
| 不用甜食/零食替代 | 正餐不吃→不给零食/酸奶/水果替代→下一顿正餐再吃 | 零食替代→脾胃被"零食填满"→正餐更不想吃 |
| 让孩子参与 | 1岁后→让孩子自己拿勺→用手抓→允许弄脏→不代喂 | 自主进食→兴趣↑→吃得更多 |
| 用餐氛围 | 不在吃饭时批评/训斥/讨论学习→轻松愉快→大人也一起吃 | 情绪→影响食欲→训斥→肝气犯胃→更不想吃 |

## 第五部分 小儿推拿——0-3岁最安全的外治法

> 小儿推拿是中医儿科最具特色的外治法。药物不经胃肠→不伤脾胃→特别适合"脾常不足"的小儿。此法源于明代《小儿推拿广义》等专著，经数百年临床验证，安全有效。

### 一、常用穴位与手法

> 📝 **推拿总原则**：手法轻柔、速度均匀、使用介质（婴儿润肤油/爽身粉→防皮肤擦伤）、每日1-2次、操作者双手温暖。

#### 日常保健核心手法

| 手法 | 位置 | 操作 | 功效 | 适用 |
|------|------|------|------|------|
| **捏脊** | 脊柱两侧（尾骨→大椎） | 双手拇指桡侧+食指捏起皮肤→交替向上推进→3-5遍/日 | 健脾助运→**儿科保健第一法** | 脾虚、积食、厌食、反复感冒 |
| **补脾经** | 拇指桡侧缘（指尖→指根） | 拇指从指尖推向指根→200-300次 | 健脾益气 | 脾虚、食少、便溏 |
| **揉板门** | 大鱼际中点 | 指端揉→100-200次 | 健脾消食 | 积食、呕吐、腹泻 |
| **顺时针摩腹** | 腹部围绕肚脐 | 掌根顺时针揉→100圈 | 促进肠蠕动→助消化 | 积食、便秘、腹胀 |
| **按揉足三里** | 外膝眼下3寸 | 拇指按揉→50次 | 强壮全身 | 各型日常保健 |

#### 对症手法

| 手法 | 位置 | 操作 | 功效 | 适用 |
|------|------|------|------|------|
| **清胃经** | 大鱼际桡侧赤白肉际 | 从腕横纹推向拇指根→100-200次 | 清胃热、消食积 | 积食、口臭、呕吐 |
| **推三关** | 前臂桡侧（腕→肘） | 从腕推至肘→100-200次 | 温阳散寒 | 风寒感冒、怕冷、腹痛 |
| **退六腑** | 前臂尺侧（肘→腕） | 从肘推至腕→100-200次 | 清热凉血 | 高热、实热证 |
| **清天河水** | 前臂正中（腕→肘） | 从腕推至肘→100-300次 | 清热解表 | 发热、外感 |
| **推涌泉** | 足底前1/3凹陷处 | 拇指从涌泉推向趾尖→100-200次 | 引火归元、安神 | 夜啼、烦躁、发热 |
| **揉膻中** | 两乳头连线中点 | 中指揉→100次 | 宽胸理气 | 咳嗽、胸闷 |
| **运内八卦** | 掌心围绕掌中 | 拇指顺时针运→100次 | 宽胸理气、消食 | 咳嗽痰多、食积 |

### 二、日常保健推拿方案（每日一次）

| 步骤 | 手法 | 次数 | 作用 |
|------|------|------|------|
| 1 | 捏脊 | 3-5遍 | 健脾助运（核心） |
| 2 | 补脾经 | 200次 | 健脾益气 |
| 3 | 揉板门 | 100次 | 消食和胃 |
| 4 | 顺时针摩腹 | 100圈 | 促进肠蠕动 |
| 5 | 按揉足三里 | 50次 | 强壮全身 |

> 最佳时间：晨起或午睡后→饭前30分钟→饭后30分钟内不做。

**"200次"到底推多久？——家长实操换算**：

| 推拿次数 | 大约时间 | 体感判断标准 |
|----------|----------|-------------|
| 50次 | 约30秒 | 1次呼吸≈推2-3遍→轻松数到50 |
| 100次 | 约1分钟 | 不用精确计时→推到皮肤微微发热即可 |
| 200次 | 约2分钟 | 最常用→推约2分钟→皮肤微红=到位 |
| 300次 | 约3分钟 | 较长时间→适合补脾经等主力手法 |

> 📝 **不必纠结次数**：小儿推拿的"次"不是精确计数量→是约数。**关键指标是皮肤反应**——推到操作部位皮肤微红、微微发热→说明气血已到→效果已起→即可停止。推了200次皮肤没反应→继续；推了100次皮肤已红→够了。比次数更重要的是：**手法轻柔、速度均匀、使用介质**。

### 三、常见病推拿对症方案

> 以下组合方案在保健方案基础上→根据症状加减→每种方案每日1-2次→3-5天为1疗程。

| 常见问题 | 推拿方案（在保健方案基础上替换/增加） | 操作要点 |
|----------|--------------------------------------|----------|
| **积食** | 保健方案+清胃经200次+顺时针摩腹加至200圈 | 揉板门改为重点→消食主力；清胃经→从腕推向拇指根→清胃热消食积 |
| **感冒（风寒）** | 推三关200次+揉膻中100次+运内八卦100次+捏脊 | 推三关=温阳散寒主力→从腕推至肘→手法稍快→皮肤微红为度 |
| **感冒（风热）** | 清天河水300次+退六腑100次+揉膻中100次 | 清天河水=清热解表主力→从腕推至肘→力度轻→速度稍快 |
| **发热** | 清天河水300次+退六腑200次+推涌泉200次 | 高热→退六腑为主→从肘推至腕→力度可稍大；推涌泉→引火归元→安神 |
| **咳嗽** | 揉膻中150次+运内八卦150次+补脾经200次 | 揉膻中=宽胸理气主力→中指揉→力度轻；痰多→加顺时针摩腹200圈 |
| **腹泻** | 补脾经300次+揉板门200次+捏脊5遍+推三关100次 | 补脾经=健脾主力→从指尖推向指根→次数增加 |
| **便秘** | 清大肠（食指桡侧→从指根推向指尖）200次+顺时针摩腹200圈+推下七节骨（第四腰椎至尾骨→向下推）100次 | 顺时针摩腹=促进肠蠕动主力；推下七节骨=通便专用→向下推→不可反向 |
| **夜啼/烦躁** | 推涌泉300次+清天河水200次+揉百会（头顶正中）50次 | 推涌泉=安神主力→从涌泉推向趾尖→力度轻→速度慢→有镇静效果 |
| **厌食** | 补脾经300次+揉板门200次+捏脊5遍 | 补脾经+揉板门=健脾消食组合→坚持7-10天→见效 |

**推拿手法常见错误与风险**：

| 错误 | 风险 | 正确做法 |
|------|------|----------|
| 力度过大→把婴儿皮肤推红/推破 | 皮肤损伤→疼痛→婴儿抗拒→不愿再推拿 | 力度=轻柔→皮肤微红为度→不破皮→不瘀青 |
| 不用介质→干推 | 摩擦→皮肤擦伤→婴儿疼痛 | 每次推拿前→手上涂婴儿润肤油/爽身粉→减少摩擦 |
| 推错方向（如退六腑推反了→变推三关） | 方向反→功效反→热证推三关→更热 | 严格按方向→推三关=腕→肘（向上）；退六腑=肘→腕（向下）→不混淆 |
| 推拿时间过长>30分钟 | 婴儿疲劳→哭闹→效果差 | 每次总时长15-20分钟→婴儿安静时做→哭闹→暂停 |
| 饭后立即推拿 | 呕吐→消化受影响 | 饭后30分钟以上再做→饭前30分钟以上做 |

### 四、推拿禁忌

| 禁忌情况 | 原因 |
|----------|------|
| 皮肤破损/感染处 | 防感染扩散 |
| 骨折/创伤处 | 避免加重损伤 |
| 出血性疾病 | 推拿→皮下出血 |
| 急性传染病 | 须就医→不自行推拿 |
| 严重心脏病 | 手法刺激→心脏负担 |
| 空腹或过饱 | 空腹→低血糖；过饱→呕吐 |
| 疫苗接种当天 | 注射局部须休息→次日可恢复 |

## 第六部分 体质辨识——不是所有孩子都一样

> 同样的喂养方式，不同孩子反应不同——因为体质不同。辨识体质→针对性调护→事半功倍。

### 五种常见体质

| 体质 | 特征 | 喂养方向 | 常见病倾向 | 忌 |
|------|------|----------|-----------|-----|
| **平和质**（理想） | 面色红润、精神活泼、二便正常、睡眠安稳、适应力强 | 均衡饮食，不过偏 | 少病 | 无特殊禁忌 |
| **脾虚质** | 面黄肌瘦、食少便溏、容易积食、舌淡苔白、四肢乏力 | 健脾为主：山药粥/茯苓粥/莲子粥；少食多餐；忌寒凉生冷 | 积食、腹泻、厌食 | 寒凉（冰饮/西瓜/苦瓜）、过饱 |
| **湿热质** | 面垢油光、湿疹反复、大便黏臭、舌红苔黄腻、体胖 | 清利湿热：薏米粥/冬瓜汤/荷叶粥；忌肥甘辛辣 | 湿疹、腹泻、反复感染 | 肥甘（油炸/巧克力/甜食）、辛辣 |
| **气虚质** | 面白乏力、自汗易感冒、语声低、舌淡、食欲差 | 补气健脾：山药粥/大枣粥；适当户外活动；反复感冒者须就医辨证→医生指导下可用黄芪食疗（2岁以上，少量3-5g起） | 反复感冒、咳嗽迁延 | 过度运动、过食寒凉 |
| **阴虚质** | 面红颧赤、手足心热、盗汗、大便干、舌红少苔、烦躁 | 滋阴润燥：百合粥/银耳羹/梨水/莲子百合粥；忌辛温燥热 | 便秘、夜啼、低热 | 辛燥（辣椒/羊肉/榴莲）、过暖 |

> 📝 **体质不是不变的**——0-3岁体质会随喂养和疾病变化。脾虚质→健脾→可能转为平和；平和质→长期过食肥甘→可能转为湿热。体质辨识是指导调护方向，不是贴标签。

**体质辨识自测（家长初筛）**——勾选最符合孩子日常表现的项目，勾最多的那行=最可能的体质：

| 问题 | 平和质 | 脾虚质 | 湿热质 | 气虚质 | 阴虚质 |
|------|--------|--------|--------|--------|--------|
| 面色 | 红润 | 萎黄 | 油垢 | 苍白 | 颧红 |
| 食欲 | 正常 | 时好时差 | 偏旺盛但消化差 | 差 | 偏差 |
| 大便 | 成形/日1次 | 不成形/便溏 | 黏臭/不畅 | 偏软 | 干硬 |
| 睡眠 | 安稳 | 翻来覆去 | 睡不安 | 易醒 | 盗汗/烦躁 |
| 出汗 | 正常 | 偶尔多 | 头汗多 | 自汗（白天动则汗） | 盗汗（夜间汗） |
| 皮肤 | 少病 | 偶尔湿疹 | 湿疹反复 | 偏白 | 偏干 |
| 性格 | 活泼 | 安静/胆小 | 急躁 | 懒动 | 烦躁 |
| 最易 | 少病 | 积食/腹泻 | 湿疹/感染 | 反复感冒 | 便秘/夜啼 |

> ⚠️ 此表仅供家长初步了解→不替代医生辨证→如孩子有明显不适→须就医→医生四诊合参→辨证更准确。

> ⚠️ **体质辨识不替代医生诊断**——以上为家长日常调护参考。如孩子有明显不适，须就医辨证→不可自行对号入座用药。

## 第七部分 中医如何看待疫苗

> 这是家长常问的问题，必须正面回答，不能含糊。

### 核心立场

**中医不反对疫苗。** 理由如下：

| 论据 | 说明 |
|------|------|
| **"治未病"思想** | 中医最高原则"上工治未病"（《素问·四气调神大论》）→疫苗=最直接的"治未病"→预防优于治疗 |
| **种痘法的历史** | 中国明代已有"人痘接种法"→是免疫学的先驱→疫苗是此理念的现代化 |
| **正气与卫气** | 中医认为"正气存内，邪不可干"（《素问·刺法论》）→疫苗=激发卫气（抗体）→正是"扶正祛邪" |

### 家长常见疑问

| 疑问 | 回答 |
|------|------|
| 接种后发热正常吗？ | 正常→疫苗=小量邪气激发正气→正邪交争→轻微发热=免疫反应→一般1-2天自退→多饮温水→物理降温 |
| 接种后可以中医调护吗？ | 可以→接种当天不做推拿→次日可恢复正常保健推拿 |
| 接种后食欲下降正常吗？ | 正常→正气集中抗邪→脾气暂时减弱→1-2天恢复→饮食清淡即可 |
| 中医能替代疫苗吗？ | **不能**——中医调护可增强体质→但无法提供针对特定病原的特异性免疫→不可替代疫苗 |

## 第八部分 0-3岁发育里程碑与中医调护对应

> 📝 **里程碑有正常范围，个体差异大**。下表为平均值，提前或延后1-2月属正常。但**严重落后须就医**。

| 月龄 | 运动发育 | 中医对应 | 调护要点 |
|------|----------|----------|----------|
| 2月 | 俯卧抬头 | 肝主筋→颈肌力量=筋力初显 | 多趴→练颈背肌→肝气条达 |
| 4月 | 翻身 | 肝筋+脾气→全身协调 | 多让自由活动→不总抱着→气行则力生 |
| 6月 | 独坐 | 脾主肌肉→腰背肌力=脾气 | 坐位练习→健脾助肌 |
| 8月 | 爬行 | 肝筋+脾肌+肾骨→协调运动 | **爬行极重要**→不急着走→爬够再走→四肢协调+感统发育 |
| 12月 | 独站/扶走 | 肾主骨→骨质密度=肾气充盛 | 不过早练走→骨骼未坚→O型腿风险 |
| 18月 | 独走稳 | 肾气渐充 | 适当户外活动→日光→助钙吸收→壮骨 |
| 24月 | 跑/跳 | 肝筋柔韧+肾骨坚固 | 脾胃好→气血足→运动发育自然跟上 |
| 36月 | 单脚站/上下楼梯 | 肝肾协调+脾气充沛 | 全面运动→不偏废 |

> ⚠️ **须就医的发育落后信号**：

| 信号 | 月龄 | 可能提示 |
|------|------|----------|
| 不会抬头 | 4月 | 神经/肌肉问题 |
| 不会翻身+身体僵硬或松软 | 6月 | 高/低肌张力→脑瘫/神经损伤可能 |
| 6月不能追视/追听/对呼唤无反应 | 6月 | 视力/听力/发育障碍 |
| 不会独坐 | 8月 | 神经/肌肉问题 |
| 不会扶站 | 12月 | 骨骼/神经问题 |
| 不会独走 | 18月 | 神经/肌肉问题 |
| 不会说单字 | 18月 | 语言/听力发育问题 |
| 不会说短语 | 30月 | 语言发育问题 |

> 📝 发育落后≠智力问题→很多是营养/环境因素→早发现→早干预→预后好。

## 第九部分 0-3岁急症红灯

> ⚠️ **以下任何一条出现，必须立即就医或拨打120，不可在家观察等待。** 婴儿变化极快——按小时计，不是按天计。

### 高热惊厥

| 项目 | 内容 |
|------|------|
| 表现 | 体温骤升时全身抽搐、两眼上翻、牙关紧闭、口唇发青、四肢僵直或抽动 |
| 好发年龄 | 6月-5岁，高峰1-3岁 |
| 原因 | 小儿肝常有余+热极生风→高热→肝风内动→惊厥 |

**现场处理（家长必须知道）**：

| 做 | 不做 | 原因 |
|----|------|------|
| 侧卧/侧头 | ❌ 不塞任何东西进嘴 | 塞东西→损伤牙齿/阻塞气道→更危险 |
| 解开衣领 | ❌ 不强行按压四肢 | 按压→骨折风险；抽搐会自行停止 |
| 记录发作时间 | ❌ 不掐人中 | 掐人中→无证据表明有效→可能造成额外伤害 |
| 抽搐>5分钟→120 | ❌ 不慌张 | 保持冷静→做对的事 |

> 📝 **多数高热惊厥在1-3分钟内自行停止**，不留后遗症。但首次发作→须就医→排查原因（是单纯热惊还是其他疾病）。

### 脱水

| 信号 | 说明 |
|------|------|
| 哭时无泪 | 泪腺分泌减少→脱水已较重 |
| 口唇干裂 | 黏膜干燥 |
| 尿少/6小时以上无尿 | 肾灌注不足 |
| 前囟凹陷（<18月龄） | 颅内压降低→脱水 |
| 皮肤弹性差 | 捏起皮肤→回弹慢→脱水 |

**处理**：口服补液盐（ORS）→少量多次→不能喝→急诊→可能需静脉补液。

### 呼吸急促

| 年龄 | 呼吸频率危险值 | 伴随危险信号 |
|------|----------------|-------------|
| <2月 | >60次/分 | 鼻翼扇动、三凹征（吸气时胸骨上窝/锁骨上窝/肋间凹陷） |
| 2-12月 | >50次/分 | 同上 |
| 1-3岁 | >40次/分 | 同上 |

**呼吸急促+三凹征→肺炎/毛细支气管炎→紧急就医。**

**三凹征是什么？——通俗解释**：

"三凹"=吸气时三个地方凹进去——

| 凹陷位置 | 通俗说法 | 说明 |
|----------|----------|------|
| 胸骨上窝 | 脖子正下方→锁骨中间→吸气时凹进去 | 最容易看到 |
| 锁骨上窝 | 锁骨上方→脖子两侧→吸气时凹进去 | — |
| 肋间隙 | 肋骨之间的缝隙→吸气时凹进去 | 呼吸极度费力时才出现→已较重 |

> 📝 **为什么凹进去？**→正常呼吸→空气顺畅进入→不费力→看不出凹陷。如果气道狭窄/肺部病变→空气进不去→婴儿拼命用力吸→胸腔负压增大→把软的地方"吸凹了"→三凹征=呼吸极度费力的信号→必须就医。

**如何数呼吸**：

| 步骤 | 方法 |
|------|------|
| 时机 | 婴儿安静/睡眠时→不哭不闹→刚运动后数不准（偏快） |
| 方法 | 看胸部或腹部起伏→一起一伏=1次呼吸 |
| 计时 | 数完整60秒→不是数15秒乘4（误差大） |
| 判断 | <2月>60次/分；2-12月>50次/分；1-3岁>40次/分→呼吸急促→就医 |

### 其他急症速查

| 急症 | 信号 | 处理 |
|------|------|------|
| **<3月龄任何发热** | 腋温≥38°C | **立即就医**——不可自行退烧→须排查严重感染 |
| **精神萎靡** | 不管体温多少→叫不醒→反应迟钝→眼神呆滞 | **紧急就医**——比高热更危险 |
| **误吸/窒息** | 突然不能哭/咳嗽/面色青紫 | **婴儿海姆立克**（详见下方步骤） |
| **持续呕吐** | 无法进食水+尿少+精神差 | 就医→防脱水 |
| **血便** | 大便带血（鲜红/暗红/黑色） | 就医→排查肠套叠/过敏/肛裂 |
| **抽搐无热** | 不发热但抽搐 | 紧急就医→排查癫痫/电解质紊乱/颅内病变 |
| **皮疹+发热+精神差** | 不只是普通湿疹 | 紧急就医→排查脑膜炎/川崎病等 |

**"不可误判"对照表——危险信号常被误认为正常现象**：

> ⚠️ 家长最容易犯的错不是"不知道急症信号"，而是"把急症信号当成正常现象"。以下每一条都是临床中真实发生过的误判案例。

| 危险信号 | 常被误判为 | 为什么不一样 | 正确做法 |
|----------|-----------|-------------|----------|
| 持续尖叫+腹部硬如石 | "普通二月闹/肠绞痛" | 肠绞痛可安抚→持续尖叫无法安抚+腹硬=肠套叠/肠梗阻可能 | **立即就医**→不可继续观察 |
| 喷射性呕吐+黄绿色/咖啡渣 | "普通吐奶/溢奶" | 溢奶=顺嘴角流出→喷射=有力喷出→黄绿=胆汁→咖啡渣=出血 | **紧急就医**→排查肠梗阻/消化道出血 |
| 发热>38.5°C持续>2天 | "出牙发热" | 出牙不会引起发热（AAP/ADA立场）→任何发热须先排查感染 | **就医**→不归因于出牙 |
| 嗜睡叫不醒+拒奶 | "犯困闹觉" | 困了能被唤醒→嗜睡=无法唤醒+不吃→严重感染/代谢问题 | **紧急就医** |
| 首月体重增长<500g | "长得慢/母乳不够" | 首月应增600-1000g→<500g=喂养不足/疾病→不正常 | **就医评估**→排查喂养问题/疾病 |
| 黄疸>14天不退（足月儿） | "生理性黄疸还没退" | 生理性黄疸7-14天消退→超14天=病理性→排查胆道/感染/甲低 | **就医**→查胆红素+病因 |
| 6月不会翻身+身体僵硬 | "大运动慢/胆子小" | 6月不会翻身+肌张力高→脑瘫/神经损伤可能 | **就医**→发育评估+神经筛查 |
| 呼吸急促>60次/分+呻吟 | "鼻子堵了" | 鼻塞呼吸不影响频率→呼吸>60次/分+呻吟=肺炎/心衰可能 | **紧急就医** |

**婴儿海姆立克急救法（0-1岁）——异物卡喉窒息**：

> ⚠️ **1岁以上儿童和成人**用腹部冲击法，**0-1岁婴儿绝不能用腹部冲击法**→肝脏损伤风险→必须用以下拍背压胸法。

**识别窒息**：婴儿吃食物/玩小物件后→突然不能哭、不能咳嗽、不能发声→面色发红→迅速转青紫→抓住喉咙→无法呼吸

**操作步骤（5+5交替法）**：

| 步骤 | 操作 | 要点 |
|------|------|------|
| ①拍背5次 | 施救者坐/跪→前臂放在大腿上→婴儿面朝下趴在前臂上→头低于胸→用手托住婴儿下颌和面颊→另一手掌根在婴儿两肩胛骨之间用力拍5次 | 每次拍击须有力→目的=利用气流将异物冲出→拍后检查异物是否排出→排出→停止→未排出→继续② |
| ②压胸5次 | 拍背5次无效→翻转婴儿→面朝上躺在另一前臂上→仍头低于胸→用两指（食指+中指）放在婴儿两乳头连线下方一横指处→快速按压5次→深度约4cm | 按压须快速有力→类似CPR按压但位置略低→按压后检查异物→可见→小心取出→不可盲目掏→可能推更深 |
| ③重复 | 拍背5次→压胸5次→交替进行→直到异物排出或婴儿失去意识 | — |
| ④失去意识 | 婴儿失去意识→停止拍背压胸→开始婴儿CPR（30次胸外按压→2次人工呼吸）→每次人工呼吸前检查口腔→可见异物→取出→不可盲目掏→拨打120 | — |

> ⚠️ **关键要点**：①婴儿头始终低于胸部→利用重力②不可盲目用手指掏异物→可能推更深③婴儿能哭/咳嗽→说明气道未完全阻塞→不要做海姆立克→鼓励咳嗽→密切观察④异物取出后仍须就医检查→可能有气道损伤⑤预防>急救：不给3岁以下整粒坚果/葡萄/圣女果（须切四瓣）/热狗（须纵切）/硬糖/果冻

### 肠套叠——0-2岁最危险的急腹症

> 肠套叠=一段肠子套入相邻肠段→肠梗阻→肠缺血→肠坏死→6-12月男婴高发→家长必须认识。

| 典型四联征 | 表现 | 说明 |
|------------|------|------|
| ①阵发性哭闹 | 突然剧烈哭叫→面色苍白→蜷腿→持续10-20分钟→然后安静或入睡→隔数十分钟再发 | 最具特征性→不是持续哭→是"一阵一阵"→家长常说"一会儿好一会儿又哭" |
| ②呕吐 | 早期吐食物→晚期吐胆汁（黄绿色） | — |
| ③果酱样血便 | 大便暗红+黏液→像果酱 | 出现较晚→约6-12小时后→不能等出现血便才就诊 |
| ④腹部腊肠样包块 | 右上腹可触及条索状包块 | 须医生触诊→家长不一定摸到 |

> ⚠️ **肠套叠处理**：出现上述表现→**立即就医**→不可等待→不做任何家庭处理→越早就诊→空气灌肠复位成功率越高→>48小时→肠坏死→须手术→甚至危及生命。

### 高热惊厥后观察要点

> 惊厥停止≠万事大吉→须密切观察24小时。

| 观察项 | 正常 | 异常（须复诊） |
|--------|------|---------------|
| 意识 | 惊厥后嗜睡1-2小时→之后清醒→精神恢复 | 嗜睡>2小时→叫不醒→意识模糊 |
| 运动 | 四肢活动自如→爬/抓/玩 | 一侧肢体无力→异常姿势→走路不稳 |
| 体温 | 逐步下降 | 再次高热→或持续>39°C不降 |
| 呕吐 | 无呕吐→或仅1次 | 反复呕吐 |
| 精神 | 恢复后精神好→玩→笑 | 烦躁/呆滞/不认人 |

> 📝 **首次高热惊厥→必须就医**→排查原因（单纯热惊还是脑炎/脑膜炎等）。单纯热惊→预后好→不留后遗症→但须医生确认→不自行判断。

## 第十部分 节点调护——满月/百天/半岁/一岁/两岁/三岁

| 节点 | 中医意义 | 调护重点 | 常见问题 |
|------|----------|----------|----------|
| **满月** | 脾胃初醒→从纯乳到接受外界刺激 | 仍以母乳为主；注意脐部是否完全愈合；开始观察面色/大便/睡眠规律 | 溢奶、夜啼、脐部渗液 |
| **百天（3月）** | 肝气渐旺→能抬头→笑→社交开始 | 多互动→情志舒畅→肝气疏泄；注意肠绞痛是否消退 | 肠绞痛（高峰期2-3月） |
| **半岁（6月）** | 脾胃"练兵"开始→辅食添加 | 严格按顺序添加；密切观察消化反应；开始捏脊保健 | 辅食不耐受、便秘/腹泻交替 |
| **一岁** | 脾胃功能初具→从奶过渡到食 | 逐步以饭为主、奶为辅；保护脾胃→不追喂不强迫；1岁体检 | 厌食、断奶时机 |
| **两岁** | 脾气渐旺→自主进食→"第一反抗期" | 允许自主→不追喂→建立良好饮食习惯；此时惯出追喂→3岁更难改 | 挑食、拒食 |
| **三岁** | 脾胃功能基本成熟→可接近成人饮食 | 仍忌寒凉暴食；体质基本定型→针对性调补；3岁体检 | 便秘、反复感冒 |

> 📝 **断奶时机**：WHO建议母乳喂养至2岁。但实际断奶时间因人而异——核心原则：**不突然断、不在生病时断、不在夏季断**。逐步减少哺乳次数→先减白天→再减夜间→最后减睡前→自然过渡。

### 新生儿行政事务清单（满月前须完成）

> 生完娃手忙脚乱→行政事务最易遗漏→逾期补办更麻烦→列一张清单逐项打钩。

| 事项 | 时间节点 | 所需材料 | 注意 |
|------|----------|----------|------|

### 一、新生儿（0-1月）日常护理

#### 1.1 脐带护理

脐带是新生儿护理的第一课。脐带残端一般在出生后7-14天自然脱落，脱落前须保持干燥清洁。

| 步骤 | 做法 | 原因 |
|------|------|------|
| 保持清洁干燥 | 洗澡后用干净毛巾轻轻擦干脐部→保持干燥即可→**不常规使用酒精/碘伏消毒** | WHO 2013、AAP 2022均已更新为自然干燥法（dry cord care）→研究表明酒精不降低感染率反延迟脱落（平均延迟2-3天）→碘伏可抑制甲状腺功能 |
| 纸尿裤反折 | 纸尿裤上缘反折→不覆盖脐部 | 覆盖→摩擦+潮湿→愈合慢 |
| 观察脐周 | 正常=脐周皮肤颜色正常、无红肿、无渗液 | — |
| 脐带脱落后 | 脐窝可有少量血丝或淡黄渗液→保持干燥→约2-3天完全愈合 | 正常脱落过程 |

⚠️ **必须就医的脐部信号**：

| 信号 | 说明 |
|------|------|
| 脐周红肿、皮肤发红 | 脐炎→须医生处理→可能需抗生素 |
| 脐部有脓性分泌物（黄绿色、有臭味） | 感染→此时医生指导下使用消毒剂 |
| 脐部出血不止（浸透纱布） | 血管未闭合→须处理 |
| 脐带超过4周未脱落 | 须排查脐茸/脐肠瘘等 |
| 脐部有肉芽组织（红色小肿物） | 脐肉芽肿→须医生用硝酸银烧灼 |

> 📝 **脐带可以碰水**——洗澡后轻轻擦干脐部即可→关键是保持干燥。如果所在地区/医院仍建议酒精消毒→遵医嘱也可→但国际指南已不再将酒精消毒作为常规推荐。

> 📝 **自然干燥法依据**：WHO 2013年《脐带护理指南》推荐自然干燥法；Zupan J, et al. Cochrane Database Syst Rev 2004——酒精组vs自然干燥组感染率无统计学差异，酒精组脱落时间显著延长。

#### 1.2 洗澡

| 项目 | 新生儿（脐带未脱落） | 脐带脱落后 |
|------|---------------------|-----------|
| 方式 | 可盆浴→洗后轻轻擦干脐部即可；如家长更放心用擦浴也可以 | 盆浴 |
| 频率 | 每2-3天一次（不必天天洗） | 每1-2天一次；夏季可每日 |
| 水温 | 36-37°C（手腕内侧试温→温热不烫） | 同左 |
| 室温 | 26-28°C（关窗关门→防穿堂风） | 同左 |
| 时长 | 5-8分钟→不宜过长→着凉 | 5-10分钟→不宜过长→着凉 |
| 用什么 | 温水即可→不必用沐浴露 | 温水→每周用1-2次婴儿无香沐浴露→不必每次都用 |
| 洗头 | 棉球蘸温水轻擦→不用洗发水 | 温水冲洗→每周1-2次婴儿无香洗发水 |
| 洗后 | 大毛巾包裹→轻按吸干（不搓）→脐部单独擦干→全身涂润肤霜 | 同左 |

**擦浴步骤**（新生儿脐带未脱落前）：

```
1. 准备好所有物品→大毛巾、棉球、温水盆、干净衣物、尿布、润肤霜
2. 先洗脸部→棉球蘸温水→从内眼角向外擦拭→每眼用新棉球→鼻子→嘴巴→耳朵外廓
3. 再洗头→一手托头→一手用温水棉球轻擦→擦干
4. 擦洗身体→上半身脱衣→温水毛巾擦→擦干→穿衣→再擦下半身
5. 脐部不碰水→脐周用酒精棉签消毒
6. 全身涂润肤霜→特别注意皮肤皱褶处（脖子、腋下、大腿根）
```

> ⚠️ **洗澡安全**：任何时候不离开婴儿→一手始终托住→即使盆浴水很浅（5cm）→婴儿也可能溺水→**绝不离开半步**。

#### 1.3 睡眠

**睡眠姿势——必须仰睡**：

| 姿势 | 是否安全 | 原因 |
|------|----------|------|
| 仰睡 | ✅ **唯一安全姿势** | 俯卧→口鼻可能被堵→新生儿抬头能力不足→窒息→婴儿猝死综合征（SIDS）风险增高 |
| 侧睡 | ❌ 不推荐 | 容易翻成俯卧→不安全 |
| 趴睡 | ❌ **禁止** | SIDS最高风险因素 |

> 📝 **"仰睡让后脑勺变扁"不是放趴的理由**——轻微偏头可在清醒时多趴（tummy time）→自然矫正→严重偏头就医。**安全永远大于头型。**

**睡眠时长参考**：

| 月龄 | 每日总睡眠 | 夜间睡眠 | 白天小睡 | 说明 |
|------|-----------|----------|----------|------|
| 0-1月 | 16-18小时 | 8-9小时（分段） | 7-8小时（4-5次） | 昼夜颠倒正常→逐步建立昼夜节律 |
| 1-3月 | 14-16小时 | 9-10小时 | 5-6小时（3-4次） | 夜间渐长→白天渐短 |
| 3-6月 | 12-15小时 | 9-10小时 | 3-5小时（2-3次） | 部分婴儿可睡整觉（6小时） |
| 6-12月 | 12-14小时 | 10-11小时 | 2-3小时（2次） | 多数可睡整觉 |

**建立昼夜节律**（0-1月就要开始）：

| 做法 | 具体操作 | 原理 |
|------|----------|------|
| 白天不拉窗帘 | 正常光线→正常声音→不刻意安静 | 光线→褪黑素分泌受抑制→白天=清醒 |
| 夜间保持暗静 | 小夜灯即可→不大灯→不说话→不逗玩 | 暗→褪黑素分泌→夜间=睡眠 |
| 区分昼夜喂养 | 白天喂奶→说话互动；夜间喂奶→安静→不逗 | 条件反射→夜间=安静=睡觉 |

**睡眠安全清单**：

| 项目 | 正确做法 | 错误做法 |
|------|----------|----------|
| 床面 | 硬床垫+床单→无杂物 | ❌ 软床垫/枕头/被子/毛绒玩具→窒息 |
| 盖被 | 睡袋（最安全）或薄被盖到胸部以下→手臂露出 | ❌ 被子盖过肩→滑到脸上→窒息 |
| 同房不同床 | 婴儿睡在父母旁边的小床→同房不同床→至少6月→理想至1年 | ❌ 同床→大人翻身→压迫→窒息风险 |
| 枕头 | 1岁前不需要枕头 | ❌ 给枕头→颈部弯曲→气道不畅→窒息 |
| 温度 | 室温22-26°C→婴儿后颈温热无汗=合适 | ❌ 捂太多→过热→SIDS风险↑ |

#### 1.4 哭闹应对——婴儿的"语言"

> 📝 婴儿哭=唯一的沟通方式→不是"不好带"→是在告诉你需求。0-3月婴儿平均每天哭1-2小时→这是正常的→不是你做错了什么。

**第一步：排除法判断哭因**

按紧急程度和常见程度排序，逐一排查：

| 排序 | 可能原因 | 哭声特征+伴随信号 | 确认方法 | 处理 |
|------|----------|-------------------|----------|------|
| **1** | **饿了** | 短促有节奏的哭→张嘴转头觅食→手往嘴里塞→嘴碰到东西就吸 | 距上次喂奶>1.5-2小时？→大概率饿了 | 喂奶→一般3-5分钟内安静=判断正确 |
| **2** | **尿布湿了/拉了** | 突然大哭→扭动身体→烦躁→有时放屁 | 打开尿布检查 | 更换尿布→温水擦洗→涂护臀霜→换完一般就安静了 |
| **3** | **困了（闹觉）** | 打哈欠+揉眼+烦躁哼唧→哭声渐强→越逗越哭→不愿对视 | 已清醒>1.5-2小时？→大概率困了 | 停止逗玩→安静暗环境→轻拍哄睡→不继续刺激 |
| **4** | **胀气/需要拍嗝** | 吃奶后哭→身体蜷缩→肚子鼓→脸憋红→放屁后缓解 | 距上次喂奶<30分钟+肚子鼓？ | 拍嗝（见上方拍嗝三法）→或飞机抱→排气 |
| **5** | **冷了/热了** | 哭声持续→无其他明显原因 | 摸后颈→凉=冷→汗=热 | 加减衣物→调整室温 |
| **6** | **肠绞痛（3周-3月）** | 傍晚定时哭闹→持续>2小时→脸红腿蜷→排气后稍缓解 | 符合"三三法则"→见第二部分 | 飞机抱+白噪音+揉腹（见第二部分肠绞痛） |
| **7** | **不舒服/生病** | 哭声尖锐异样→持续不停→伴发热/呕吐/腹泻/皮疹 | 量体温→检查全身 | 有异常→就医 |
| **8** | **需要抱/求关注** | 哭声起伏→你走开就哭→你来看就停→眼神跟随你 | 排除以上所有原因→检查后无异常 | 抱起来安抚→婴儿需要安全感→不是"惯坏了" |

> 📝 **关键原则：先解决生理需求，再安抚情绪。** 饿了不喂只哄→越哄越哭；尿布满了不换只抱→屁股越来越痛。**排查顺序=处理顺序**。

**不同月龄哭闹的特点**：

| 月龄 | 哭闹特点 | 最常见原因 | 家长心态 |
|------|----------|-----------|----------|
| 0-1月 | 哭声尖锐→频率高→昼夜都哭 | 饿了/尿布/冷热/肠绞痛初期 | 最崩溃期→但请记住→这是阶段性的→会过去 |
| 1-3月 | 哭闹达到高峰（6-8周最高） | 肠绞痛→黄昏闹 | 高峰期→每天傍晚定时哭→不是你做得不好 |
| 3-6月 | 哭闹明显减少→开始有规律 | 困了闹觉→长牙期（4月起可能开始） | 好转期→婴儿越来越能表达 |
| 6-12月 | 哭声更有目的性→指向明确 | 分离焦虑（8月左右）→长牙→困了 | 能听懂更多→能沟通→更容易应对 |

**哭闹时的"读婴术"——观察身体语言**：

| 身体信号 | 含义 | 处理 |
|----------|------|------|
| 张嘴转头→手往嘴里塞 | 饿了→觅食反射 | 喂奶 |
| 打哈欠→揉眼→不愿对视 | 困了→需要入睡 | 减少刺激→哄睡 |
| 身体蜷缩→腿蜷向腹部→脸红 | 腹痛/胀气 | 拍嗝/飞机抱/揉腹 |
| 身体僵硬→弓背 | 不舒服/疼痛 | 检查全身→有无头发缠绕手指/脚趾（发丝止血带）→有无红肿 |
| 抓耳朵 | 可能耳朵痒/长牙/中耳炎 | 检查耳道→伴发热→就医排查中耳炎 |
| 揪头发/抓脸 | 烦躁/过度刺激 | 减少刺激→安静环境→轻拍 |
| 看着你→你走就哭→你来就笑 | 分离焦虑（6月+） | 正常发育阶段→不嫌弃→安抚→逐步适应 |

> ⚠️ **发丝止血带**——这是一个容易被忽视的急症：婴儿手指/脚趾被脱落的头发缠绕→越缠越紧→阻断血液循环→指端肿胀发紫→不及时处理→坏死。**婴儿无故持续哭闹→检查每根手指脚趾→有无细线/头发缠绕→有→小心剪断→取不下→就医。**

**通用安抚法（5S法）**：

| 步骤 | 做法 | 原理 | 注意 |
|------|------|------|------|
| Swaddle（包裹） | 见下方详细步骤 | 模拟子宫环境→安全感→减少惊跳反射 | 3月后婴儿会翻身→不包裹→翻过去手被绑→窒息 |
| Side/Stomach（侧/俯卧抱） | 抱时让婴儿侧卧或俯卧在大人胸前 | 安抚→**但放下时必须仰睡** | ⚠️ 抱着时侧/俯卧OK→放下必须仰睡→SIDS预防 |
| Shush（嘘声） | 嘘嘘声→贴近耳边→音量盖过哭声 | 模拟子宫血流声→白噪音效果 | 也可用白噪音APP→海浪声/吹风机声/吸尘器声 |
| Swing（轻摇） | 坐着→婴儿靠胸前→轻摇→频率约1-2次/秒 | 模拟子宫中的晃动 | ⚠️ **绝不剧烈摇晃**→婴儿颈部肌肉无力→脑组织在颅骨内晃动→摇婴综合征→脑出血→死亡/永久损伤 |
| Suck（吸吮） | 安抚奶嘴/洗净的手指 | 吸吮=最原始的安抚反射 | 安抚奶嘴：母乳建立后（3-4周）再引入→不影响吸吮；睡着后奶嘴掉出→不塞回；1岁后逐步减少→2岁前戒除 |

**Swaddle（包裹）详细步骤**：

```
材料：薄棉包被（107cm×107cm菱形铺开）

步骤1：将包被菱形铺开→顶角朝上→将顶角向下折约15cm
步骤2：将婴儿放在包被上→肩线与折线齐平→头在折线上方
步骤3：将婴儿右臂自然放在身体旁→拉起左侧包被→裹过身体→塞入右侧身下→手臂被固定
步骤4：将底部包被向上折→盖住腿脚→脚可以自由弯曲→不绑直→把多余部分塞入折缝
步骤5：将婴儿左臂自然放在身体旁→拉起右侧包被→裹过身体→塞入左侧身下→完成

松紧判断：
✅ 胸口能插入2-3指=合适
✅ 髋部和腿可以自由弯曲和活动=正确
❌ 包太紧→腿被绑直→髋关节发育不良风险
❌ 3月后仍包裹→婴儿会翻身→窒息风险
```

> ⚠️ **绝对不可剧烈摇晃婴儿**——不管多崩溃多烦躁。摇婴综合征（SBS）是0-1岁可致命的虐待→婴儿头大身小+颈部无力→剧烈摇晃→脑在颅骨内撞击→出血→死亡或永久脑损伤。**哭得受不了→把婴儿安全放在小床上→离开房间→深呼吸→5分钟→再回来**→比摇晃安全一万倍。

**当所有方法都无效时**——宝妈自救指南：

```
1. 深呼吸→告诉自己"这不是我的错"→婴儿哭不会哭坏→但你的情绪会传染
2. 把婴儿安全放在小床上→仰睡→离开房间5分钟→喝口水→深呼吸
3. 5分钟后回来→重新尝试安抚
4. 如果持续无法安抚+有异常信号→就医
5. 不要因为哭闹而摇晃/拍打/捂住婴儿的嘴→这些行为可能致命
6. 如果你自己感到崩溃→打电话给家人/朋友→请人来替你→你不丢人
```

#### 1.5 如何抱婴儿——0-3月最关键

> 新生儿头大身小+颈部肌肉无力→头完全靠大人支撑→抱的姿势不对→伤颈椎→必须学会正确抱法。

**核心原则：一手托头+一手托臀——任何时候都不松手**

**抱法一：摇篮抱（最常用，适合喂奶和安抚）**

```
1. 一手滑入婴儿头颈下方→手掌托住头和颈
2. 另一手滑入婴儿臀部和腿下方→托住臀部
3. 两手同时用力→将婴儿轻轻抱起
4. 让婴儿头枕在你肘弯处→身体躺在你的前臂上→像躺摇篮
5. 婴儿身体贴近你的胸→能听到你的心跳→最有安全感
```

**抱法二：竖抱/肩扛抱（适合拍嗝）**

```
1. 一手托住婴儿头颈→一手托住臀部→先抱起
2. 将婴儿慢慢竖起→让婴儿下巴靠在你肩头
3. 一手从臀部改为托住婴儿腰背部→另一手仍然托住头颈
4. 婴儿身体贴着你的胸→面朝外或面朝你都可以
5. ⚠️ 竖抱时婴儿头不能后仰→头颈必须始终有支撑
```

> 📝 **0-3月竖抱时间不宜过长**——每次拍嗝竖抱10-20分钟即可→长时间竖抱→脊柱受压→婴儿骨骼软→不宜久竖。3月后颈部力量增强→可逐步延长竖抱时间。

**抱法三：飞机抱（适合肠绞痛/胀气）**

```
1. 让婴儿俯卧在你的前臂上→婴儿脸朝外
2. 婴儿胸部贴着你的手掌→腿搭在你的手臂两侧
3. 另一手轻拍婴儿背部→或轻轻摇晃
4. ⚠️ 确保婴儿口鼻不被你的手臂堵住→随时观察呼吸
```

**从床上抱起婴儿的正确步骤**：

| 步骤 | 做法 |
|------|------|
| 1 | 先对婴儿说话→轻触→让婴儿知道你来了→不被突然抱起吓到 |
| 2 | 一手从侧面滑入头颈下方→手掌托住整个头部 |
| 3 | 另一手滑入臀部下方 |
| 4 | 两手同时缓缓用力→平稳抱起→不猛提 |
| 5 | 抱起后→让婴儿身体贴近你胸→头部有支撑 |

**放下婴儿的正确步骤**：

| 步骤 | 做法 |
|------|------|
| 1 | 一手托住头颈→一手托住臀部→降低身体 |
| 2 | 先让臀部着床→再放下腰背→最后放下头部 |
| 3 | 抽出托头的手→保持轻按→防止婴儿惊跳→慢慢松开 |
| 4 | ⚠️ 一定是先放屁股后放头→先放头→后脑勺先着床→颈部后仰→伤颈椎 |

**抱婴儿的禁忌**：

| 禁忌 | 原因 |
|------|------|
| 不托头颈直接抱 | 头无支撑→后仰→伤颈椎 |
| 单手提着婴儿手腕/胳膊 | 关节脱位风险 |
| 剧烈摇晃（包括上下颠、左右甩） | 摇婴综合征→脑出血→致命 |
| 抱着婴儿弯腰捡东西 | 婴儿可能滑落→先放下婴儿→再捡 |
| 长时间单手抱 | 0-3月必须双手→婴儿太软→单手不稳 |

#### 1.6 穿衣判断——摸后颈

| 判断部位 | 摸后颈（不是手脚！） |
|----------|----------------------|
| 温热无汗 | ✅ 正好 |
| 发凉 | 少了→加一层 |
| 出汗 | 多了→减一层 |

> 📝 **婴儿手脚偏凉是正常的**——末梢循环未发育完善→手脚凉≠冷→摸后颈才准确。很多家长看手脚凉就加衣→捂太多→过热→SIDS风险↑。

**穿衣原则**：

| 原则 | 做法 | 原因 |
|------|------|------|
| 比大人多一层 | 大人穿短袖→婴儿穿短袖+薄包被 | 婴儿体表面积大→散热快 |
| 分层穿衣 | 薄衣多层→便于加减 | 温差变化快→方便调节 |
| 纯棉为主 | 选A类婴幼儿纺织品→无甲醛无荧光剂 | 婴儿皮肤薄→敏感→化学物质易过敏 |
| 不穿带绳/带珠 | 避免绳索绕颈、珠子脱落吞咽 | 窒息风险 |
| 袜子不24小时穿 | 室内温暖时可不穿→让脚接触地面→促进感知发育 | 光脚不等于"寒从脚起"→室内≠室外 |

#### 1.7 室温与湿度

| 项目 | 适宜范围 | 说明 |
|------|----------|------|
| 室温 | 22-26°C | 夏季可开空调（26-28°C，不直吹婴儿）；冬季取暖→不放暖宝宝/热水袋在婴儿身旁（烫伤+过热） |
| 湿度 | 40-60% | 冬季干燥→加湿器→每天换水+每周清洗→防细菌霉菌；夏季潮湿→除湿或空调除湿模式 |

#### 1.8 黄疸——新生儿最常见问题

> 约60%足月儿、80%早产儿会出现黄疸。家长须会区分生理性vs病理性。

| 鉴别点 | 生理性黄疸（正常） | 病理性黄疸（须就医） |
|--------|-------------------|---------------------|
| 出现时间 | 生后2-3天出现 | 生后24小时内出现→**紧急** |
| 高峰时间 | 第4-5天 | 持续加重不退 |
| 消退时间 | 足月儿7-14天；早产儿3-4周 | 足月儿>2周未退；早产儿>4周未退 |
| 黄疸范围 | 从面部→胸→上肢→逐渐蔓延 | 迅速蔓延至四肢/手足心→**紧急** |
| 精神状态 | 精神好、吃奶好、大便正常 | 精神差、嗜睡、拒奶、大便灰白→**紧急** |

**家庭护理（生理性黄疸）**：

| 方法 | 做法 | 原理 |
|------|------|------|
| 多喂奶 | 每日8-12次→多吃多排→胆红素从便排出 | 胆红素→肠道→随便排出→吃不够→排不出→黄疸加重 |
| 适当晒太阳 | 室内窗边→隔着玻璃→露出四肢→每次10-15分钟→每日2-3次→**避开10am-4pm强光** | 阳光中蓝光→帮助胆红素分解；⚠️ 不直射→不晒脸→防紫外线伤眼和皮肤 |
| 观察黄疸范围 | 从额头往下按→皮肤泛白后看颜色→逐渐向下蔓延=加重 | 粗略判断黄疸程度 |

> ⚠️ **黄疸不能靠"肉眼看"确定严重程度**→须医生用经皮胆红素仪或抽血检测。以下情况必须就医：
> - 24小时内出现黄疸
> - 黄疸迅速蔓延到手心脚心
> - 伴嗜睡/拒奶/发热
> - 2周未退（足月儿）
> - 大便颜色变浅/灰白

> 📝 **中医对黄疸的认识**：黄疸属"胎黄"范畴→《诸病源候论》："小儿在胎，其母脏气有热，熏蒸于胎，至生下小儿，体皆黄，谓之胎疸。"→胎黄分阳黄（湿热→黄色鲜明→茵陈蒿汤方向）和阴黄（寒湿→黄色晦暗→茵陈理中汤方向）。但新生儿黄疸须先排除病理性→**病理性黄疸必须西医治疗（光疗）→不可自行中药退黄→延误可致胆红素脑病→不可逆损伤**。

#### 1.9 鹅口疮

| 项目 | 内容 |
|------|------|
| 表现 | 口腔内壁、舌面、上颚出现白色乳凝块样斑膜→擦不掉（强擦会出血）→不是奶渍 |
| 原因 | 白色念珠菌感染→婴儿口腔卫生不当/免疫力低/抗生素使用后 |
| 与奶渍区别 | 奶渍=轻轻一擦就掉；鹅口疮=擦不掉+强擦出血 |
| 处理 | 就医→医生开具制霉菌素悬液→涂抹口腔→每日3-4次→用至消失后继续3天→防复发 |
| 预防 | 奶瓶奶嘴每次用后清洗消毒；母乳喂养→母亲乳头保持清洁干燥；不随意用抗生素 |
| ⚠️ | 鹅口疮反复发作→须排查免疫力问题→就医 |

#### 1.10 指甲修剪

| 项目 | 做法 |
|------|------|
| 何时剪 | 婴儿指甲长得快→约每周1次；指甲长了会抓伤自己脸 |
| 怎么剪 | 婴儿熟睡时剪→用婴儿专用圆头指甲剪→沿指甲自然弧度剪→不剪太短→不留尖角 |
| 手脚区别 | 手指甲→按弧度剪；脚趾甲→平剪→不往两侧剪深→防嵌甲 |

#### 1.11 新生儿特殊生理现象——不是病，别慌

> 新生儿有许多看起来"不对"但实际正常的生理现象→了解后不焦虑→不做错误处理。

**马牙/上皮珠**：

| 项目 | 内容 |
|------|------|
| 表现 | 牙龈上或上颚出现白色/黄白色小颗粒→像小米粒→一至数个 |
| 原因 | 牙板上皮残余→角化脱落→属正常生理 |
| 处理 | **不需要任何处理**→数周至数月自行脱落 |
| ⚠️ | **绝对不可挑破/擦破**→口腔细菌多→挑破→感染→严重可致颌骨骨髓炎 |

**乳腺肿大**：

| 项目 | 内容 |
|------|------|
| 表现 | 出生后3-5天→乳房肿大→男女婴均可出现→可挤出少量乳汁样液体 |
| 原因 | 母体雌激素经胎盘传入→出生后激素水平骤降→乳腺暂时反应 |
| 处理 | **不挤压/不揉搓**→2-3周自行消退 |
| ⚠️ | 挤压→感染→新生儿乳腺炎→须抗生素→严重须切开引流 |

**假月经**：

| 项目 | 内容 |
|------|------|
| 表现 | 女婴出生后5-7天→阴道少量血性分泌物→持续1-3天 |
| 原因 | 母体雌激素撤退→子宫内膜脱落出血 |
| 处理 | 正常生理→观察即可→保持会阴清洁 |
| ⚠️ | 出血量多/持续>3天/伴其他异常→须就医排查 |

**头皮血肿/产瘤**：

| 项目 | 内容 |
|------|------|
| 产瘤（先锋头） | 经产道挤压→头皮水肿→出生即有→跨越骨缝→2-3天消退→不需处理 |
| 头皮血肿 | 骨膜下血管破裂→出生后1-2天才明显→**不跨越骨缝**→2周-3月逐渐吸收→不需处理 |
| ⚠️ 共同禁忌 | **不可揉搓/热敷/穿刺抽吸**→揉搓→出血增多；穿刺→感染风险 |
| ⚠️ 就医 | 血肿快速增大/伴呕吐/嗜睡→须排查颅内出血 |

**斜颈识别**：

| 项目 | 内容 |
|------|------|
| 表现 | 婴儿头总是偏向一侧→下巴转向对侧→一侧颈部可触及硬包块（胸锁乳突肌肿块） |
| 原因 | 胸锁乳突肌纤维化→宫内姿势压迫/产伤→多见于臀位产/难产 |
| 发现时机 | 出生后2-4周内→42天体检时医生常规检查 |
| 处理 | 确诊后→医生指导手法牵伸→每日数次→大多数3-6月内恢复；6月后无改善→须评估是否手术 |
| ⚠️ | 不早发现→面部不对称→斜视→脊柱侧弯→早期干预→预后好 |

**发育性髋关节不良（DDH）筛查**：

| 项目 | 内容 |
|------|------|
| 高危因素 | 臀位产/女婴/家族史/合并斜颈/羊水过少 |
| 体征 | 双腿皮纹不对称→一侧腿短→外展受限（换尿布时一侧腿打不开） |
| 筛查 | 42天体检→医生做Ortolani试验/Barlow试验→有疑问→髋关节B超 |
| 处理 | 早发现→吊带固定→3-6月恢复；晚发现>6月→可能需石膏/手术 |
| ⚠️ | **不要把婴儿双腿绑直**（蜡烛包）→髋关节处于伸直内收位→增加DDH风险→正确包裹：腿可自由弯曲外展→"青蛙位" |

#### 1.12 母乳储存（背奶妈妈）

> 职场妈妈需要提前储奶→以下是安全储存标准：

| 储存条件 | 时间 | 说明 |
|----------|------|------|
| 室温（25°C以下） | 4小时 | 尽快使用→不推荐常温久放 |
| 冰箱冷藏（0-4°C） | 72小时至8天 | 放冰箱最内侧→不放门侧（温度不稳）→72小时为安全首选→若冰箱温度稳定≤4°C可延至8天（ABM 2017） |
| 冰箱冷冻室 | 3-6个月 | 独立冷冻室→不开门→6月；普通冷冻→3月 |
| 深冷（-18°C以下） | 6-12个月 | — |

**解冻与使用**：

| 步骤 | 做法 | 不该做 |
|------|------|--------|
| 解冻 | 提前从冷冻放到冷藏→缓慢解冻→解冻后冷藏保存≤24小时用完 | ❌ 微波炉加热→受热不均→烫伤+破坏营养 |
| 温奶 | 隔水温热→40°C左右→手腕内侧试温 | ❌ 煮沸→营养全破坏 |
| 剩奶 | 婴儿喝过后1小时内喝完→喝不完倒掉 | ❌ 再放回冰箱→细菌已混入→变质 |
| 解冻后不可再冻 | 解冻后的母乳不可再冷冻→冷藏≤24小时→室温≤1-2小时 | ❌ 解冻后再次冷冻→细菌繁殖+营养破坏 |
| 分装 | 按每餐量分装（60-120ml/袋）→标注日期 | 一次冷冻太多→解冻后用不完→浪费 |

| 项目 | 说明 |

**坐高铁**：

| 项目 | 说明 |
|------|------|
| 噪音防护 | 长时间高铁噪音→用婴儿降噪耳罩/棉球轻塞→保护听力 |
| 喂奶 | 高铁有母婴室→提前问乘务员位置→或在座位用哺乳巾遮挡 |

**去医院就诊准备**：

| 带什么 | 说明 |
|--------|------|
| 疫苗本/保健手册 | 医生需查看接种记录 |
| 体温记录 | 何时开始发热→最高几度→用了什么退烧药→效果如何 |

**怎么和医生描述病情**：

| 要说清 | 举例 |
|--------|------|
| 什么时候开始的 | "从昨晚8点开始发热" |
| 主要症状 | "发热39度+咳嗽+流黄涕" |
| 变化趋势 | "今天比昨天高了/低了/差不多" |

**打疫苗当天细节**：

| 问题 | 回答 |
|------|------|
| 穿什么 | 宽松短袖/背心→容易露出上臂和左上臂（接种部位）→不穿连体衣→脱起来麻烦 |
| 能不能洗澡 | 接种当天可擦浴→避免浸泡注射部位→次日无发热可正常洗澡→如果洗了→观察注射部位→红肿不加重→没事→不必恐慌 |
| 接种后多久可以走 | 观察30分钟→无过敏反应→离院 |
| 哪些情况暂缓接种 | 发热/急性病/严重湿疹/正在用免疫抑制剂→等康复后再补种 |

#### 2.2 维生素D补充——0-1岁最关键的营养补充

> ⚠️ **这是纯中医视角容易遗漏的刚需**——维生素D不足→钙吸收差→佝偻病→不可逆骨骼变形。

| 项目 | 内容 |
|------|------|
| 补充时机 | **出生后2周内即开始**（不论母乳/配方奶） |
| 每日剂量 | 400IU（国际单位）= 10μg |
| 持续时间 | 至少到2岁→建议持续至青春期 |
| 制剂选择 | 维生素D3滴剂→单成分→不用维A+维D合剂（易维A过量） |
| 母乳喂养儿 | **必须额外补充**——母乳中维D含量极低→无法满足 |
| 配方奶喂养儿 | 需计算→配方奶已含维D→如果每日奶量≥1000ml且配方奶维D含量足够→可能不需额外补→但多数婴儿吃不到1000ml→仍需补充→具体咨询医生 |

> 📝 **中医如何看待维D补充**：维D促进钙吸收→钙=骨→肾主骨→维D=助肾气充养骨骼→与"后天养先天"一致→不矛盾→这是现代营养学对中医"肾常虚"的具体补充手段。

**晒太阳能否替代维D补充？**

| 方式 | 能否替代 | 原因 |
|------|----------|------|
| 日常晒太阳 | **不能完全替代** | 北方冬季日照不足、隔着玻璃无效、婴儿皮肤娇嫩不宜暴晒→维D合成受多种因素影响→不稳定的来源 |
| 维D制剂 | ✅ 可靠来源 | 剂量精确→不受天气/纬度/皮肤颜色影响→是保证维D摄入的首选 |

#### 2.3 补铁——6月后铁储备耗尽

| 项目 | 内容 |
|------|------|
| 为什么需要 | 足月儿出生时储备的铁→4-6月耗尽→6月后必须从食物获取→不及时补充→缺铁性贫血→影响智力发育（不可逆） |
| ⭐ 纯母乳足月儿4月龄预防性补铁 | AAP 2010推荐：纯母乳喂养的足月儿→**4月龄起**预防性补充铁剂1mg/kg/天→直至引入含铁辅食→因母乳铁含量极低→4月后储备耗尽→等6月加辅食已晚2月→期间缺铁可影响神经发育 |
| 6月起补铁食物 | 铁强化米粉/肉泥/肝泥（第一口辅食可选→都是补铁来源）；蛋黄（7-8月加）；红肉末（9-10月加） |
| 何时查血红蛋白 | 6月体检时常规查→如有贫血→医生开具铁剂→不自行补铁 |
| 维C助铁吸收 | 含铁食物+富含维C食物同吃→铁吸收率↑→如：米粉+果泥；肉末+番茄 |
| 早产儿补铁 | 出生后2-4周起→须补铁剂→至1岁→医生指导剂量（早产儿铁储备更低） |

#### 2.4 补钙——一般不需要额外补

| 情况 | 是否需要补钙 | 原因 |
|------|-------------|------|
| 母乳喂养+维D400IU | ❌ 不需要额外补钙 | 母乳钙吸收率高达60%→维D充足→钙够用 |
| 配方奶喂养 | ❌ 不需要 | 配方奶含钙充足 |
| 6月后正常添加辅食 | ❌ 不需要 | 奶+辅食中钙足够 |
| 确诊佝偻病 | ✅ 医生指导下补 | 维D缺乏→钙吸收差→须同时补维D+钙 |

> ⚠️ **"补钙"是0-1岁最大的误区之一**——很多家长给孩子吃钙片→实际缺的不是钙→是维D→维D不足→吃再多钙也吸收不了→**补维D比补钙重要**。

#### 2.5 趴趴时间（Tummy Time）

| 项目 | 内容 |
|------|------|
| 开始时间 | 脐带脱落后→出生后2-3周起 |
| 做法 | 婴儿清醒时→放在硬床面或爬行垫上→俯卧→每日2-3次→每次1-2分钟起→逐步延长 |
| 原理 | 锻炼颈背肌→抬头能力→预防偏头→为翻身/爬行打基础 |
| 中医对应 | 肝主筋→颈肌力量=筋力→趴=练筋→肝气条达 |
| ⚠️ | **必须清醒时趴**→困了就翻回仰睡→趴着睡觉=窒息风险 |

#### 2.6 4月睡眠倒退期

| 项目 | 内容 |
|------|------|
| 原因 | 4月左右婴儿睡眠模式从"婴儿型"转为"成人型"→睡眠周期变短→浅睡比例增加→更容易醒 |
| 表现 | 之前能睡4-5小时→突然每1-2小时醒→夜醒频繁→家长崩溃 |
| 应对 | 这是正常的发育阶段→不是"坏了"→保持原有睡前仪式→不因为夜醒就抱睡/奶睡→耐心→2-4周后度过 |
| ⚠️ | 不要因为睡眠倒退就加辅食/换奶粉→4月加辅食太早（见第三部分）→睡眠问题≠饥饿问题 |

#### 2.7 夜奶减停

| 月龄 | 建议 | 方法 |
|------|------|------|
| 0-3月 | 夜间必须喂→按需 | 婴儿胃小→夜间也需营养 |
| 3-6月 | 逐步减少夜奶次数 | 延长夜间喂奶间隔→先从3小时延到4小时→逐步拉长 |
| 6月+ | 可尝试断夜奶 | 白天吃够+辅食保证→夜间先减1次→用拍哄替代奶哄→逐步过渡 |
| 9-12月 | 多数婴儿可以不吃夜奶 | 如果仍频繁夜醒→排查习惯性夜奶（不是饿→是习惯）→须温柔但坚定地减少 |

> 📝 **如何判断夜醒是饿了还是习惯**：如果上次喂奶间隔>3小时+真吸吮→饿了→喂；如果间隔<2小时+含着不吸→习惯→拍哄→不喂。

#### 2.8 湿疹日常护理细节

| 项目 | 做法 | 原因 |
|------|------|------|
| 洗澡水温 | 32-37°C→偏凉→不热洗 | 热水→血管扩张→瘙痒加重 |
| 沐浴露 | 每周最多1-2次→选无香无皂基→不用碱性肥皂 | 频繁洗去皮脂→皮肤屏障更差 |
| 洗澡时长 | 5-10分钟→速战速决 | 久泡→皮肤水分蒸发→更干 |
| 洗后3分钟内涂润肤霜 | 全身涂抹→湿疹处厚涂→像"糊墙"一样 | 3分钟内=皮肤水分未蒸发→锁水效果最好 |
| 润肤霜用量 | 每周150-200g（全身）→湿疹儿用到250g+ | 用少了=没效果→家长最常犯的错误 |
| 润肤霜选择 | 无香精/无防腐剂的婴儿专用→膏状>乳液（膏状锁水更强） | 乳液含水量高→蒸发后更干 |
| 穿衣 | 纯棉→宽松→不穿羊毛/化纤直接接触皮肤 | 摩擦+闷热→瘙痒 |
| 室内湿度 | 50-60% | 太干→皮肤失水→瘙痒；太湿→汗液不易蒸发→也痒 |

#### 2.9 奶粉选择与冲泡

**配方奶选择**：

| 情况 | 推荐 | 原因 |
|------|------|------|
| 足月健康婴儿 | 普通配方奶（1段0-6月/2段6-12月） | 按月龄选段位→营养成分配比不同 |
| 牛奶蛋白过敏 | 深度水解配方或氨基酸配方 | 须医生诊断后更换→不自行换 |
| 乳糖不耐受 | 无乳糖配方 | 须医生确认→不自行换 |
| 早产/低体重 | 早产儿配方→至体重追上后转普通配方 | 须医生指导 |

**冲泡要点**：

| 项目 | 做法 | 不该做 |
|------|------|--------|
| 水 | 先烧开→稍放凉至约70°C→再冲奶→冲好后迅速冷却至喂奶温度（隔水冷却→手腕试温→温热不烫） | ❌ 用40-50°C温水直接冲→无法杀灭奶粉中可能存在的阪崎肠杆菌→新生儿/2月龄以下婴儿尤其危险→死亡率可达40-80%（WHO 2007） |
| 比例 | 严格按罐上说明→先放水→后放奶粉→平勺（不压实） | ❌ 随意加减→过浓→肾脏负担；过稀→营养不足 |
| 摇匀 | 双手搓着摇→不上下猛摇→减少气泡 | ❌ 上下猛摇→大量气泡→胀气→吐奶 |
| 喂前试温 | 滴一滴在手腕内侧→温热不烫 | ❌ 直接喂→可能烫伤 |
| 剩奶 | 喝剩的1小时内喝完→超时倒掉 | ❌ 留到下顿→细菌繁殖→腹泻 |
| 含益生菌配方奶 | 说明书要求40-50°C冲泡→遵说明书→70°C会杀灭益生菌→但须注意卫生→用煮沸后放凉的水→不直接用温水 | 2月龄以上婴儿用含益生菌配方奶可按说明书40-50°C冲泡→**新生儿/2月龄以下仍建议70°C**→安全优先 |

**奶嘴流速选择**：

| 月龄 | 推荐型号 | 流速 | 流速过快的信号 | 流速过慢的信号 |
|------|---------|------|---------------|---------------|
| 0-3月 | S号（慢流） | 1滴/秒 | 呛奶+吞咽声大+奶从嘴角漏出+咳嗽 | 吸很久不满+奶嘴被吸瘪+吃一顿>30分钟 |
| 3-6月 | M号（中流） | 连续滴落 | 同上 | 同上 |
| 6月+ | L号（快流） | 细流 | 同上 | 同上 |

> 📝 **判断标准**：倒转奶瓶→奶应一滴一滴连续滴落→不是直线流出（太快）→也不是很久才一滴（太慢）。宝宝不呛奶+20分钟内吃完=流速合适。

#### 2.10 混合喂养注意事项

| 项目 | 做法 | 原因 |
|------|------|------|
| 先母乳后配方 | 每次先吸吮母乳→两侧都吸→不够再加配方奶 | 保持泌乳刺激→母乳越吸越多→不吸→越来越少 |
| 不用奶瓶补充（初期） | 母乳建立期（0-4周）→用小杯/勺喂配方→不用奶瓶 | 奶瓶吸吮容易→婴儿可能不愿再费力吸母乳→乳头混淆 |
| 记录母乳量 | 不必精确→观察尿量+体重→判断总量是否够 | 不焦虑→多数"奶不够"是误判 |

#### 2.11 哄睡技巧与自主入睡培养

**0-3月**——不用刻意培养→按需入睡→此时建立安全感>培养自主入睡

**3-6月**——可开始建立睡前仪式

| 步骤 | 内容 | 原因 |
|------|------|------|
| 固定时间 | 每晚约同一时间开始睡前仪式 | 生物钟→条件反射→到点就困 |
| 睡前仪式 | 见下方月龄模板 | 固定顺序→大脑接收"该睡了"信号 |
| 放床时机 | 困了但还没完全睡着→放下→让他自己完成入睡最后一步 | 如果每次都抱睡/奶睡到完全睡着→醒来发现不在怀里→哭→形成依赖 |

**"落地醒"3步放床法——抱睡→放床不醒的关键技巧**：

> 很多家长反映"一放就醒"→不是婴儿睡眠浅→是放床手法不对→温差+重力+莫罗反射三重刺激→必须用技巧过渡。

| 步骤 | 操作 | 要点 |
|------|------|------|
| ①放床顺序 | **脚→臀→背→头**→3-5秒完成→连贯平稳→不犹豫 | 先放下半身→重心下移→再放头→减少重力落差感→与"头先下"相反 |
| ②延迟抽手 | 头放稳后→手掌平放胸腹→轻压→**保持30秒-1分钟**→等呼吸平稳→缓慢抽手 | 手掌温度+重量=持续触觉→婴儿以为还在大人身上→等深睡眠过渡→再撤 |
| ③轻拍退出 | 抽手后→继续轻拍1-2分钟→频率渐慢→停→观察→呼吸平稳→安静退出 | 逐步减少干预→不是突然消失→给婴儿适应时间 |

> 📝 **关键**：第②步"延迟抽手"是成败关键→很多家长头一放就抽手→温差+触觉突然消失→莫罗反射触发→秒醒→手掌压胸30秒=最简单有效的过渡。
| 夜醒处理 | 先等1-2分钟→不给立刻回应→让婴儿尝试自己接觉→再哭再介入 | 给自愈机会→不是每次夜醒都需要大人干预 |

**月龄分睡前仪式模板**（总时长20-30分钟）：

| 月龄 | 睡前仪式步骤 | 替代说明 |
|------|-------------|----------|
| 0-3月 | 温水擦洗(5min)→换睡衣+尿布(3min)→喂奶(10-15min)→轻拍+哼歌(3min)→关灯 | 不讲故事→婴儿听不懂→用哼歌/轻拍替代；喂奶放在仪式中间→不是最后一步→避免奶睡依赖 |
| 3-6月 | 洗澡(5-8min)→换睡衣(3min)→喂奶(10min)→看黑白卡片/布书(3min)→轻拍+哼歌(3min)→关灯 | "看布书"≠讲故事→翻页+指图+声音→简单互动→告诉大脑"白天结束→该睡" |
| 6-12月 | 洗澡(8min)→换睡衣(3min)→喂奶/吃辅食(10min)→读绘本(5min)→轻拍(3min)→关灯 | 绘本选3-5页简单→每页1句话→固定→条件反射→读到"晚安"→闭眼 |

**清醒窗口表——怎么判断"该睡了"**：

| 月龄 | 清醒窗口（两次睡眠之间） | 闹觉信号 | 放床时机 |
|------|------------------------|----------|----------|
| 0-2周 | 45-60分钟 | 打哈欠+揉眼+烦躁 | 信号出现→立刻减刺激→准备入睡 |
| 2-4周 | 60-90分钟 | 同上+不愿对视 | 同上 |
| 1-3月 | 1-1.5小时 | 同上+抓耳朵 | 清醒约1小时→主动安排入睡 |
| 3-6月 | 1.5-2.5小时 | 同上+哭闹 | 清醒约2小时→准备 |
| 6-12月 | 2-3小时 | 同上+粘人+烦躁 | 清醒约2.5小时→准备 |

> ⚠️ **超过清醒窗口不睡→过度疲劳→更难入睡→哭闹加剧→"越困越不睡"**——这是家长最容易犯的错误。不要等婴儿"自己困了才放"→到清醒窗口就主动安排→比等信号更有效。

**日夜颠倒纠正方案**（7-10天可纠正）：

| 时间 | 做法 | 目的 |
|------|------|------|
| 07:00 | 打开窗帘→让阳光进来→对婴儿说话→"早上好"→换衣服→喂奶 | 光线→抑制褪黑素→告诉大脑"天亮了" |
| 白天 | 正常声音→不刻意安静→正常活动→每次清醒后到窗口晒太阳5-10分钟 | 建立"白天=活跃"的认知 |
| 白天小睡 | 不拉全遮光窗帘→留缝→每次小睡不超过2.5小时→超了→轻唤醒 | 防止白天睡太多→晚上不困 |
| 17:00后 | 逐步减少刺激→不用强光→安静玩耍 | 过渡→为夜间做准备 |
| 19:00-20:00 | 睡前仪式→关灯→夜间模式 | 建立"晚上=睡觉" |
| 夜间喂奶 | 小夜灯→不说话→不逗玩→喂完→轻拍→放→不互动 | 夜间=无聊=不值得醒来→条件反射 |
| 凌晨1-4点清醒 | 不开大灯→不逗玩→不抱起来到处走→保持暗+静→轻拍→不说话→让婴儿知道"现在还是晚上" | 如果开灯+互动→婴儿以为天亮了→白天睡→恶性循环 |

> 📝 **关键**：凌晨清醒→大人最难熬→但这一步最关键→如果你扛不住开灯逗玩→前功尽弃→坚持7-10天→生物钟会倒过来。

**婴儿床布置安全清单**：

| 项目 | 正确 | 错误 |
|------|------|------|
| 位置 | 父母床旁边→伸手可及→同房不同床→至少6月→理想至1年 | ❌ 婴儿和大人同睡一张床→压迫/窒息风险 |
| 床面 | 硬床垫+紧绷床单→无其他物品 | ❌ 软床垫/枕头/被子/毛绒玩具/床围 |
| 床围 | ❌ **不用床围**→AAP明确反对→婴儿脸贴上→窒息→无通气 | 不买床围→已买→拆除 |
| 床中床 | ⚠️ 不推荐→婴儿可能翻身贴上软壁→窒息→不如直接在硬床垫上 | — |
| 距离 | 婴儿床靠大床→一侧护栏可放下→方便夜间照料 | ❌ 婴儿床放另一个房间 |

> ⚠️ **哭声免疫法（CIO）不适合0-6月**——0-6月婴儿哭=真实需求→应回应。6月后可逐步延迟响应→但不是"让哭不管"→是"等1-2分钟→轻拍→不抱→再等"→逐步拉长。

**安抚奶嘴使用指南**：

| 项目 | 说明 |
|------|------|
| 引入时机 | 母乳喂养建立后（3-4周后）→太早→乳头混淆→影响母乳吸吮；配方奶喂养→出生后即可使用 |
| SIDS预防 | ⭐ **睡眠时使用安抚奶嘴可降低SIDS风险约50%**（AAP 2022）→每次睡眠（含小睡）都应提供→即使奶嘴掉出也不必重新塞入→保护效应仍存在 |
| 型号选择 | 按月龄选→0-6月用小号→6-18月中号→18月+大号→不跨号使用→太大→ choking risk |
| 材质 | 硅胶（透明→耐用→可煮消毒）或乳胶（黄色→柔软→易老化→3-4周换） |
| 清洁 | 0-3月→每次用前消毒→3月后→清水洗净→定期消毒；掉地上→不捡起来直接用→洗→消毒 |
| 使用原则 | 安抚用→不是阻止吃饭→饿了给奶嘴→越吸越饿→哭更凶→先喂奶 |
| 睡着后 | 奶嘴掉出→不塞回→让婴儿自己决定→减少依赖（SIDS保护效应仍在） |
| 不涂糖/蜂蜜 | ❌ 蜂蜜→1岁以下致命（肉毒杆菌）；糖→龋齿 |
| 戒除时机 | 1岁后逐步减少→2岁前戒除→>2岁仍用→影响牙齿排列（开颌） |
| 戒除方法 | 逐步减少→先减白天→再减睡前→最后减夜醒→用其他安抚替代（抚拍/玩具/故事） |

> 📝 **依据**：AAP 2022安全睡眠指南明确推荐，睡眠时使用安抚奶嘴是SIDS预防措施之一。机制可能与：保持上气道通畅、降低觉醒阈值、减少俯卧位翻转风险有关。母乳喂养建立前暂不引入以免乳头混淆，但一旦母乳建立（3-4周），应主动在睡眠时提供。

#### 2.12 何时可以枕枕头

| 月龄 | 建议 |
|------|------|
| 0-12月 | **不需要枕头**→不用枕头 |
| 1岁后 | 可给薄枕（1-2cm）→不给成人枕头 |

> 📝 婴儿脊柱尚未形成成人曲度→头部和躯干在同一平面→垫枕头→颈部弯曲→气道受压→窒息风险+脊柱不良姿势。

#### 2.13 奶瓶/餐具消毒

| 月龄 | 频率 | 方法 |
|------|------|------|
| 0-3月 | 每次用后消毒 | 煮沸消毒→水开后煮5分钟→或蒸汽消毒锅 |
| 3-6月 | 每日1次消毒→其余清水洗净 | 免疫力渐强→不必每次消毒 |
| 6月后 | 清水+洗洁精洗净→定期消毒（每周1-2次） | — |

#### 2.14 鼻塞处理——0-6月极常见

> 婴儿鼻腔窄→一点分泌物就堵→不是感冒→家长常过度焦虑。

**生理性鼻塞vs病理性鼻塞**：

| 鉴别点 | 生理性鼻塞（正常） | 病理性鼻塞（须就医） |
|--------|-------------------|---------------------|
| 鼻涕 | 无或少量清涕 | 大量黄绿涕/脓涕 |
| 精神 | 精神好→吃睡正常 | 精神差→拒奶→发热 |
| 呼吸 | 偶尔呼哧→吃奶时加重→安静时缓解 | 持续张口呼吸→影响吃奶→呛咳 |
| 持续 | 数天→时好时坏 | 持续加重>7天 |

**鼻塞处理方法（按优先级）**：

| 方法 | 具体操作 | 适用情况 | ⚠️ |
|------|----------|----------|-----|
| ①生理盐水滴鼻 | 婴儿专用生理盐水滴剂→每侧鼻孔1-2滴→等1-2分钟→分泌物软化→婴儿打喷嚏或自行排出 | 日常鼻塞/有干鼻屎 | 不用自制盐水→浓度/消毒不可控 |
| ②吸鼻器 | 滴盐水后→用球形吸鼻器→先捏瘪球体→轻插入鼻孔→松开球体→吸出分泌物 | 鼻屎软化后仍排不出 | ⚠️ 不频繁吸→刺激鼻黏膜→分泌更多→恶性循环→每日最多2-3次 |
| ③温湿毛巾敷鼻 | 温湿毛巾敷在鼻根处→3-5分钟→蒸汽湿润鼻腔 | 鼻腔干燥 | 毛巾不烫→手腕试温 |
| ④竖抱/抬高上半身 | 喂奶后竖抱→睡觉时床垫头部抬高15-30°（垫床腿→不垫枕头） | 吃奶时鼻塞加重 | 不用枕头垫高→窒息风险 |
| ⑤浴室蒸汽 | 关浴室门→开热水→蒸汽充满→抱婴儿坐5-10分钟 | 鼻塞严重影响睡眠 | 不让婴儿接触热水→大人先试温度 |

> ⚠️ **不使用**：成人感冒药/含麻黄碱的滴鼻剂/薄荷膏（薄荷对婴儿神经系统有刺激）→婴儿禁用。鼻塞伴发热+咳嗽→可能是上呼吸道感染→就医。

#### 2.15 频繁打嗝——不是病

| 项目 | 内容 |
|------|------|
| 原因 | 婴儿膈肌发育不完善→轻微刺激（吃奶/温度变化/情绪波动）→膈肌痉挛→打嗝 |
| 是否正常 | 完全正常→不影响健康→婴儿不会觉得难受（比成人轻松得多） |
| 处理 | 多数不需处理→几分钟自行停止；如果持续较长→喂几口奶/温水→吞咽动作→膈肌放松→嗝止 |
| ⚠️ 不该做的 | ❌ 捏耳朵/按眼球/惊吓→这些偏方无科学依据→可能伤害婴儿 |

#### 2.16 眼屎多/泪管堵塞

| 项目 | 内容 |
|------|------|
| 表现 | 单侧或双侧眼屎多→内眼角有黄色/白色分泌物→眼睑可能粘连 |
| 原因 | 鼻泪管堵塞→泪液无法排入鼻腔→积聚→细菌繁殖→眼屎增多。约6%新生儿有此问题→多数1岁内自愈 |
| 日常清洁 | 用消毒棉签/纱布蘸温开水→从内眼角向外眼角轻轻擦拭→每只眼用独立棉签→不交叉 |
| 泪管按摩法 | 洗净双手→食指按压内眼角与鼻根之间的泪囊区→向下向内按压→每次5-10下→每日3-4次→帮助疏通鼻泪管 |
| ⚠️ 就医指征 | 眼白发红+大量脓性分泌物+眼睑红肿→可能结膜炎→须就医→医生开具抗生素眼药水；按摩2-3月无改善→眼科就诊→可能需泪管探通术 |

#### 2.17 囟门日常观察

| 项目 | 内容 |
|------|------|
| 前囟位置 | 头顶偏前→菱形→额缝与矢状缝交汇处 |
| 前囟大小 | 出生时约2.5×2.5cm→随生长缩小→约12-18月闭合 |
| 后囟位置 | 头顶偏后→三角形 |
| 后囟大小 | 出生时很小或已闭→最迟6-8周闭合 |
| 正常触感 | 平坦→柔软→与周围颅骨齐平→可见搏动（与心跳同步）→正常 |
| ⚠️ 凸起 | 囟门明显隆起+烦躁/呕吐/嗜睡→颅内压增高→**紧急就医** |
| ⚠️ 凹陷 | 囟门明显凹陷→脱水→补充水分→如伴尿少/口唇干→就医 |
| 日常护理 | 囟门可正常洗头→动作轻柔→不按压→不回避→头皮有污垢→婴儿油软化后轻洗 |

> 📝 **囟门闭合早晚的临床意义**：过早闭合（<6月）→须排查小头畸形→就医；过晚闭合（>2岁）→须排查佝偻病/甲状腺功能减低/颅内压增高→就医。

#### 2.18 出牙护理——4-12月必经之路

> 出牙是0-1岁日常护理的高频问题，几乎每个婴儿都会经历不适。

**出牙时间表（大致参考，个体差异大）**：

| 月龄 | 出牙 | 数量 |
|------|------|------|
| 6-10月 | 下中切牙（下面两颗门牙） | 2颗 |
| 8-12月 | 上中切牙（上面两颗门牙） | 2颗 |
| 9-13月 | 上侧切牙 | 2颗 |
| 10-16月 | 下侧切牙 | 2颗 |

**出牙信号**：

| 信号 | 说明 | 处理 |
|------|------|------|
| 流口水增多 | 牙齿刺激唾液腺→口水多→可能引发口水疹 | 及时擦拭→涂润肤霜隔离→见下方口水疹 |
| 咬东西/啃手 | 牙龈痒→啃咬缓解 | 给牙胶/咬咬乐→冷藏牙胶（不冷冻）→凉感缓解牙龈肿胀 |
| 牙龈肿胀 | 可见牙龈红肿→可能微蓝 | 冷藏牙胶咬→干净手指轻按牙龈→按摩缓解 |
| 烦躁/哭闹 | 牙龈不适→情绪差 | 多安抚→转移注意力→咬牙胶 |
| 轻微发热 | 出牙**不会**引起发热（AAP/ADA立场声明）→如果体温升高→须排查其他原因 | 观察→任何体温升高→首先考虑感染而非出牙→>38°C→就医排查 |
| 食欲下降 | 牙龈痛→不愿吃 | 给偏凉偏软的食物→不强迫→可用冷藏牙胶先缓解再喂 |

> ⚠️ **出牙不会引起发热**（AAP/ADA立场声明）——出牙仅可引起轻微体温波动，不会导致真正发热。腹泻、呕吐更与出牙无关→出现这些→不是出牙→是生病→就医。

**出牙期口腔清洁**：

| 月龄 | 清洁方法 |
|------|----------|
| 0-6月（未出牙） | 每日用干净纱布/硅胶指套蘸温水→轻擦牙龈和舌面→清洁口腔+习惯建立 |
| 6-12月（出牙期） | 纱布/指套擦牙龈+已萌出牙齿→每颗牙的唇面/舌面/咬合面都擦→每日2次（晨起+睡前） |
| 12月+ | 软毛婴儿牙刷+米粒大小含氟牙膏（1000ppmF）→每日2次→家长帮刷至7岁 |

> ⚠️ **含氟牙膏是安全的**——米粒大小→即使吞咽也远低于中毒量→国际牙科协会推荐婴儿出牙即用含氟牙膏。不含氟牙膏=没有防蛀效果→不推荐。

#### 2.19 口水疹/流口水期护理

| 项目 | 内容 |
|------|------|
| 原因 | 出牙期口水增多→口水含消化酶→刺激面部皮肤→发红→疹子 |
| 好发部位 | 口周、下巴、颈部褶皱 |
| 预防 | 及时擦口水→用柔软棉巾轻按吸干（不摩擦）→涂凡士林/润肤霜形成隔离层→睡觉时在下巴垫纯棉口水巾 |
| 处理 | 已发红→涂厚层凡士林/氧化锌软膏→隔离口水→每次擦口水后补涂 |
| ⚠️ | 不用含激素药膏→口水疹不是湿疹→是物理刺激→隔离保湿即可；持续加重/渗液→可能合并真菌感染→就医 |

#### 2.20 0-6月纯母乳喂养的便秘

> 母乳喂养婴儿可能出现"数天不排便"→但这不一定是便秘→须区分。

| 情况 | 表现 | 性质 | 处理 |
|------|------|------|------|
| 母乳攒肚 | 数天（甚至7-10天）不排便→但排便时=软便→不费力→婴儿精神好→体重增长正常 | **正常**→母乳吸收率高→残渣少→不足以刺激排便 | **不需要任何处理**→等→不喂水→不用开塞露→不用肥皂条 |
| 真性便秘 | 排便费力→哭闹→大便干硬→肛门裂伤 | 异常→须排查 | 就医→不自行用泻药/开塞露 |

> 📝 **"攒肚"vs便秘的关键区别**：看大便性状→不是看间隔天数。软便=攒肚=正常；干硬=便秘=异常。

#### 2.21 洋葱穿衣法——分层穿衣实操

> 婴儿体温调节差→穿多→出汗→吹风→感冒→"捂出来"的病比冻出来的多。

**洋葱穿衣法**：像洋葱一样分层→冷了加→热了减→灵活调节。

| 室温 | 穿衣方案 | 说明 |
|------|----------|------|
| 26-28°C（夏季空调房） | 短袖连体衣1件→或薄长袖1件 | 不穿袜子→脚凉不是冷→末梢循环差→正常 |
| 22-26°C（春秋室内） | 薄长袖连体衣+薄棉马甲 | 外层马甲→外出加→室内减 |
| 18-22°C（冬季暖气房） | 长袖连体衣+薄棉马甲+薄外套 | 三层→灵活增减 |
| <18°C（外出/无暖气） | 长袖连体衣+薄棉马甲+厚外套+帽子+手套 | 外出才加厚外套→进屋即脱 |

**判断冷热的标准**：

| 部位 | 冷热判断 | 说明 |
|------|----------|------|
| 后颈（正确位置） | 温热无汗=穿够了；有汗=穿多了；发凉=穿少了 | ⭐最准确 |
| 手脚（不可靠） | 手脚微凉=正常→末梢循环未发育完善→不代表冷 | ❌ 不以手脚温度判断→穿到手脚热=已经穿多了 |
| 面色 | 红润=正常；苍白=可能冷或病；通红+烦躁=可能太热 | 综合 |

> ⚠️ **"有一种冷叫奶奶觉得冷"**——穿多的危害>穿少→穿多→出汗→毛孔开放→一吹风→感冒→家长以为"穿少了"→实际上穿多了才是原因。

#### 2.22 盆浴步骤——完整操作指南

| 步骤 | 操作 | ⚠️ |
|------|------|-----|
| ①准备 | 备齐：温水盆（38-40°C→手腕内侧试温→温热不烫）、婴儿沐浴露（每周1-2次）、洗头帽/纱布、大毛巾、换洗衣物+尿布→全部放在伸手可及处 | ⚠️ 先备好再抱婴儿→中途不可离开去拿东西 |
| ②脱衣 | 先脱衣服→留尿布→用大毛巾裹住身体→保持温暖 | — |
| ③洗头 | 婴儿夹在大人腋下→面朝上→头微后仰→手托头颈→另一手用纱布蘸水轻洗→不用力抠头垢→沐浴露搓泡后轻揉→清水冲净→注意不让水流进耳朵和眼睛 | — |
| ④洗身体 | 撤尿布→一手托头颈和肩背→另一手托臀→缓慢放入水中→先适应水温→从上到下洗：颈→腋→胸→腹→四肢→背→臀部→褶皱处重点洗（颈褶/腋窝/腹股沟/大腿根） | ⚠️ 一手始终托住婴儿→绝不松手→5cm水可溺亡 |
| ⑤出浴 | 一手托头→一手托臀→抱出→立即用大毛巾包裹→轻按吸干→不擦（摩擦伤皮肤）→褶皱处擦干→3分钟内全身涂润肤霜 | — |
| ⑥后续 | 涂润肤霜→穿尿布→穿衣→喂奶（洗澡消耗热量→洗后吃得好睡得香） | 洗澡时间5-10分钟→不宜过长 |

> ⚠️ **脐带未脱落前**：可盆浴→洗后轻轻擦干脐部→保持干燥即可→详见1.1脐带护理。

#### 3.2 过敏原引入策略

> ⚠️ **最新研究推翻了"延迟引入过敏原可防过敏"的旧观念**——延迟引入反而增加过敏风险。关键是**逐步、少量、观察**。

| 过敏原 | 引入时机 | 方法 | 观察 |
|--------|----------|------|------|
| 蛋黄 | 7-8月 | 从1/4开始→连续3天→无反应→加至1/2→再3天→全蛋 | 皮疹/呕吐/腹泻/呼吸急促→停→2周后试→仍过敏→排除 |
| 蛋白 | 9-10月 | 蛋黄耐受后再试蛋白→少量→观察3天 | 蛋白是最常见过敏原之一 |
| 鱼类 | 9-10月 | 白肉鱼先试→少量鱼泥→观察 | 海鱼>河鱼易过敏 |
| 小麦 | 7-8月 | 面条/馒头少量→观察 | 麸质过敏 |
| 大豆 | 8-9月 | 豆腐少量→观察 | — |
| 坚果 | 12月后 | 坚果酱（非整粒→窒息！）→极少量→观察 | 坚果过敏可严重→首试须在家→备好手机 |
| 牛奶（鲜奶） | 12月后 | 1岁前不喝鲜奶→蛋白质分子大→难消化+易过敏 | 1岁后少量试→不耐受→继续配方奶 |
| 蜂蜜 | **1岁后** | 1岁以下**绝对禁用**→含肉毒杆菌芽孢→婴儿肠道未成熟→可致死 | — |

**过敏反应识别**：

| 反应 | 表现 | 严重程度 |
|------|------|----------|
| 轻度 | 口周红疹、轻度荨麻疹 | 停该食物→观察→1-2天消退 |
| 中度 | 大面积荨麻疹、呕吐、腹泻 | 停该食物→就医 |
| 重度 | 呼吸急促、嘴唇肿胀、面色苍白、意识模糊 | ⚠️ **紧急就医→过敏性休克** |

#### 3.3 何时可以喝水

| 月龄 | 建议 | 原因 |
|------|------|------|
| 0-6月纯母乳 | **不需要额外喝水** | 母乳中87%为水→按需哺乳→水分足够；喝水→占胃→奶吃不够→营养不足；大量喝水→水中毒（低钠血症）→危险 |
| 0-6月配方奶 | **一般不需要额外喝水** | 配方奶按规定比例冲泡→水分足够；仅在天热/出汗多/大便干结时→少量温水→每次5-10ml→不替代奶 |
| 6-12月 | 可少量喝水→每次辅食后1-2小口→每日总计30-60ml | 喝水=辅食训练的一部分→不是必需→奶仍是主要水分来源 |
| 12月+ | 正常饮水→鼓励喝水>喝果汁 | — |

> ⚠️ **0-6月婴儿唯一例外**：发热/腹泻时→医生指导→口服补液盐→不是白开水。

#### 3.4 非积食性便秘——辅食过渡期便秘

| 原因 | 表现 | 处理 |
|------|------|------|
| 辅食添加过快 | 大便干硬+排便费力 | 减慢辅食添加速度→回退到上一阶段→逐步再来 |
| 水分不足 | 6月后奶量减少+未补充水分 | 辅食后给少量温水→增加水分摄入 |
| 膳食纤维不足 | 全是精米面→无蔬菜 | 增加菜泥→西梅泥/梨泥→天然通便 |
| 牛奶蛋白过敏 | 便秘+湿疹+呕吐 | 就医排查→换深度水解配方 |

**便秘食疗**（6月以上）：

| 食物 | 做法 | 功效 |
|------|------|------|
| 西梅泥 | 西梅蒸熟打泥 | 天然山梨糖醇→渗透性通便→最有效 |
| 梨泥 | 梨蒸熟打泥 | 润肠+果糖→促排便 |
| 火龙果泥 | 红心火龙果打泥 | 膳食纤维+花青素→通便效果显著 |
| 增加菜泥比例 | 每餐辅食中菜泥占1/3 | 膳食纤维→增加便便体积→促进肠蠕动 |

> ⚠️ **不使用开塞露/蜂蜜栓→除非医生指导**→依赖→自主排便能力更差。**1岁以下婴儿绝对禁用蜂蜜**（肉毒杆菌芽孢风险→可致死）。

#### 3.5 生长发育曲线——如何判断"够不够"

> 家长最关心"体重够不够"→不能凭感觉→须看生长曲线。

**0-1岁体重参考（WHO标准，粗略参考）**：

| 月龄 | 男婴体重（kg） | 女婴体重（kg） | 增长规律 |
|------|---------------|---------------|----------|
| 出生 | 3.3（2.5-4.0正常） | 3.2（2.5-3.8正常） | — |
| 3月 | 6.0 | 5.5 | 出生体重约翻倍 |
| 6月 | 7.8 | 7.2 | 出生体重约2-2.5倍 |
| 12月 | 9.8 | 9.2 | 出生体重约3倍 |

> 📝 **判断标准不是"绝对值"而是"生长趋势"**：
> - 体重沿着百分位线稳步上升=正常
> - 体重曲线突然下跨2条百分位线=生长缓慢→须就医排查
> - 出生偏小（<2.5kg）→追赶生长→前3月可能长得快→正常

**0-1岁身高参考**：

| 月龄 | 男婴身高（cm） | 女婴身高（cm） |
|------|---------------|---------------|
| 出生 | 49.9 | 49.1 |
| 6月 | 66.5 | 65.0 |
| 12月 | 75.0 | 73.5 |

> 📝 建议下载WHO生长曲线APP→每次体检后记录→看曲线走向→比单次数据更有意义。

#### 3.6 辅食添加常见问题——拒食/干呕/过敏

**拒食（婴儿把食物推出/扭头/闭嘴）**：

| 原因 | 处理 |
|------|------|
| 首次尝试新食物→不习惯 | 正常→新食物需8-15次反复尝试才被接受→不放弃→隔2-3天再试→不强迫 |
| 不饿 | 在奶后1-2小时→婴儿情绪好→稍有饥饿感时尝试→刚吃饱不想吃 |
| 口感/温度不对 | 从稀到稠循序渐进→温度适中→不冷不热→有的婴儿不喜欢太稀的 |
| 婴儿想自己抓→不让 | 8月后给手指食物→煮软的胡萝卜条/香蕉段→让婴儿自己拿→锻炼手眼协调 |

**干呕（gagging）**：

| 项目 | 内容 |
|------|------|
| 与窒息的区别 | 干呕=声音大+面色红+能咳嗽→是保护反射→把太深/太大的食物推出来→**安全**；窒息=无声+面色青紫+不能哭/咳→**危险** |
| 原因 | 婴儿呕吐反射的触发点比成人靠前→食物到舌头中后部就触发→是正常发育过程 |
| 处理 | 保持冷静→不惊慌→不伸手掏→让婴儿自己把食物推出来→掏→可能把食物推更深→反而危险 |
| 预防 | 食物做成适当大小→不过大过硬→逐步从泥→碎→块过渡→给足够时间适应 |

**辅食过敏反应处理**：

| 反应 | 表现 | 处理 |
|------|------|------|
| 轻度 | 口周红疹→几小时消退 | 停该食物→2周后再试小量→仍过敏→排除→等3月后再试 |
| 中度 | 荨麻疹+呕吐+腹泻 | 停该食物→就医→不自行给抗过敏药 |
| 重度 | 呼吸急促+嘴唇肿胀+面色苍白+意识模糊 | ⚠️ **立即就医→过敏性休克**→不等待→不自行开车→打120 |

#### 3.7 断奶具体步骤与回奶指导

> ⚠️ **断奶铁律**：不突然断、不在生病时断、不在夏季断。断奶是渐进过程→不是一刀切。

**断奶时间线**：

| 阶段 | 操作 | 时间跨度 |
|------|------|----------|
| 1. 减少白天的哺乳次数 | 先减最不依赖的那一顿（通常是上午或下午）→用配方奶/辅食替代→每3-4天减1顿 | 2-4周 |
| 2. 减少睡前哺乳 | 睡前奶→改为瓶喂/杯喂配方奶→逐步减量→用讲故事/抚拍替代奶睡 | 1-2周 |
| 3. 减少夜奶 | 夜醒先拍哄→不给奶→坚持3-5天→婴儿接受新的安抚方式 | 1-2周 |
| 4. 最后减晨起哺乳 | 晨起奶→改为瓶喂配方奶→或直接吃早餐 | 1-2周 |
| 总计 | 逐步减→从6顿→4顿→2顿→1顿→0→约4-8周 | 4-8周 |

**回奶指导（母亲）**：

| 方法 | 做法 | 原理 |
|------|------|------|
| 减少吸乳刺激 | 不额外吸奶/挤奶→胀痛时挤出一小部分（排到不痛即可→不排空） | 刺激越少→泌乳越少→自然回 |
| 冷敷 | 胀痛时→冷敷乳房→每次15分钟→每日3-4次 | 收缩血管→减少泌乳→缓解胀痛 |
| 穿合身内衣 | 稍紧但不勒→支撑→不额外刺激 | — |
| 避免热敷/按摩 | ⚠️ 热敷/按摩=刺激泌乳→回奶期不做 | — |
| 炒麦芽水 | 炒麦芽60-120g→煮水代茶饮→每日1剂→连用3-5天 | 炒麦芽=回奶经典→消食+回乳 |
| 维生素B6 | 每次200mg→每日3次→连用3-5天→须医生指导 | 抑制泌乳素→西医回奶方案 |

> ⚠️ **回奶期预防乳腺炎**：如果乳房出现硬块+红+痛+发热→可能乳腺炎→就医→不自行揉开。

#### 3.8 分离焦虑——6-12月开始出现

| 项目 | 内容 |
|------|------|
| 出现时间 | 约6-8月开始→8-12月达高峰→持续至2岁左右 |
| 表现 | 母亲离开视线就哭→粘人→不愿给他人抱→夜间也怕母亲不在 |
| 原因 | 认知发展→婴儿开始理解"客体永存"→知道母亲存在→但不确定母亲会回来→恐惧 |
| 处理原则 | 接纳→不批评→不偷偷溜走→但要温和坚定→不因哭就永远不走 |

**分离焦虑应对实操**：

| 方法 | 具体做法 | 原因 |
|------|----------|------|
| 告别仪式 | 每次离开→蹲下→平视婴儿→说"妈妈去XX→很快回来"→亲亲→交给看护人→走→不回头→不拖泥带水 | 婴儿需要可预期的分离→偷偷溜走→更焦虑→不知道妈妈什么时候消失 |
| 缩短分离时间 | 初期→离开5分钟→回来→拥抱→"妈妈回来了"→逐步延长→10分钟→30分钟→1小时 | 建立信任→妈妈说回来就回来→安全感↑ |
| 过渡物品 | 留一件母亲的衣服（有母亲气味）→让婴儿抱着→有安全感 | 气味=安全信号 |
| 陌生环境 | 到新环境→先陪婴儿熟悉→不立刻离开→让婴儿适应后再告别 | 新环境+陌生人→双重焦虑→逐步适应 |
| 夜间分离 | 睡前仪式→固定→可预知→婴儿知道接下来→不恐慌 | 睡前仪式=安全感锚点 |

#### 3.9 口腔护理/刷牙指导——从第一颗牙开始

| 月龄 | 口腔清洁方法 | 工具 |
|------|-------------|------|
| 0-6月（未出牙） | 干净纱布/硅胶指套蘸温水→轻擦牙龈+舌面→每日1次 | 纱布/指套 |
| 6-12月（出牙期） | 同上→加已萌出牙齿的清洁→每颗牙的3个面都擦→每日2次（晨起+睡前） | 纱布/指套→出牙4颗以上可换软毛婴儿牙刷 |
| 12月+ | 软毛婴儿牙刷+米粒大小含氟牙膏→每日2次→家长帮刷→至7岁 | 婴儿牙刷+含氟牙膏 |

**刷牙要点**：

| 要点 | 说明 |
|------|------|
| 含氟牙膏是安全且必要的 | 米粒大小→即使吞咽也远低于中毒量→国际牙科协会推荐→不用不含氟牙膏（无防蛀效果） |
| 刷牙手法 | 上牙从上往下→下牙从下往上→咬合面来回刷→每颗牙刷5-6下→每侧各3颗→总计2分钟 |
| 不让婴儿含奶瓶睡 | 奶液含糖→含奶瓶睡→糖长时间接触牙齿→龋齿→"奶瓶龋"→上排门牙最先坏 |
| 睡前喝奶后刷牙 | 先喝奶→后刷牙→不是先刷牙后喝奶 |
| 1岁开始看牙医 | 建立牙科档案→及早发现龋齿→涂氟保护 |

#### 3.10 语言发育里程碑与促进方法

| 月龄 | 正常语言表现 | 促进方法 | ⚠️ 须就诊信号 |
|------|-------------|----------|-------------|
| 0-3月 | 哭声区分需求（饿/痛/烦）；发出"a/o"等元音 | 多与婴儿说话→回应婴儿的声音→模仿婴儿发音 | 3月对声音无反应/不发声 |
| 4-6月 | 咿呀学语→"ba-ba""ma-ma"（无意义）；笑出声 | 指着物品命名→"这是杯子"→重复关键词→语速慢→声音有韵律 | 6月不转头寻声源/不发出任何辅音 |
| 7-12月 | 理解简单指令（"不行""过来"）；有1-3个有意义的词（"妈妈""拜拜"）；用手指 | 读绘本→指图命名→回应婴儿的指→"对，那是小狗"→多给语言输入 | 12月无有意义词汇/不看人/不应名 |

> 📝 **语言发育关键**：输入>输出→婴儿需要大量语言输入→才能输出→家长"话多"=好事→多描述日常→"妈妈给你换尿布啦""水好暖和呀"→语言不是教出来的→是在互动中自然习得的。

### 四、0-1岁安全防护

> ⚠️ **窒息是0-1岁意外死亡第一原因**——安全防护不是"多余"，是必须。

#### 4.1 窒息风险清单

| 风险物品 | 场景 | 预防 |
|----------|------|------|
| 整粒坚果/葡萄/圣女果/糖果 | 进食 | 切碎→坚果磨酱→葡萄切四瓣→1岁前不给硬糖 |
| 硬币/纽扣/小零件 | 爬行/玩耍 | 地面上所有直径<3cm的物品收走→婴儿什么都往嘴里放 |
| 塑料袋 | 任何 | 绝不让孩子接触→套头→窒息 |
| 绳索/窗帘绳 | 睡觉/玩耍 | 窗帘绳系高→婴儿床不挂绳索→防勒颈 |
| 枕头/被子/毛绒玩具 | 睡觉 | 1岁前床面只放床垫+床单→不放任何松软物品 |
| 果冻 | 进食 | 3岁前不给果冻→吸进去堵气管→极难取出 |

#### 4.2 跌落防护

| 场景 | 预防 |
|------|------|
| 换尿布台 | 一手始终扶住婴儿→不转身拿东西→先备好→再放婴儿 |
| 床 | 婴儿会翻身后→床栏拉起→床栏间距<6cm→婴儿不会卡头 |
| 沙发 | 不让婴儿独坐沙发→哪怕"就1秒"→翻身就掉→1秒够了 |
| 学步车 | ❌ **不推荐使用学步车**→翻倒风险+不能真正学步+影响髋关节发育 |

#### 4.3 汽车安全

| 项目 | 要求 |
|------|------|
| 安全座椅 | **必须使用**→出生起→后向安装→至2岁或超过座椅限重 |
| 位置 | 后排→选能最稳固安装的位置（LATCH/ISOFIX接口处最优）→中间位置理论最安全但若安装不稳固则不如两侧→绝不在前排（气囊弹出→致命） |
| 抱着坐车 | ❌ **绝对不行**→30km/h碰撞→10kg婴儿=300kg冲击力→人抱不住→飞出 |

#### 4.4 烫伤预防

| 场景 | 预防 |
|------|------|
| 喂奶 | 试温→手腕内侧→不直接嘴试→成人觉得温→婴儿可能烫 |
| 洗澡 | 先放冷水→再放热水→试温→绝不先放热水 |
| 热饮 | 抱婴儿时不拿热饮→不把热饮放婴儿可触及处 |

#### 4.5 溺水预防

| 场景 | 预防 |
|------|------|
| 洗澡 | 一手始终扶住→不离开→电话响了也不走→5cm水可致婴儿溺亡 |
| 洗衣机 | 盖子始终关闭 |
| 水桶/浴缸 | 用完立即倒空→不存水 |

#### 4.6 坠床/换尿布台坠落处理

> 0-1岁坠床几乎每个婴儿都会经历→大多数无大碍→但须知道如何观察和何时就医。换尿布台坠落高度更高→须特别关注。

**换尿布台坠落特殊评估**：

换尿布台高度约80-90cm→比婴儿床（约40-50cm）高一倍→坠落冲击力更大→评估须更谨慎。

| 与床坠的区别 | 换尿布台坠落 | 处理 |
|-------------|-------------|------|
| 坠落高度 | 80-90cm（约成人腰部高度） | 比床坠更须警惕内伤→观察期延长至48小时 |
| 坠落姿势 | 常为头朝下（婴儿头重→翻转时头先着地） | 重点检查头部→即使表面无包也须密切观察意识 |
| 坠落面 | 常为硬地面（瓷砖/木地板） | 比地毯面更危险→如有条件→尿布台下方铺软垫 |
| 发生场景 | 家长转身拿尿布/湿巾→瞬间坠落 | **预防>处理**→所有用品提前放在手边→一手始终扶住→不转身→不离开 |

**坠床后立即评估**：

| 评估项 | 正常（可观察） | 异常（须就医） |
|--------|---------------|---------------|
| 意识 | 哭了→安抚后→精神好→照玩 | 嗜睡→叫不醒→意识模糊 |
| 呕吐 | 不呕吐→或仅因哭闹吐1次 | 反复呕吐≥2次→喷射性呕吐 |
| 面色 | 红润→哭后很快恢复 | 苍白/青紫/异常潮红 |
| 四肢活动 | 四肢活动自如→爬/抓/玩 | 一侧肢体不动/无力/异常姿势 |
| 瞳孔 | 两侧等大→对光有反应 | 一大一小/对光无反应 |
| 头部外观 | 无包/小包→逐步消退 | 大包迅速增大/凹陷/耳鼻流水 |

**坠床后观察期（24小时）**：

| 时间 | 观察 | 做法 |
|------|------|------|
| 第1小时 | 每15分钟查看意识→叫名字→看反应 | 不让婴儿立刻睡觉→观察30分钟→如无异常→可睡→但2小时唤醒1次→确认能醒 |
| 2-6小时 | 每2小时唤醒→确认能醒+反应正常 | 夜间设闹钟唤醒 |
| 6-24小时 | 观察精神/食欲/呕吐/活动 | 异常→就医 |

**预防坠床**：

| 措施 | 说明 |
|------|------|
| 床栏 | 婴儿会翻身后→始终拉起床栏→检查床栏锁定→床栏间距<6cm |
| 床垫高度 | 婴儿床床垫放最低档→减少坠落距离 |
| 地面缓冲 | 床边铺软垫→万一坠落→缓冲 |
| 不独留高处 | 换尿布台/沙发/大床→一手始终扶住→不转身→不离开 |

#### 4.7 烧烫伤急救——冲脱泡盖送

> 婴儿皮肤薄→同样温度→烫伤比成人更深→必须掌握急救五步。

| 步骤 | 操作 | 时间 | ⚠️ |
|------|------|------|-----|
| ①冲 | 立即用流动冷水冲烫伤处→水温15-25°C→不是冰水 | **至少15-20分钟** | 最关键的一步→终止热力向深层组织传导→冲得越早越久→损伤越轻 |
| ②脱 | 冲水同时→小心脱去伤处衣物→如衣物粘在皮肤上→剪开周围→不撕扯 | — | 不撕→撕→把皮撕下来→二次伤害 |
| ③泡 | 继续在冷水中浸泡→（如面积大→不适合泡→继续冲） | 10-30分钟→至疼痛明显减轻 | — |
| ④盖 | 用干净纱布/无菌敷料轻轻覆盖→不包扎太紧 | — | 不涂牙膏/酱油/香油/任何偏方→这些→感染+影响医生判断 |
| ⑤送 | 面积>婴儿手掌大小/面部/手/足/会阴/起水泡→送医院 | — | 水泡不挑破→自破→碘伏消毒→纱布覆盖 |

> ⚠️ **化学灼伤**（如清洁剂）→先大量清水冲洗→至少30分钟→脱去污染衣物→就医。

#### 4.8 误服毒物/药物处理

| 项目 | 内容 |
|------|------|
| 立即做 | 拿走剩余毒物/药物→保留原包装→拨打120或中毒咨询热线 |
| ⚠️ 不催吐 | 催吐→腐蚀性物质二次灼伤食管→得不偿失 |
| ⚠️ 不喂牛奶/油/醋 | 这些偏方→可能与毒物反应→加重损伤→不喂任何东西→等120指导 |
| 就医时带 | 误服物的原包装→估计误服时间→估计误服量→婴儿当前状态 |
| 预防 | 所有药物/化学品/洗洁精放在婴儿够不到的高处→用后立即收起→不把药说成"糖"→不把化学品装在饮料瓶里 |

#### 4.9 过敏性休克——最严重的过敏反应

| 项目 | 内容 |
|------|------|
| 触发因素 | 食物（坚果/蛋/牛奶/海鲜）、药物、虫咬 |
| 表现 | 皮肤荨麻疹+呼吸急促/喘鸣+嘴唇/舌头肿胀+面色苍白+意识模糊→可几分钟内危及生命 |
| 处理 | ⚠️ **立即拨打120**→不等待→不自行开车→让婴儿平卧→抬高双腿→如随身携带肾上腺素笔（EpiPen）→按说明注射→记录时间 |
| 预防 | 已知严重过敏→随身携带肾上腺素笔→医生处方→教所有看护人使用方法 |

### 五、季节性护理

#### 春季（3-5月）

| 关注点 | 护理 |
|--------|------|
| 过敏 | 春花粉→湿疹/过敏性鼻炎→减少户外花粉高峰期（上午10点前）出门→回家洗脸洗手 |
| 穿衣 | 春捂→不急着减衣→早晚温差大→分层穿衣 |
| 疫病 | 手足口病高发（4-7月）→勤洗手→不去人多密闭场所→口腔手足出现水疱→就医（详见下方手足口病） |

#### 夏季（6-8月）

| 关注点 | 护理 |
|--------|------|
| 防痱 | 室温26-28°C→穿薄棉衣→勤换汗湿衣物→不用痱子粉（吸入风险）→用痱子水/露 |
| 防晒 | 6月以下→不直晒→遮阳+帽子；6月以上→防晒霜（SPF30+、物理防晒）→2小时补涂 |
| 防蚊 | 蚊帐最安全→2月以上可用驱蚊液（含避蚊胺≤30%或派卡瑞丁）→不涂手（婴儿吃手） |
| 防脱水 | 多喂奶/水→观察尿量→尿少色深→补水 |
| 空调 | 可用→26-28°C→不直吹→风口朝上→定时通风 |

#### 秋季（9-11月）

| 关注点 | 护理 |
|--------|------|
| 保湿 | 秋燥→皮肤干→润肤霜每日3-5次→尤其洗澡后 |
| 防感冒 | 换季温差→分层穿衣→不捂→不冻 |
| 腹泻 | 秋季腹泻（轮状病毒）→勤洗手→接种轮状疫苗→腹泻→防脱水（见第四部分） |

#### 冬季（12-2月）

| 关注点 | 护理 |
|--------|------|
| 保暖 | 室温20-24°C→出门加帽+手套→腹部保暖（脾怕寒） |
| 保湿 | 室内暖气→干燥→加湿器→40-60%湿度→每天换水→每周清洗 |
| 通风 | 每日开窗通风2次→每次15分钟→通风时婴儿避开穿堂风 |
| 不过度穿衣 | "有一种冷叫奶奶觉得冷"→摸后颈→温热无汗=刚好→不出门不必穿太厚 |

### 六、常见传染病补充

#### 手足口病——4-7月高发

| 项目 | 内容 |
|------|------|
| 病原 | 肠道病毒（以柯萨奇A16和EV71最常见）→EV71型→重症风险高 |
| 好发年龄 | 6月-5岁 |
| 潜伏期 | 3-7天 |
| 典型表现 | 发热+口腔疱疹/溃疡（舌/牙龈/颊黏膜）+手足臀部出现红色丘疹→转为水疱→不痛不痒 |
| 口腔溃疡处理 | 温凉流食/半流食（米汤/粥/酸奶）→避免酸/咸/热食物→刺激溃疡→疼痛拒食；冷饮/冰棒→暂时缓解疼痛→促进进食 |
| 发热处理 | 同一般发热处理→对乙酰氨基酚/布洛芬→按体重 |
| 皮疹处理 | 不挑破→不涂药→保持清洁→穿宽松棉衣→防抓破感染 |
| 传播途径 | 粪-口+飞沫+接触→传染性极强→患病期间不去托幼→症状消失后仍排毒数周 |
| ⚠️ 重症信号 | 持续高热>3天+频繁呕吐+肢体抖动+呼吸心率增快+精神萎靡→**紧急就医**→EV71重症可致脑炎/肺水肿→致命 |
| 中医认识 | 湿热疫毒→侵犯肺脾→外发肌肤→治以清热解毒利湿→须医生辨证→不自行用药 |

#### 乳糖不耐受识别与处理

| 项目 | 内容 |
|------|------|
| 表现 | 吃奶后腹胀+肠鸣+水样腹泻+泡沫便+肛门发红→持续数天以上 |
| 与牛奶蛋白过敏区别 | 乳糖不耐受=消化问题→无皮疹/血便；牛奶蛋白过敏=免疫问题→有湿疹/血便/呕吐 |
| 继发性乳糖不耐受 | 腹泻后→肠黏膜受损→乳糖酶减少→暂时不能消化乳糖→最常见→腹泻→继发乳糖不耐受→腹泻加重→恶性循环 |
| 处理 | 继发性→腹泻好转后→乳糖酶恢复→自愈→期间：母乳喂养→可继续→每次喂奶前加乳糖酶滴剂；配方奶→暂时换无乳糖配方→腹泻好转1周后→逐步转回→不长期用无乳糖配方 |
| ⚠️ | 不自行诊断→须医生确认→排除牛奶蛋白过敏→两者处理完全不同 |

#### 疫苗接种反应详细处理

| 反应 | 表现 | 处理 | 何时就医 |
|------|------|------|----------|
| 局部红肿 | 接种部位红肿→硬结→触痛 | 冷敷→每次10分钟→每日3-4次→不揉搓→不热敷→会自行消退→1-2周 | 红肿直径>5cm/持续扩大/化脓 |
| 低热 | 37.5-38.5°C→接种后6-24小时出现 | 多饮水→正常穿衣→观察→1-2天自行消退 | >39°C/>48小时不退 |
| 烦躁/嗜睡 | 哭闹增多或比平时嗜睡 | 正常反应→多安抚→多抱→观察→1-2天恢复 | 嗜睡叫不醒/持续哭闹>3小时 |
| 食欲下降 | 1-2天内吃得少 | 正常→饮食清淡→不强迫→2天内恢复 | 拒食>2天/呕吐/腹泻 |
| 过敏反应 | 皮疹/荨麻疹/面部肿胀/呼吸困难 | 轻度皮疹→观察→抗过敏药→须医生指导；呼吸困难/肿胀→**紧急就医** | 任何过敏反应→就医→严重→120 |

> 📝 **接种后观察30分钟再离院**——严重过敏反应（过敏性休克）→多在接种后数分钟至30分钟内发生→留在接种点→有急救设备→安全。

### 七、发热测量方法

| 方法 | 适用 | 正常范围 | 注意 |
|------|------|----------|------|
| 腋温（水银/电子体温计） | 所有年龄 | 36.0-37.3°C | 最常用→测3-5分钟→擦干腋窝汗液 |
| 耳温枪 | 6月以上 | 35.8-37.8°C | ⚠️ 6月以下耳道小→不准→不推荐 |
| 额温枪 | 所有年龄（快速筛查） | 35.5-37.5°C | 受环境温度影响→出汗→不准→作参考 |
| 肛温 | <3月婴儿（最准确） | 36.5-37.8°C | 准确但操作难→须润滑→插入1-1.5cm→一般由医护人员操作 |

> 📝 **何时量体温**：摸额头/后颈感觉热→先量→不要靠手感判断→额温枪快速筛查→腋温确认。

**退烧药按体重速查**（仅供参考，首次使用前咨询医生）：

| 药物 | 适用月龄 | 剂量 | 频率 | 注意 |
|------|----------|------|------|------|
| 对乙酰氨基酚（泰诺林） | ≥3月 | 10-15mg/kg/次 | 每4-6小时1次→24小时≤4次→**最大日剂量60mg/kg** | 3月以下发热→就医→不自行给 |
| 布洛芬（美林） | ≥6月 | 5-10mg/kg/次 | 每6-8小时1次→24小时≤3次→**最大日剂量40mg/kg** | 6月以下不用→脱水者不用 |
| ❌ **阿司匹林** | **<18岁禁用** | — | — | **可致瑞氏综合征（Reye syndrome）**→肝脑损伤→死亡率20-40%→AAP自1982年起禁止儿童用阿司匹林退热→任何年龄均不可替代对乙酰氨基酚/布洛芬 |

> ⚠️ **按体重不按年龄**——同月龄婴儿体重差异大→按体重算才准确。不常规交替用药→选一种→给够时间起效（30-60分钟）→体温降1-1.5°C即算有效→不必降到完全正常。

**腋温测量实操4步**（最常用、最安全）：

| 步骤 | 操作 | ⚠️ |
|------|------|-----|
| 1 | 先擦干腋窝汗液→有汗→测不准 | — |
| 2 | 将体温计尖端放在腋窝顶点→手臂紧贴身体→夹紧 | 不夹紧→测低→假正常 |
| 3 | 电子体温计→等蜂鸣（约30-60秒）；水银体温计→5分钟 | 推荐买电子→安全→水银打碎→汞中毒风险 |
| 4 | 读数→36.0-37.3=正常；37.3-38=低热；38-39=中热；>39=高热 | — |

**宝宝不配合量体温的3种对策**：

| 对策 | 做法 | 适用 |
|------|------|------|
| 睡着时测 | 轻轻放入→不吵醒→等蜂鸣→取出 | 最佳→最准 |
| 喂奶时测 | 边喂边测→婴儿安静→不动 | 退而求其次 |
| 先筛查后确认 | 额温枪快速扫一下→高→再用腋温确认 | 快速→额温偏高再确认 |

**推荐购买哪种温度计**：

| 类型 | 推荐 | 原因 |
|------|------|------|
| 电子腋温计 | ⭐首选 | 准确+安全+便宜（20-50元）→30秒出结果 |
| 耳温枪 | 6月+推荐 | 快（1秒）→但6月以下不准→稍贵（150-300元） |
| 额温枪 | 补充用 | 快速筛查→不够准→不能替代腋温/耳温 |
| 水银体温计 | ❌不推荐 | 打碎→汞中毒→已被多国禁用 |

**0-3岁家庭常备药箱**：

> 家有婴儿→常备药=刚需→但"备什么"和"不备什么"同样重要。

**推荐常备**：

| 药品 | 用途 | 注意 |
|------|------|------|
| 对乙酰氨基酚滴剂/混悬液 | 退热止痛（≥3月） | 按体重算剂量→备2种浓度（滴剂/混悬液）→注意区分 |
| 布洛芬混悬液 | 退热止痛（≥6月） | 脱水者不用 |
| ORSⅢ（口服补液盐散Ⅲ） | 腹泻脱水补液 | 按说明书冲泡→不自行配盐水 |
| 生理盐水滴鼻剂/喷鼻剂 | 鼻塞缓解 | 婴儿专用→每侧1-2滴 |
| 炉甘石洗剂 | 痱子/蚊虫叮咬止痒 | 用前摇匀→破损皮肤不用 |
| 氧化锌护臀霜（如Desitin） | 尿布疹预防+治疗 | 每次换尿布后涂→隔离刺激 |
| 润肤霜（大罐装） | 湿疹保湿 | 每周150-200g（全身）→量大才有效 |
| 碘伏棉签 | 小伤口消毒 | 脐带护理不常规使用→但外伤消毒可用 |
| 莫匹罗星软膏 | 皮肤小感染/破损 | 2-3次/日→须医生指导 |

**❌ 不应在家自备/自行使用**：

| 药品 | 禁用原因 |
|------|----------|
| 阿司匹林 | <18岁禁用→瑞氏综合征→致命 |
| 抗生素（阿莫西林/头孢等） | 须医生处方→90%小儿感冒为病毒→抗生素无效→反伤脾胃 |
| 止咳药（含右美沙芬/可待因） | <6岁禁用→抑制咳嗽反射→痰排不出→更危险 |
| 洛哌丁胺（易蒙停） | <2岁禁用→肠麻痹→中毒性巨结肠 |
| 蜂蜜 | <1岁禁用→肉毒杆菌芽孢→致命 |
| 成人感冒药/复方制剂 | 成分复杂→儿童不适用→可能含伪麻黄碱/咖啡因 |

### 八、常见皮肤问题补充

#### 痱子

| 项目 | 内容 |
|------|------|
| 原因 | 汗腺阻塞→汗液滞留→发红发痒 |
| 表现 | 颈部/胸背/褶皱处红色小丘疹→痒 |
| 处理 | 降温→开空调→温水擦洗→薄涂痱子水/炉甘石洗剂→保持皮肤干爽 |
| ⚠️ 不用痱子粉 | 粉末→吸入→肺部→婴儿呼吸道窄→吸入性肺炎风险 |

#### 尿布疹（红屁股）

| 项目 | 内容 |
|------|------|
| 原因 | 尿便刺激+潮湿+摩擦→皮肤发红→重则破皮 |
| 处理 | 勤换尿布（每2-3小时或便后即换）→温水洗→轻按吸干→涂护臀霜（含氧化锌→隔离尿液）→严重时→裸露晾屁股→每天2-3次→每次10-15分钟 |
| ⚠️ | 不用湿巾反复擦→摩擦加重→温水洗更温和；护臀霜要厚涂→像"糊墙"→薄薄一层不够 |

**尿布疹分级处理——从轻到重**：

| 级别 | 表现 | 处理 | ⚠️ |
|------|------|------|-----|
| 轻度 | 皮肤发红→无破损 | 温水冲洗→轻按吸干→厚涂含氧化锌护臀霜→每次换尿布时涂 | 不用湿巾→不用爽身粉 |
| 中度 | 红肿明显+有细小丘疹 | 同上+裸露晾屁股→每天3次→每次15分钟+吹风机冷风吹干（不热风） | — |
| **破皮** | 皮肤破损→渗液→糜烂 | ⚠️ **不直接涂氧化锌霜在开放伤口**→先用温水冲洗→轻按吸干→涂水胶体敷料/医生处方的屏障膏→或涂纯凡士林形成隔离→再覆盖一层薄纱布→换尿布时温水冲→不擦→不撕粘在伤口上的敷料→等它自然脱落 | 湿巾→绝对不用→只能温水冲→轻轻按干→不摩擦 |
| 真菌感染 | 鲜红色+边缘清楚+"卫星灶"（周围零星小红点）+氧化锌无效>3天 | 就医→医生开具抗真菌药膏（如制霉菌素/克霉唑）→不自行用激素药膏→真菌+激素=加重 | 破皮>3天不愈/蔓延/有脓→就医 |
| ⚠️ 就医 | 破皮>3天不愈合+有脓液+蔓延至腹部/大腿+婴儿发热 | 就医→可能需口服抗生素 | — |

#### 脂溢性皮炎（头垢/乳痂）

| 项目 | 内容 |
|------|------|
| 表现 | 头顶黄色油腻鳞屑→厚薄不一→不痒（与湿疹区别） |
| 处理 | 洗澡前30分钟→涂婴儿油/橄榄油→软化→洗澡时用软毛刷轻刷→逐步脱落→不硬抠 |
| 预后 | 多数6-12月自行消退→不硬抠→抠破→感染 |
| ⚠️ | 如果头皮红肿+渗液+蔓延至面部→可能合并湿疹→就医 |

## 第十二部分 1-3岁日常护理操作指南

> 0-1岁有第十一部分手把手教→1-3岁也不能断档。幼儿会走会跑会说话→危险源完全不同→行为引导比喂养更难→这部分补上。

### 一、1-3岁安全防护——与0-1岁完全不同的危险源

| 类别 | 风险 | 预防措施 |
|------|------|----------|
| **攀爬坠落** | 椅子/桌子/窗台/楼梯 | 家具固定到墙上（防倾倒）→窗户安装安全锁/限位器→楼梯上下安装安全门→不让孩子单独在阳台/窗台 |
| **电器** | 插座/电线/电器 | 插座保护盖→电线用理线器收纳→电器不用时拔插头→电热水壶/熨斗放在孩子够不到处 |
| **药品/化学品** | 药品/洗洁精/洁厕灵 | 所有药品/化学品锁在高处柜中→不把药说成"糖"→用完立即收起→不装在饮料瓶里 |
| **走失** | 超市/商场/公园 | 教孩子记住父母名字+电话→出门手牵手→不让孩子离开视线→防走失手环/背包牵引绳 |
| **烫伤（新风险）** | 拉桌布/够灶台/开水杯 | 不用桌布→锅柄朝灶台内侧→热饮不放在桌面边缘→厨房安装安全门 |
| **溺水（新风险）** | 浴缸/马桶/水桶 | 不让孩子单独在浴室→马桶盖关上→浴缸/水桶用完立即倒空→学游泳≠防溺水→仍须看护 |
| **交通** | 电动车/停车场 | 电动车后座安装儿童座椅+脚踏→不让孩子在停车场/车道玩耍→停车场牵手走 |
| **窒息（新风险）** | 硬币/电池/小玩具/整粒食物 | 地面小物件收走→纽扣电池极危险→葡萄/圣女果切四瓣→坚果3岁前不给→果冻3岁前不给 |

### 二、1-3岁情绪与行为引导

> 1-3岁肝常有余→肝气偏旺→易怒易躁→发脾气=肝气郁而化火的外在表现→不是"坏孩子"→是发育阶段。

**撒泼打滚/发脾气**：

| 原则 | 做法 | 原因 |
|------|------|------|
| 保持冷静 | 大人不吼→不骂→不打→蹲下来→平视→"妈妈看到你很生气" | 大人吼→孩子更激动→肝火加肝火→越闹越凶 |
| 接纳情绪 | "生气可以→但打人不可以"→允许情绪→限制行为 | 不接纳→压抑→肝气更郁→更爆 |
| 不妥协不刺激 | 坚持底线→"不可以就是不可以"→不给糖→不因为哭就答应→但也不故意激怒→转身→让孩子安全地发泄 | 妥协→哭闹=有效策略→下次更凶；激怒→越闹越凶 |
| 等冷静后讲道理 | 哭完→抱→"刚才你很生气→因为想吃糖→但是饭前不能吃糖"→简单→1-2句话→不长篇大论 | 情绪中→听不进→白费口舌→冷静后→才能听 |
| 预防 > 处理 | 饥饿/困倦/过度刺激→最容易发脾气→出门前吃好睡好→不带困饿儿逛超市 | 肝常有余+脾常不足→饿→脾虚→肝旺→发脾气 |

**咬人/打人**：

| 场景 | 处理 | 原因 |
|------|------|------|
| 1-2岁出牙期咬人 | 给牙胶→"咬这个→不咬人"→满足口欲→不惩罚 | 出牙不适→不是攻击→给替代 |
| 2-3岁故意打人 | 立即制止→握住手→"不可以打人→打人会痛"→严肃→但不大喊 | 明确边界→让孩子知道不可接受 |
| 争抢时打人 | 分开→"你想要玩具→用嘴巴说→不能打"→教表达→"可以说'给我玩一下吗'" | 不会表达→用行动替代→教语言 |

### 三、如厕训练

> 中医视角：肾主二便→括约肌控制=肾气充盛的标志→18-24月龄肾气渐充→可以开始训练→不早于18月→晚于3岁也正常→每个孩子节奏不同。

**如厕训练准备信号**（以下大部分出现=可以开始）：

| 信号 | 说明 |
|------|------|
| 能听懂简单指令 | "去拿球"→能执行 |
| 尿布干燥>2小时 | 说明膀胱容量够→能控制 |
| 对马桶/厕所感兴趣 | 看大人上厕所→好奇→想模仿 |
| 不喜欢脏尿布 | 拉了→要求换→说明有意识了 |
| 能自己拉下裤子 | 基本自理能力 |

**如厕训练步骤**：

| 步骤 | 做法 | 时间 |
|------|------|------|
| 1. 买儿童马桶 | 让孩子选→放在卫生间→先熟悉→坐一坐→不脱裤子→只是玩 | 1-2周 |
| 2. 定时坐 | 饭后20-30分钟→每天固定3-4个时间→让孩子坐马桶3-5分钟→不强迫→不训斥 | 2-4周 |
| 3. 摘尿布坐 | 熟悉后→脱裤子坐→不期待马上有→习惯"坐马桶"这个动作 | 1-2周 |
| 4. 观察信号 | 孩子突然停下来→蹲→摸裤裆→脸色变化→立刻带去马桶→"你是不是要尿尿？" | 持续观察 |
| 5. 成功→大力表扬 | 成功一次→"太棒了！你会在马桶上尿尿了！"→让孩子有成就感 | — |
| 6. 失败→不批评 | 尿裤子了→"没关系→下次我们争取在马桶上尿"→换裤子→不训斥→训斥→恐惧→抗拒 | — |
| 7. 白天先训练→晚上后训练 | 白天先不穿尿布→晚上仍穿→白天训练成功1-2月后→午睡不穿→夜间不穿 | 白天→夜间约2-3月 |

> ⚠️ **不在以下情况开始训练**：刚搬家/刚入园/刚添弟弟妹妹/生病期间→压力→倒退→等稳定后再开始。

### 四、入园准备

| 类别 | 准备内容 | 中医视角 |
|------|----------|----------|
| 心理准备 | 提前1-2月读幼儿园绘本→参观教室→玩"上学游戏"→减少分离焦虑 | 肝常有余→新环境→肝气郁→焦虑→提前熟悉→疏肝 |
| 自理能力 | 独立吃饭+独立上厕所+表达需求（"老师我要尿尿"）+自己穿鞋 | 脾常不足→不会自理→等待→饿→脾虚→提前训练→健脾 |
| 免疫准备 | **入园后每月1-2次感冒属正常**→持续1-2学期后逐步减少→这是免疫暴露→不是体弱→不必焦虑 | 培土生金→健脾→肺气足→抵抗力↑→入园前1月可做保健推拿加强 |
| 实用物品 | 书包+姓名贴+换洗衣物2套+室内鞋+水杯→所有物品贴姓名贴 | — |
| 生病应对 | 入园后生病→及时休息→不硬送→不因为"刚送就想请假"而愧疚→健康第一 | 脾虚→病中不养→反复→该休则休 |

### 五、挑食偏食具体应对

**常见挑食模式**：

| 模式 | 表现 | 应对策略 |
|------|------|----------|
| 只吃白食 | 只吃米饭/面条/面包→拒绝蔬菜和肉 | 隐藏蔬菜→胡萝卜/菠菜打泥混入米饭→逐渐减少隐藏比例→让孩子习惯味道→同时每餐仍提供可见蔬菜→不强逼→让他自己选择 |
| 食物固化（food jag） | 连续多天只吃一种食物→其他都拒绝 | 允许→不焦虑→这是阶段性→持续提供其他食物→不因为只吃一种就不提供→"吃不吃是你的事→提供是我的事"→通常2-4周自行过渡 |
| 质地拒绝 | 拒绝颗粒状/块状→只接受泥状 | 从泥→碎→小颗粒→逐步过渡→每次只提升一小步→不跳级→让孩子有时间适应新口感 |
| 拒绝新食物 | 看到新食物就摇头推开 | **8-15次反复暴露**→每次放在盘中→不吃也放→看→摸→舔→一小口→多次接触后可能接受→不强迫→"你可以不吃→但它在这里" |

### 六、1-3岁屏幕时间建议

| 月龄 | 建议 | 原因 |
|------|------|------|
| 0-18月 | **避免所有屏幕**（视频通话除外） | 大脑快速发育期→屏幕→被动接收→阻碍主动探索→注意力发展受影响 |
| 18-24月 | 可少量→但须大人陪伴→一起看→解释内容 | 不陪伴→不理解→只是光影刺激→无教育意义 |
| 2-3岁 | 每日≤1小时→每次≤20分钟→内容选慢节奏→无闪烁→无广告 | 肝常有余→视觉过度刺激→肝火上炎→烦躁/夜啼/注意力差→少看→多户外→疏肝 |
| 所有年龄 | 睡前1小时不看→吃饭时不看→不作为安抚工具 | 睡前看→蓝光→抑制褪黑素→入睡困难；吃饭看→注意力在屏幕→不知饱→过量→积食 |

### 八、焦三仙水完整煮法

| 项目 | 说明 |
|------|------|
| 配方 | 焦山楂3g+焦麦芽3g+焦神曲3g |
| 加水量 | 300ml冷水→浸泡5分钟→大火烧开→转小火煮10分钟→剩约100ml→过滤 |
| 喂法 | 温服→不凉不热→分2-3次→饭后30分钟喝→每次约30-50ml |
| 味道 | 酸涩微焦→婴儿可能拒绝 |
| 婴儿拒喝怎么办 | ①混入米汤→稀释味道→药效不减→只是浓度降低→可适当多喝一点弥补 ②用喂药滴管→少量→嘴角滴入→不直接灌→防呛 ③加1-2g冰糖→微甜→可接受→不加重→不改变药性→**不加蜂蜜**（1岁以下禁用） |
| 疗程 | **不超3天**→消食不健脾→久用伤脾→3天后仍积食→就医→不自行继续 |

## 附录一 0-3岁常用中成药速查

> ⚠️ **以下为家长了解用，不自行给药。小儿用药须医生辨证后使用。剂量由医生根据体重和病情确定。**

| 药名 | 主要成分 | 功效 | 适用证 | 注意 |
|------|----------|------|--------|------|
| **保和丸** | 山楂、神曲、半夏、茯苓、陈皮、连翘、莱菔子 | 消食导滞、和胃 | 食积停滞→脘腹胀满、嗳腐吞酸 | 消食不健脾→不长期用→积食消后停药 |
| **小儿健脾丸** | 党参、白术、茯苓、甘草、山药、莲子等 | 健脾益气 | 脾虚→食少便溏、面色萎黄 | 补而不滞→可较长时间服用 |
| **王氏保赤丸** | 大黄、黄连、巴豆霜、朱砂等 | 祛滞、健脾、化痰 | 乳滞疳积→呕吐腹泻、脾胃虚弱 | 含泻下药+朱砂（含汞）→**须医生指导**→不可自行长期用→不作为常规消食药 |
| **藿香正气水（儿童剂型）** | 藿香、紫苏、白芷等 | 解表化湿、理气和中 | 暑湿感冒/胃肠型感冒 | ⚠️ 酒精含量高→儿童**禁用**含醇剂型→须用无醇颗粒/口服液 |
| **小儿肺热咳喘口服液** | 麻黄、苦杏仁、石膏等 | 清热解毒、宣肺化痰 | 肺热咳嗽 | 风寒咳嗽忌用 |
| **健胃消食片** | 太子参、陈皮、山药、麦芽、山楂 | 健脾消食 | 脾虚食积→消化不良 | 日常助消化可用→不替代正餐调控 |

> ⚠️ **用药铁律**：
> 1. 小儿用药"中病即止"——见效就停→不巩固→不预防性给药
> 2. 不自行同时用多种中成药→成分可能重复→过量
> 3. 不把中成药当保健品长期吃→"是药三分毒"→消食药久用伤脾
> 4. <6月婴儿不自行给任何药物→必须就医
> 5. 退烧药选一种（对乙酰氨基酚或布洛芬）→按体重算剂量→不常规交替使用→6月以下婴儿发热必须就医→不可自行给退烧药

## 附录四 0-3岁大便对照卡

### 正常大便

| 月龄 | 喂养方式 | 正常表现 | 频次 |
|------|----------|----------|------|
| 0-1月 | 纯母乳 | 金黄糊状、微酸味 | 每日2-5次（初胎便为墨绿色→3天内转黄） |
| 0-1月 | 配方奶 | 淡黄成形、味稍臭 | 每日1-3次 |
| 1-6月 | 母乳 | 金黄糊状 | 每日1-4次（有的数天1次但性状正常→也可能正常） |
| 1-6月 | 配方奶 | 淡黄成形 | 每日1-2次 |
| 6-12月 | 混合喂养 | 黄色成形或糊状 | 每日1-2次 |
| 1-3岁 | 以食为主 | 黄色成形、类似成人 | 每日1次 |

### 需关注的大便

| 表现 | 可能原因 | 初步处理 |
|------|----------|----------|
| 绿色稀便 | 受凉 / 铁未吸收 | 注意保暖；观察1-2天 |
| 酸臭+奶瓣 | 伤食（消化不良） | 减食+焦三仙水 |
| 泡沫+肠鸣 | 风寒泻 / 乳糖不耐受 | 保暖；持续→排查乳糖不耐受 |
| 羊屎状干硬 | 便秘 | 多饮水+多食蔬果+顺时针揉腹 |
| 黏液便 | 肠道刺激/感染 | 观察→持续或加重→就医 |

### 紧急就医的大便

| 表现 | 可能原因 | 紧急程度 |
|------|----------|----------|
| 白色陶土样 | 胆道阻塞 | ⚠️ **紧急** |
| 果酱样（红+黏液） | 肠套叠 | ⚠️ **紧急** |
| 鲜血便 | 肛裂/过敏/肠息肉 | ⚠️ **就医** |
| 黑色柏油样 | 上消化道出血 | ⚠️ **紧急** |
| 水样大量腹泻+精神差 | 脱水风险 | ⚠️ **紧急** |

> 📝 **新生儿胎便→过渡便→正常便变化过程**：

| 时间 | 大便 | 颜色 | 性状 | 说明 |
|------|------|------|------|------|
| 出生24小时内 | 胎便 | 墨绿→近黑 | 黏稠→像柏油→无臭 | 正常→由羊水吞入的脱落细胞+胆汁+黏液组成→3-5次后排完 |
| 第2-3天 | 过渡便 | 绿褐→黄绿 | 渐稀→渐糊 | 胎便与奶便混合→颜色过渡→正常 |
| 第4-5天 | 奶便 | 金黄（母乳）/淡黄（配方奶） | 糊状→有酸味（母乳）/稍臭（配方奶） | 说明吃到了足够的奶→如果第5天仍排胎便→奶量可能不够→须咨询 |

> ⚠️ **出生24小时内无胎便→须排查消化道畸形**；第5天仍为墨绿胎便→喂养量可能不足→须评估。
