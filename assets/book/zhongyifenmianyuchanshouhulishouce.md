## 第一章 妊娠生理

### 一、怀孕的本质

中医认为，怀孕的本质是"两条命共享一套气血系统"。

- **母体**：自身气血养胎，气血既要维持自身，又要供给胎儿
- **胎儿**：全靠母体气血，没有独立气血来源，完全依赖母体

类比关系：

```
母体 = 树根（吸收营养）
脐带 = 树干（传输通道）
胎儿 = 果实（最终结果）
```

根旺→果壮，根弱→果萎。

### 二、胎儿靠什么养

| 系统 | 中医术语 | 功能 | 类比 |
|------|----------|------|------|
| 冲脉 | "冲为血海" | 储存和供给血液 | 血库/输油管 |
| 任脉 | "任主胞胎" | 固摄胎儿、维持妊娠 | 安保系统/安全带 |

**冲脉供血，任脉固胎**——冲脉是"供能系统"，任脉是"安保系统"。

### 三、冲脉与任脉的位置

#### 任脉

| 项目 | 内容 |
|------|------|
| 走向 | 从下往上，沿人体前正中线 |
| 起点 | 会阴（小腹内，耻骨联合后方） |
| 终点 | 承浆（下嘴唇下方凹陷处） |
| 经过 | 小腹→肚脐→胸口→咽喉→下巴 |
| 俗称 | "前正中线" |

定位口诀：从肚脐正中往下摸到耻骨，再往上沿中线到胸口到喉咙到下巴——这条线就是任脉。

#### 冲脉

| 项目 | 内容 |
|------|------|
| 走向 | 从下往上，沿腹部正中旁开半寸（约一横指宽） |
| 起点 | 会阴（与任脉同起点） |
| 主干 | 紧贴任脉两侧，几乎并行上行 |
| 上行支 | 夹脐上行→散于胸中→灌注诸经 |
| 下行支 | 沿大腿内侧下行→足大趾 |
| 俗称 | "血海"，和任脉像是"双轨并行" |

#### 两脉位置关系

```
       ← 胸口 →
     ┃    ┃    ┃
   冲脉  任脉  冲脉
   (左)  (中)  (右)
     ┃    ┃    ┃
     ┃  肚脐  ┃
     ┃    ┃    ┃
     ┃    ┃    ┃
     ┃  子宫区  ┃  ← 两脉都汇聚在此
     ┃    ┃    ┃
     └────┴────┘
        会阴
```

- 起点相同：都起于会阴/小腹内
- 走向相似：都从下往上走腹部
- 位置相邻：冲脉在任脉两侧，间隔仅半寸
- 汇聚区域：小腹部（子宫区）是两脉核心交汇点

#### 生动理解

| | 任脉 | 冲脉 |
|--|------|------|
| 比作 | 安全带 | 输油管 |
| 功能 | 固定胎儿不滑落 | 输送气血养胎儿 |
| 位置 | 正中间，像安全带扣在正中 | 两侧，像输油管从两边供油 |
| 出问题 | 安全带松了→胎儿滑落（流产） | 输油管堵了→胎儿缺油（发育迟缓） |

### 四、关键穴位

| 穴位 | 位置 | 所属经脉 | 作用 |
|------|------|----------|------|
| 关元 | 肚脐正下方3寸（约4横指） | 任脉 | 补肾固胎，孕期保健要穴 |
| 气海 | 肚脐正下方1.5寸（约2横指） | 任脉 | 补气培元 |
| 中极 | 肚脐正下方4寸 | 任脉 | 调理冲任，治妇科 |
| 气冲 | 耻骨旁开2寸 | 冲脉 | 冲脉起始穴，降气平冲 |

整个下腹部（肚脐到耻骨之间）就是冲任二脉的"主战场"。

### 五、总论核心总结

```
脉的本质：气血之先（比症状更早报警）
脉的动力：资始于肾（命门之火推动）
脉的充盈：资生于胃（水谷精微充盈）
脉的运行：随气而至（气是帅，脉是影）
脉的诊断：有是病必有是脉（脉病相应）
```

## 第二章 孕期变化与调养

### 一、妊娠呕吐（恶阻）

#### 发生机理

```
怀孕 → 冲脉聚血养胎 → 冲脉气血充盈
                ↓
        正常：冲气下行 → 养胎 → 无呕吐
        异常：冲气上逆 → 冲犯胃气 → 胃气也跟着上逆 → 呕吐
```

核心：不是冲脉"太强"，而是冲脉之气**方向反了**——该往下走的结果往上冲。

#### 孕早期最明显的原因

| 时期 | 冲脉状态 | 呕吐情况 |
|------|----------|----------|
| 孕早期（1-3月） | 冲脉骤然充盈，气最盛 | 呕吐最严重 |
| 孕中期（4-6月） | 冲脉适应状态，气渐平 | 减轻或消失 |
| 孕晚期（7-9月） | 胎儿下降，冲气不再上冲 | 基本无呕吐 |

#### 治疗

核心思路：降冲气 + 和胃气

| 治法 | 原理 | 具体方法 |
|------|------|----------|
| 降冲平逆 | 把往上冲的气压下去 | 针灸内关、足三里 |
| 和胃止呕 | 帮助胃气恢复正常下降 | 陈皮、砂仁、生姜 |
| 健脾益气 | 增强胃的"防守力" | 白术、茯苓 |

#### 仲景经方正治：干姜人参半夏丸

| 项目 | 内容 |
|------|------|
| 出处 | 《金匮要略·妇人妊娠病脉证并治第二十》JGL-21-006 |
| 原文 | "妊娠，呕吐不止，干姜人参半夏丸主之。" |
| 组成 | 干姜一两、人参一两、半夏二两 |
| 制法 | 上三味，末之，以生姜汁糊为丸，如梧子大 |
| 服法 | 饮服十丸，日三服 |
| 功效 | 温中散寒，益气降逆止呕 |
| 辨证要点 | 呕吐不止（非偶呕）、伴胃寒之象（口淡、喜热饮、舌淡）、脉偏弱 |

**为何此方是恶阻正治**：

```
妊娠恶阻核心病机：冲气上逆 + 胃虚寒

干姜 → 温中散寒（治胃虚寒之本）
人参 → 益气补中（治胃虚之本）
半夏 → 降逆止呕（治冲气上逆之标）
生姜汁糊丸 → 助半夏降逆，且解半夏之毒

三味药恰好覆盖了恶阻的三个环节
```

**与一般止呕法的区别**：

| 方法 | 作用层次 | 适用 |
|------|----------|------|
| 陈皮砂仁生姜 | 和胃降逆，偏于理气 | 呕吐轻证 |
| 干姜人参半夏丸 | 温中+益气+降逆，标本兼治 | **呕吐不止**（反复呕吐、经久不愈） |
| 针灸内关足三里 | 经络层面调气 | 辅助配合 |

**禁忌**：阴虚火旺者（口干舌红、脉细数）不宜用干姜之温燥；呕吐伴发热者须辨证，非单纯虚寒者不可用。

### 二、血聚于下，气浮于上

孕期母体的气血分布：

```
血 → 聚于下（小腹养胎）→ 上半身相对缺血
气 → 浮于上（往上冲）  → 上半身气偏盛
```

| | 气的状态 | 血的状态 | 结果 |
|--|---------|---------|------|
| 上半身 | 气偏盛（浮上来） | 血相对不足（下去了） | 气多血少 |
| 下半身 | 气相对不足 | 血聚于此养胎 | 血多气相对少 |

#### 上半身表现

| 症状 | 原理 |
|------|------|
| 面红、潮热 | 气浮于上→上部阳气偏盛→虚火上浮 |
| 头晕目眩 | 气往上冲+血跟不上→清窍失养 |
| 心烦易怒 | 气浮扰心→心神不宁 |
| 口干口苦 | 虚火上炎→灼伤津液 |
| 失眠 | 气浮于上→心神不安 |

中医叫"戴阳"——下面虚寒，上面虚火浮越，脸反而红红的。这不是气血充足的红，而是虚火的红。

#### 下半身表现

| 症状 | 原理 |
|------|------|
| 小腹重坠 | 血聚于下+胎儿重量→下焦负重 |
| 腰酸 | 肾气不足+负重 |
| 下肢水肿 | 气虚不能运化水湿+下焦血聚压迫 |
| 下肢发凉 | 气浮于上→下面相对缺气温煦 |

### 三、妊娠期经方正治（《金匮·妇人妊娠病》）

> 仲景对妊娠病的论述与产后病同等重要。以下经方均出自《金匮要略·妇人妊娠病脉证并治第二十》，按临床常见程度排列。

#### 1. 妊娠呕吐——干姜人参半夏丸

（已见本章第一节，此处不重复）

#### 2. 妊娠腹痛——当归芍药散

| 项目 | 内容 |
|------|------|
| 原文 | "妇人怀妊，腹中㽲痛，当归芍药散主之。"（JGL-20-005） |
| 组成 | 当归三两、芍药一斤、芎藭半斤、茯苓四两、白术四两、泽泻半斤 |
| 功效 | 养血疏肝、健脾利湿 |
| 辨证要点 | 妊娠腹痛绵绵+面色萎黄+下肢水肿或小便不利 |

**此方是妊娠腹痛最常用的经方**。方中芍药一斤为君——酸收敛阴缓急止痛；当归、川芎养血活血；茯苓、白术、泽泻健脾利湿。血虚+湿滞并见者最宜。

#### 3. 妊娠胞阻（胎漏/先兆流产）——胶艾汤

| 项目 | 内容 |
|------|------|
| 原文 | "妇人有漏下者，有半产后因续下血都不绝者，有妊娠下血者，假令妊娠腹中痛，为胞阻，胶艾汤主之。"（JGL-20-004） |
| 组成 | 芎藭、阿胶、甘草各二两，艾叶、当归各三两，芍药四两，干地黄四两 |
| 功效 | 养血止血、调经安胎 |
| 辨证要点 | 妊娠阴道出血+腹中痛——冲任不固、阴血失守 |

> ⚠️ **妊娠阴道出血无论量多少，必须先就医排除宫外孕、胎盘前置等器质性问题，再考虑中医安胎。** 胶艾汤适用于冲任不固的虚证出血，实证（热迫血行）不宜。

#### 4. 妊娠小便难——当归贝母苦参丸

| 项目 | 内容 |
|------|------|
| 原文 | "妊娠，小便难，饮食如故，当归贝母苦参丸主之。"（JGL-20-007） |
| 组成 | 当归、贝母、苦参各四两 |
| 功效 | 养血润燥、清热利小便 |
| 辨证要点 | 妊娠小便困难（尿频尿急或排尿不畅）+饮食正常——血虚+郁热下注膀胱 |

**与西医"妊娠期尿路感染"有交叉**——但此方针对的是血虚+郁热，不是湿热下注。若尿频尿急尿痛+舌苔黄腻=湿热→不宜此方。

#### 5. 妊娠水气（水肿）——葵子茯苓散

| 项目 | 内容 |
|------|------|
| 原文 | "妊娠有水气，身重，小便不利，洒淅恶寒，起即头眩，葵子茯苓散主之。"（JGL-20-008） |
| 组成 | 葵子一斤、茯苓三两 |
| 功效 | 通窍利水 |
| 辨证要点 | 妊娠水肿+小便不利+头眩——水气内停 |

> ⚠️ 葵子（冬葵子）滑利，有通利下行之性。仲景用之治妊娠水气，但量须严格控制，须在医师指导下使用。

#### 6. 妊娠养胎——当归散与白术散

仲景对妊娠养胎有两首专方，证治不同：

| | 当归散（JGL-20-009） | 白术散（JGL-20-010） |
|---|----------------------|----------------------|
| 原文 | "妇人妊娠，宜常服当归散" | "妊娠养胎，白术散主之" |
| 组成 | 当归、黄芩、芍药、芎藭各一斤，白术半斤 | 白术、芎藭各四分，蜀椒三分，牡蛎二分 |
| 功效 | 养血健脾、清热安胎 | 健脾温中、除湿安胎 |
| 适用体质 | 血虚有热者（口干、尿黄、舌偏红） | 脾虚有寒湿者（便溏、怕冷、苔白润） |
| 方义 | 当归+芍药+川芎养血，黄芩清热，白术健脾——血热者养胎 | 白术健脾，蜀椒温中散寒，牡蛎固涩除湿，川芎行血——寒湿者养胎 |

**两方一清一温，体现了仲景"随证治之"的核心——同样是养胎，体质不同则方不同。** 不可不辨证就"常服当归散"——阴虚有热者宜，阳虚有寒者服之反助热伤胎。

## 第三章 冲任诊断

> **本章说明**：本章内容涉及脉诊、腹诊等专业诊断方法，供陪护人员或中医从业者参考学习。孕妇如对自身冲任状态有疑问，建议由专业中医师操作判断，不必自行摸脉。

### 一、方法①：从症状推断

#### 任脉虚弱的信号

| 症状 | 原理 | 判断 |
|------|------|------|
| 孕早期腰酸、小腹下坠 | 任脉无力固摄→胎气下坠 | 任脉虚 |
| 阴道少量出血（胎漏） | 任脉固血无力→血溢脉外 | 任脉明显虚 |
| 反复流产（滑胎） | 任脉彻底守不住胎 | 任脉严重虚 |
| 小腹发凉 | 任脉气血不足→失于温煦 | 任脉虚寒 |
| 白带清稀量多 | 任脉不能固摄津液 | 任脉虚 |

#### 任脉充盈的信号（正常）

| 症状 | 原理 | 判断 |
|------|------|------|
| 孕期小腹温润有力 | 任脉固摄正常→胎安 | 任脉正常 |
| 无腰酸下坠感 | 任脉托住胎儿 | 任脉正常 |
| 胎位稳定 | 任脉固胎有力 | 任脉正常 |

#### 冲脉虚弱的信号

| 症状 | 原理 | 判断 |
|------|------|------|
| 胎儿偏小、发育迟缓 | 冲脉血少→供给不足 | 冲脉虚 |
| 孕妇面色苍白、唇色淡 | 冲为血海，血海不足→面色无华 | 冲脉血虚 |
| 孕妇心悸、失眠 | 血不养心 | 冲脉血虚 |
| 乳汁不足（产后） | 冲脉不能化血为乳 | 冲脉虚 |

#### 冲脉上逆的信号

| 症状 | 原理 | 判断 |
|------|------|------|
| 妊娠呕吐严重 | 冲气上逆犯胃 | 冲气上逆 |
| 胸满气逆 | 冲气上冲至胸 | 冲气上逆 |
| 呃逆不止 | 冲气上逆动膈 | 冲气上逆 |

### 二、方法②：腹部触诊（腹诊）

操作：平躺→双腿微屈→放松腹部→用手掌轻按小腹

| 触感 | 判断 | 说明 |
|------|------|------|
| 温暖、柔软、有弹性 | 冲任正常 | 气血充盈，温煦有力 |
| 发凉、松软、按之无力 | 冲任虚寒 | 气血不足，失于温煦 |
| 紧绷、硬满、压痛 | 冲气郁滞 | 气血不通，郁而化实 |
| 按之有抵抗感、拒按 | 冲任瘀阻 | 气血瘀滞在小腹 |

核心口诀：**喜按为虚，拒按为实；温软为常，凉硬为异。**

### 三、方法③：脉诊（尺脉定冲任）

寸关尺三部分候脏腑，尺部直接反映肾与冲任：

| 尺脉表现 | 判断 | 说明 |
|----------|------|------|
| 尺脉沉细无力 | 冲任虚 | 气血不足，肾虚冲任弱 |
| 尺脉滑利和缓 | 冲任正常 | 孕期滑脉为正常（气血充盈养胎） |
| 尺脉弦涩 | 冲任瘀滞 | 气血运行不畅 |
| 尺脉洪大 | 冲气偏盛 | 可能冲气上逆 |

注意：孕后尺脉偏滑是正常的（怀孕本身就会出现滑脉），只有异常偏弱或异常偏盛才需关注。

### 四、方法④：穴位按压

| 穴位 | 位置 | 按压反应 | 判断 |
|------|------|----------|------|
| 关元 | 脐下3寸 | 酸胀舒适 | 正常 |
| | | 疼痛拒按 | 瘀阻 |
| | | 按之无力、发凉 | 虚寒 |
| 气海 | 脐下1.5寸 | 同上 | 同上 |
| 中极 | 脐下4寸 | 同上 | 同上 |
| 三阴交 | 内踝尖上3寸 | 酸胀正常 | 冲任通 |

自查口诀：按着酸胀=正常通；按着疼=不通；按着空=不足。

## 第四章 临产征兆

### 一、试胎、弄胎、正产

| | 试胎 | 弄胎 | 正产 |
|--|------|------|------|
| 发生时间 | 孕8-9月 | 临近预产期 | 足月 |
| 疼痛 | 偶尔发紧 | 阵发性，似真非真 | 阵发性，越来越强 |
| 规律性 | 无规律 | 假规律（不递进） | 真规律（递进式） |
| 间隔 | 不定 | 不缩短 | 越来越短 |
| 持续时间 | 几秒就过 | 不延长 | 越来越长 |
| 疼痛趋势 | 不加重 | 不加重 | 越来越强 |
| 宫口变化 | 不开 | 不开 | 逐渐开大 |
| 处理 | 不用管 | 观察 | 立即去医院 |

### 二、最核心的判断标准：三个"越来越"

```
正产的铁律：
  间隔 → 越来越短（10分钟→5分钟→3分钟→2分钟）
  时间 → 越来越长（30秒→45秒→60秒→90秒）
  痛感 → 越来越强（能忍→咬牙→无法忍受）
```

只有同时满足三个"越来越"，才是正产。

### 三、正产五大征兆

| 征兆 | 俗称 | 说明 |
|------|------|------|
| 阵痛递进 | 规律宫缩 | 核心标志 |
| 见红 | 宫颈黏液栓脱落+少量出血 | 通常24-48小时内生产 |
| 破水 | 胎膜破裂羊水流出 | 需紧急就医 |
| 腰腹坠胀 | 胎儿下降压迫 | — |
| 便意感 | 胎头压迫直肠 | — |

重要性排序：阵痛递进 > 见红 > 破水（破水最危险：不管有没有宫缩都要立即平躺去医院）

### 四、判断流程

```
肚子疼了？
    ↓
疼痛有规律吗？
    ├── 没有 → 试胎（不用担心）
    │
    └── 有规律 → 三个"越来越"满足吗？
          ├── 不满足（不递进）→ 弄胎（继续观察）
          │
          └── 满足（递进式加重）→ 正产！→ 立即去医院
```

## 第五章 孕期调护与顺产准备

> **本章目的**：分娩是否顺利，很大程度取决于孕期如何调养。仲景虽未专论"顺产准备"，但《金匮·妇人妊娠病》的核心思想——"当随证治之、护养胎元"——贯穿始终。本章从中医气血冲任理论出发，结合临床实际，给出从孕早期到临产的逐阶段调护指导，帮助孕妇为顺利分娩做好身体准备。

### 一、顺产的三要素与中医对应

西医总结顺产三要素：产力、产道、胎儿。中医对应如下：

| 西医要素 | 中医对应 | 顺产要求 | 失调后果 |
|----------|----------|----------|----------|
| 产力（宫缩力） | 气血充沛、气能推动 | 气足→宫缩有力→产程顺利 | 气虚→宫缩乏力→滞产 |
| 产道（骨盆+软产道） | 冲任通畅、胞脉舒展 | 冲任无阻滞→产道开合自如 | 气滞血瘀→产道紧缩→难产 |
| 胎儿（大小+位置） | 胎气调和、胎位正 | 胎气顺→胎儿自然转正 | 胎气不顺→胎位异常 |

```
顺产 = 气足（推得动）+ 冲任通（开得了）+ 胎气正（位得对）
              ↓                    ↓                   ↓
          孕期养气血            孕期调气活血          孕期适当活动
```

### 二、孕早期（1-3月）：固胎安冲

孕早期最核心的任务不是"为顺产准备"，而是**固胎**——先保住，再谈后续。

#### 常见问题与调护

| 问题 | 中医认识 | 调护原则 | 具体做法 |
|------|----------|----------|----------|
| 恶阻（呕吐） | 冲气上逆（详见第二章） | 降冲和胃 | 干姜人参半夏丸（重证）；轻证：生姜3片煮水+陈皮3g代茶 |
| 腰酸腹坠 | 任脉不固→胎气下坠 | 固任安胎 | 避免久站久蹲；卧床休息为主 |
| 阴道少量出血（胎漏） | 冲任不固→血不归经 | 止血安胎 | **立即就医**，中医方向：胶艾汤（JGL-20-004）——须执业医师辨证 |

#### 孕早期禁忌

| 禁忌 | 原因 |
|------|------|
| 激烈运动/搬重物 | 冲任初聚养胎，外力扰动→冲任不固→流产风险 |
| 情绪大起大落 | 怒则气上→冲气上逆→加重恶阻；恐则气下→胎气下坠 |
| 房事 | 早期冲任未稳→房事扰动→最易引发流产 |
| 乱用药 | 孕早期是胎儿器官形成期，任何药物须经医师确认 |

> ⚠️ **孕早期出现阴道出血，无论量多少，必须就医。** 不要自行判断"量少没关系"，也不要自行服保胎药。胎漏的辨证须由医师完成——虚者补之（胶艾汤方向），热者清之，瘀者慎之，不可一律"补"。

### 三、孕中期（4-6月）：养气血、调冲任

孕中期是相对平稳的阶段，恶阻渐消、胎气渐稳。**这是为顺产打基础的关键窗口期。**

#### 3.1 养气血——为产力储备

```
分娩要消耗大量气血 → 气足则宫缩有力 → 气虚则宫缩乏力 → 滞产

孕期养气血 = 给"产力"充值
  养血：红枣、桂圆、枸杞、当归（孕中期少量可用，早期不用）
  补气：山药、莲子、黄芪（孕中晚期可在医师指导下少量使用）
  养脾胃：脾胃为气血生化之源 → 脾胃好 → 气血自然充
```

**养脾胃优先于直接补气血**——脾胃是气血的"工厂"，工厂运转正常，原料（食物）自然化为气血。脾胃虚弱→吃再多补品也化不了。

| 养脾胃方法 | 做法 | 注意 |
|-----------|------|------|
| 山药粥 | 鲜山药50g+大米50g煮粥 | 每日1碗，温和不燥 |
| 茯苓山药粥 | 茯苓粉10g+鲜山药30g+大米 | 健脾渗湿，孕期水肿者尤宜 |
| 规律饮食 | 定时定量，不过饥过饱 | 伤脾胃最甚的是饮食不规律 |
| 忌寒凉 | 少吃生冷瓜果、冰饮 | 寒伤脾阳→运化减弱→气血生化不足 |

#### 3.2 适当活动——气行则血行

"孕期要静养"是片面的。过度静卧→气滞血瘀→反而不利顺产。仲景未反对孕妇活动，临床实际也证实：适量活动有利于顺产。

| 活动 | 适合孕期 | 作用 | 注意 |
|------|----------|------|------|
| 散步 | 孕中期起，每日30分钟 | 气血流通→冲任舒畅 | 不觉疲劳为度 |
| 孕妇瑜伽 | 孕中期，在专业指导下 | 柔韧骨盆韧带+调息 | 未经指导不可自行练 |
| 爬楼梯 | 孕晚期（37周后） | 助胎头下降 | 有早产风险者禁用 |
| 家务轻活 | 全孕期 | 保持气血流通 | 不提重物、不久蹲 |

**禁忌活动**：跳跃、快跑、搬重物、久蹲久站、腹部受压的体位。

#### 3.3 控制体重——胎大则难产

这是临床最常见的难产原因之一，中医古籍早有论述。

《诸病源候论》明确指出：孕妇"不可过食肥甘"——胎儿过大→产道相对狭窄→难产。

| 孕期增重参考 | 范围 | 说明 |
|-------------|------|------|
| 孕前BMI<18.5（偏瘦） | 增重12.5-18kg | 偏瘦者需多长 |
| 孕前BMI 18.5-24（正常） | 增重11.5-16kg | 标准范围 |
| 孕前BMI>24（偏胖） | 增重7-11.5kg | 偏胖者少长 |
| 整个孕期 | 每周增重不超过0.5kg为安全 | 短期暴增→水肿或巨大儿 |

**最危险的饮食误区**：孕中晚期大量喝浓汤（猪蹄汤、浓鸡汤）→既增母体脂肪，又促进胎儿过大。孕期营养重"质"不重"量"——蛋白质、铁、钙比浓汤重要得多。

### 四、孕晚期（7-9月）：助胎下降、防早产

孕晚期两大任务：**助胎头入盆** + **预防早产**。

#### 4.1 助胎下降

胎头入盆是顺产的前提。入盆时机因人而异：初产妇多在孕36-38周入盆，经产妇可能临产时才入盆。

| 方法 | 做法 | 原理 | 注意 |
|------|------|------|------|
| 散步 | 每日30-40分钟 | 重力+骨盆晃动→助胎头下降 | 有早产征兆者停止 |
| 爬楼梯 | 每日2-3层，慢上慢下 | 骨盆运动+重力辅助 | 37周后使用，有早产风险者禁用 |
| 坐分娩球 | 坐在瑜伽球上轻轻左右晃动 | 骨盆开合→助胎头对准产道 | 须有人保护，防跌倒 |
| 艾灸至阴穴 | 艾条悬灸双侧至阴穴（足小趾外侧指甲角旁），每次15分钟，每日1-2次 | 至阴穴是足太阳膀胱经井穴→膀胱经与肾经相表里→灸之可调冲任、转胎位 | **胎位不正时使用**（臀位→头位），须在医师指导下进行，36周前效果最好 |

> 📝 **艾灸至阴穴转胎位**是中医临床确有实效的方法。现代研究亦有报道，其机理可能与艾灸刺激→子宫放松→胎儿活动空间增大→自行转位有关。但须强调：须在B超确认无脐带绕颈等禁忌后、在医师指导下进行。

#### 4.2 预防早产

| 早产征兆 | 表现 | 处理 |
|----------|------|------|
| 规律宫缩（<37周） | 每10分钟内宫缩≥2次，持续30秒以上 | **立即就医** |
| 见红（<37周） | 少量阴道出血或血性分泌物 | **立即就医** |
| 破水（<37周） | 阴道突然流出清亮液体 | **立即平卧、垫高臀部、急就医** |
| 下坠感明显 | 感觉胎儿往下掉、压迫感骤增 | 就医检查 |

**预防早产的日常注意**：

| 避免 | 原因 |
|------|------|
| 过度劳累 | 劳则气耗→气虚不固→冲任失摄 |
| 情绪激动 | 怒恐→气乱→冲任不宁 |
| 跌扑外伤 | 直伤冲任→扰动胎气 |
| 性生活 | 孕晚期宫缩敏感→性刺激可诱发宫缩 |
| 不明偏方 | 某些"催生"偏方含麝香、红花→可致早产 |

### 五、临产前的准备

#### 5.1 何时去医院——出发信号

第四章已详述临产征兆的辨别，此处给出简明的"出发判断"：

| 信号 | 是否出发 | 说明 |
|------|----------|------|
| 规律宫缩：每5-6分钟一次，每次≥30秒 | ✅ **出发** | 初产妇宫口开3cm前到院即可 |
| 见红：少量粉红/暗红分泌物 | ⏳ 观察 | 见红后通常12-48小时临产，可先洗澡吃饭，不必慌张 |
| 见红：量多如月经或鲜红 | ✅ **立即出发** | 量多≠正常见红，须排除前置胎盘/胎盘早剥 |
| 破水：清亮液体从阴道流出 | ✅ **立即出发** | 破水后感染风险递增，须尽快到院 |
| 破水+液体浑浊/绿色 | ✅🚨 **紧急出发** | 浑浊=胎粪污染→胎儿窘迫→争分夺秒 |
| 胎动明显减少或消失 | ✅🚨 **紧急出发** | 随时可能胎儿缺氧 |

**破水后的正确处理**：

```
破水 → 立即平卧 → 臀下垫枕头/被子抬高臀部 → 垫好卫生巾
     → 不要站立走动（站立→羊水流失更快→脐带脱垂风险）
     → 不要洗澡（感染风险）
     → 立即出发去医院
```

> ⚠️ **初产妇不必过早就医**：宫缩刚开始时（间隔>5分钟、可忍受），可以在家休息、少量进食、观察进展。过早到院→等待时间长→焦虑疲劳→反而不利。但**经产妇**产程快，有规律宫缩即可出发。

#### 5.2 待产包

| 类别 | 物品 |
|------|------|
| 证件 | 身份证、医保卡、产检记录、孕期检查报告 |
| 产妇用品 | 睡衣2-3套（前开扣方便哺乳）、产妇卫生巾、一次性内裤、毛巾、保温杯、吸管（卧床喝水用） |
| 哺乳用品 | 哺乳内衣、防溢乳垫 |
| 宝宝用品 | 新生儿衣服、包被、纸尿裤、湿巾 |
| 中药外敷 | 大黄芒硝1:4混合粉末装纱布袋（会阴肿胀备用，见第十二章） |
| 食物 | 红糖、生姜（产后煮红糖姜水用）、易消化的零食（小面包、藕粉、巧克力） |
| 其他 | 手机充电器、现金/银行卡 |

> 📝 **待产包建议在孕36周前准备好**，放在固定位置，随时提了就走。

#### 5.3 产前饮食

临产前的饮食原则：**高热量、易消化、不过饱**。

| 推荐 | 原因 |
|------|------|
| 藕粉/小米粥 | 高热量+易消化→为产程储能 |
| 鸡蛋1-2个 | 优质蛋白→耐饥饿 |
| 巧克力/红糖水 | 快速供能→第二产程消耗大时补充 |
| 少量多次 | 不宜一次吃太饱→呕吐风险 |

**禁忌**：产前不要吃油腻难消化的食物→产程中呕吐→误吸风险；不要空腹上阵→体力不足→宫缩乏力。

#### 5.4 产前呼吸法——调息减痛

中医"调息"与产科学界公认的拉玛泽呼吸法完全相通——核心都是"通过呼吸调节，放松肌肉、减轻疼痛、保存体力"。

**第一产程（宫口未全开）——慢呼吸**：

```
宫缩来时：
  ① 用鼻子缓慢深吸气（4秒）
  ② 用嘴巴缓慢呼气（6秒）——像吹蜡烛一样
  ③ 重复，直到宫缩过去

宫缩间隙：
  自然呼吸，全身放松，闭目休息
```

**宫缩剧烈时——浅快呼吸**：

```
宫缩最痛的阶段：
  ① 嘴巴微微张开
  ② 轻快地"哈—哈—哈—"呼吸（每秒1次）
  ③ 感觉头晕时放慢→恢复慢呼吸

注意：不要过度换气（手脚发麻=换气过度→放慢）
```

**第二产程（宫口全开、该用力时）——用力呼吸**：

```
宫缩来时：
  ① 深吸一口气
  ② 屏住呼吸→像解大便一样往下用力（10-15秒）
  ③ 快速呼气→再深吸→再用力（每次宫缩用力2-3次）

宫缩间隙：
  完全放松→喝口水→闭目休息
```

> 📝 **呼吸法的核心**：不是"不痛"，而是"不跟痛对抗"——宫缩时肌肉紧张→痛加重；呼吸放松→肌肉松弛→痛减轻。中医说的"调息→调气→安神"也是这个道理。

#### 5.5 产程中穴位按压辅助

以下穴位可在产程中由陪产人帮助按压，安全无创，辅助减痛：

| 穴位 | 位置 | 按压方法 | 作用 |
|------|------|----------|------|
| 合谷 | 手背虎口处（拇食指并拢，肌肉最高点） | 拇指持续按压，力度以酸胀为度 | 镇痛、行气——合谷为手阳明大肠经原穴，"面口合谷收"，镇痛范围广 |
| 三阴交 | 内踝尖上4横指（约3寸），胫骨后缘 | 拇指按压，每次宫缩时按压30秒 | 促进宫缩、缓解腰痛——三阴交为肝脾肾三经交会，调冲任 |
| 次髎 | 骶骨两侧第二对骶后孔（腰骶部凹陷处） | 掌根或拇指按压揉推 | 缓解腰骶剧痛——此穴直通胞宫，按压可放松盆底肌肉 |

> ⚠️ **合谷+三阴交在孕早期/中期禁用**（古有"合谷三阴交堕胎"之说，两穴合用可促进宫缩）。但**临产后可以使用**——此时本就需要宫缩。只限产程中由陪产人按压，不可自行在孕晚期随意按压。

#### 5.6 产前情志调护

```
恐惧 → 气下（恐则气下）→ 气虚不固 → 宫缩无力
紧张 → 气机郁滞 → 冲任不畅 → 产程延长
平静 → 气血和畅 → 宫缩有力 → 产程顺利
```

| 调护方法 | 做法 | 原理 |
|----------|------|------|
| 了解分娩过程 | 读完第六章，知道每个阶段会发生什么 | 消除未知恐惧 |
| 呼吸练习 | 孕晚期每日练习慢呼吸5分钟 | 肌肉记忆→产程中自然使用 |
| 陪产人支持 | 丈夫或家人全程陪伴 | 有安全感→气机不乱 |
| 避免负面信息 | 不看难产故事、不听"恐怖经历" | 恐则气下→最忌 |

#### 5.7 陪产人须知

陪产人的角色不是"旁观"，而是直接影响产程的参与者：

| 应该做 | 不应该做 |
|--------|----------|
| 握住产妇的手，给予肯定和鼓励 | 说"你怎么这么娇气"之类的话 |
| 帮产妇按压合谷、三阴交、揉腰 | 产妇宫缩时反复问"好了没" |
| 提醒产妇呼吸（"来，跟我一起呼吸"） | 在产房打电话/玩手机 |
| 宫缩间隙递水、擦汗、帮产妇调整姿势 | 表现出焦虑、慌张→传染给产妇 |
| 产妇喊叫时不制止（喊叫是正常的气机宣泄） | 喊"你别叫了省点力气"→产妇更紧张 |

> 📝 **关于喊叫**：产程中喊叫是正常反应，中医理解为"气机宣泄"。强行忍住→气机郁滞→反而延长产程。但持续的尖叫→耗气伤津→到该用力时没力气。陪产人可在宫缩间隙温和引导："刚才喊得很好，现在歇一歇，喝口水"——不是制止，是引导节奏。

### 六、影响顺产的常见因素与中医认识

| 因素 | 中医认识 | 调护方向 |
|------|----------|----------|
| 气虚体质（乏力、气短、自汗） | 气虚→宫缩乏力→滞产 | 孕中晚期健脾益气（山药、莲子）→临产时补气（参须泡水，须医师指导） |
| 气郁体质（焦虑、胸胁胀满） | 气郁→冲任不畅→产程延长 | 调畅情志→陈皮3g+玫瑰花3朵代茶 |
| 痰湿体质（肥胖、水肿、身重） | 痰湿阻滞→产道不利+胎儿易大 | 控制体重→健脾化湿（茯苓山药粥） |
| 寒凝体质（怕冷、手脚凉、经来腹痛） | 寒凝→冲任收缩→产道紧→痛剧 | 孕期温通→艾灸关元、足三里 |
| 高龄初产（≥35岁） | 气血渐亏→冲任弹性减弱 | 更需孕中期起养气血+适当活动 |

### 七、顺产准备时间线

| 孕期 | 核心任务 | 具体做法 |
|------|----------|----------|
| 1-3月 | **固胎** | 安静休息、避免劳倦、恶阻重者就医 |
| 4-6月 | **养气血+调脾胃** | 山药粥、规律饮食、每日散步30分钟 |
| 7-8月 | **助胎位+控体重** | B超查胎位、臀位者艾灸至阴穴（医师指导）、每周称体重 |
| 9月 | **助胎下降+待产准备** | 散步/爬楼梯（37周后）、准备待产包、练习呼吸 |
| 临产 | **调情志+储能** | 深呼吸放松、吃易消化高热量食物、不恐惧 |

> ⚠️ **重要声明**：以上调护方法适用于无并发症的正常妊娠。如有妊娠高血压、妊娠糖尿病、前置胎盘、胎位异常等合并症，须严格遵从产科医师指导，本章内容不能替代医嘱。

## 第六章 分娩过程

### 一、中医对分娩的核心认知

```
分娩 = 气血推动胎儿下行 + 冲任二脉开合放行 + 宫缩（阵痛）节律配合
```

| 力量 | 来源 | 作用 |
|------|------|------|
| 产力 | 气血推动 | 把胎儿往下推 |
| 产道 | 冲任开合 | 打开通道让胎儿通过 |
| 节律 | 阵痛递进 | 一阵一阵推进，不能持续硬推 |

### 二、分娩三产程

| 产程 | 西医叫法 | 中医认识 | 核心变化 |
|------|----------|----------|----------|
| 第一产程 | 开口期 | 开胞期 | 宫口从闭合→开全（10cm） |
| 第二产程 | 娩出期 | 出胎期 | 胎儿娩出 |
| 第三产程 | 胎盘期 | 下胞期 | 胎盘娩出 |

### 三、第一产程：开胞期

最漫长的阶段。

| 阶段 | 宫口变化 | 感觉 | 中医认识 |
|------|----------|------|----------|
| 潜伏期 | 0→3cm | 疼痛可忍，间隔较长 | 气血初动，冲任始开 |
| 活跃期 | 3→10cm | 疼痛加剧，间隔缩短 | 气血奔涌，冲任大开 |

**核心原则：第一产程只呼吸，不用力。**

| 做什么 | 不做什么 |
|--------|----------|
| 深呼吸配合宫缩 | 宫缩时大喊大叫（耗气） |
| 宫缩间隙放松休息 | 过早屏气用力（宫口未全开） |
| 适当走动助胎头下降（⚠️胎膜已破者禁止下床，须卧床；打无痛者下床须有人搀扶） | 一直躺着不动 |

### 四、宫口未全开就用力的危害

| 危害 | 具体说明 |
|------|----------|
| 母体撕裂伤 | 宫口只开了3cm，胎头约9-10cm，硬推→宫颈/会阴撕裂 |
| 耗气伤血 | 持续屏气→大量消耗体力→到真正该用力时没力气→滞产 |
| 胎儿缺氧 | 产妇屏气→腹压骤增→子宫血管被压→胎盘供血中断→胎儿窘迫 |

中医正确用力原则：

| 时机 | 做什么 |
|------|--------|
| 宫口3-9cm | 绝对不用力 |
| 宫缩来时 | 只做深呼吸 |
| 宫缩间隙 | 全身放松休息 |
| 宫口全开（10cm） | 这时才能用力 |

### 五、第二产程：出胎期

宫口全开后，才是真正该用力的时候。

| 原则 | 做法 | 原理 |
|------|------|------|
| 宫缩时用力 | 深吸一口气→屏气往下推（10-15秒） | 借宫缩之力+自身之力=合力推胎 |
| 宫缩间隙放松 | 快速呼气放松→喝水休息 | 蓄力待发 |
| 用力方向正确 | 像解大便一样往下用力 | 力往产道方向走 |
| 听从身体信号 | 有强烈便意感时自然用力 | 便意=胎头压迫直肠=快出来了 |

呼吸配合口诀：

```
宫缩来 → 深吸一口气 → 憋住 → 用力往下推（10-15秒）
宫缩停 → 快速呼气放松 → 喝口水休息 → 等下一次宫缩
```

### 六、第三产程：下胞期

胎儿娩出后，胎盘娩出。

### 七、产后身体状态

中医概括为：**"百节空虚，气血大亏"**

| 项目 | 产后状态 | 中医认识 |
|------|----------|----------|
| 气 | 分娩耗气→气虚 | 推力用完了，气大亏 |
| 血 | 产程出血+恶露排出→血虚 | 血大量流失 |
| 津液 | 产程出汗+出血→津亏 | 汗出伤津 |
| 冲任 | 胎儿娩出→冲任骤然空虚 | 血海骤空 |
| 腠理 | 产后毛孔张开→虚汗不止 | 营卫不和，表虚不固 |

#### 这些是正常的，不用怕

产后很多不适是正常的生理过程，不必恐慌：

| 现象 | 为什么正常 | 什么时候须就医 |
|------|-----------|---------------|
| 产后1-3天大量虚汗 | 气虚不固+体内多余水分排出→自然过程 | 汗出过多伴心慌气短→气随汗脱 |
| 产后2-3天乳房胀硬 | 生理性涨奶→泌乳启动信号 | 红肿热痛+发热→乳腺炎 |
| 恶露有血腥味 | 正常，子宫创面修复中排出 | 臭味→感染 |
| 产后排尿会阴刺痛 | 伤口愈合中，尿液刺激 | 完全排不出尿→尿潴留 |
| 初乳很少（几滴） | 初乳本就量少质稠，正常 | 产后3天以上仍完全无乳汁→需通乳 |
| 产后便秘 | 肠蠕动减弱+腹压改变+不敢用力 | 5天以上不排便→需处理 |
| 小腹隐痛（如痛经） | 子宫收缩恢复→正常宫缩痛 | 剧痛不止+恶露增多→须就医 |

> 📝 **简单原则**：如果某个不适让你担心，先对照上表——在上面且符合"正常"描述→观察即可；不在上面或超出"正常"范围→就医确认。宁可多问一次，不可硬扛。

### 八、产后三重开放

```
① 气虚 → 卫气不固 → 城墙无守兵
② 冲任开合未复 → 气血通道大开 → 大门没关
③ 腠理（毛孔）张开 → 虚汗不止 → 窗户敞开
                ↓
          风寒湿热长驱直入
```

### 九、为什么产后受风受寒后果严重？

邪气容易进（三重开放），更关键的是**进了就出不来**：

```
风寒湿热入侵 → 直达深层（关节、经络、筋骨）
                ↓
正常人：正气足→驱邪外出→好了
产后人：正气虚→无力驱邪→邪留
                ↓
邪气停留在关节、经络深处 → 气血运行受阻→不通则痛
                ↓
每到阴雨天、受凉→邪气活跃→疼痛发作
                ↓
一辈子的病根
```

产后各邪入侵后果：

| 邪气 | 入侵部位 | 后果 | 俗称 |
|------|----------|------|------|
| 风 | 关节、经络 | 产后身痛、关节游走性疼痛 | "产后风" | 仲景正治：竹叶汤（JGL-22-009，详见第十一章经方节） |
| 寒 | 子宫、小腹、关节 | 产后腹痛、关节冷痛 | "产后寒" | 仲景正治：当归生姜羊肉汤（JGL-22-004） |
| 湿 | 肌肉、关节 | 产后水肿、身重困倦 | "产后湿" | — |
| 风寒同犯 | 全身关节 | 产后关节痛，遇冷加重 | 最常见的月子病 |

### 十、产后汗证

| 类型 | 特点 | 病机 | 治法 |
|------|------|------|------|
| 自汗 | 白天醒时出汗，动则汗出 | 气虚不固 | 补气固表 |
| 盗汗 | 夜间睡时出汗，醒则汗止 | 阴虚内热 | 滋阴清热 |

#### 理解自汗——"守卫不够"

```
卫气 = 人体的守卫兵，负责管理毛孔开合
白天：卫气行于体表 → 管住毛孔 → 正常人不出汗
产后气虚 → 卫气不足 → 守卫不够 → 毛孔关不紧
    ↓
稍微一动 → 毛孔就松开 → 汗就漏出来了
不动的时候 → 毛孔勉强维持 → 汗少或不出
```

类比：自汗=城门关不紧→一有风吹草动就漏（气虚不固表）。

#### 理解盗汗——"贼趁夜色"

```
白天：阳气行于体表 → 阴在内被阳气管住 → 不出汗
夜间：阳气入里 → 体表少了阳气的"看守" → 阴虚则虚热内生
    ↓
虚热趁夜间阳气入里、体表防守空虚时 → 蒸迫津液外出 → 盗汗
醒了 → 阳气复出于表 → 虚热被压制 → 汗止
```

类比：盗汗=贼趁夜色偷东西→睡着时偷偷出汗→醒了就停（阴虚内热）。

#### 自汗与盗汗的本质区别

| | 自汗（气虚） | 盗汗（阴虚） |
|--|-------------|-------------|
| 核心病机 | 气虚→固摄无力 | 阴虚→虚热蒸迫 |
| 发生时机 | 白天醒时，活动后加重 | 夜间睡时，醒则汗止 |
| 出汗性质 | 毛孔"关不住" | 虚热"蒸出来" |
| 治疗方向 | 补气固表（加固城门） | 滋阴清热（釜底抽薪） |
| 代表方 | 玉屏风散 | 当归六黄汤 |

#### 产后汗证的经方正治

产后自汗与盗汗，时方虽有玉屏风散、当归六黄汤，但仲景经方对产后汗证有更贴合"产后"特殊体质的对应：

| 汗证类型 | 时方 | 经方 | 经方优势 |
|----------|------|------|----------|
| 产后自汗（气虚+营卫不和） | 玉屏风散 | **桂枝加黄芪汤**（JGL-02-003） | 桂枝汤调和营卫（产后最需调营卫）+黄芪固表，比玉屏风散更贴合产后"营卫不和"之病机 |
| 产后盗汗（阴虚+阳浮不固） | 当归六黄汤 | **桂枝加龙骨牡蛎汤**（JGL-07-008） | 产后盗汗多非纯阴虚，常兼阳浮不固。桂龙牡既固涩敛汗又潜阳，比纯滋阴降火更贴合产后"阴阳两虚"之实际。当归六黄汤苦寒药多（芩连柏），产后脾胃虚弱者恐难承受 |

> ⚠️ 产后初期出汗多为自汗（气虚），是正常现象。若持续不缓解，或出现盗汗明显，需辨证调治。

## 第七章 胎盘处理

### 一、胎盘娩出时机

| 阶段 | 时间 | 说明 |
|------|------|------|
| 胎儿娩出后 | 约5-15分钟 | 胎盘自然剥离娩出 |
| 最长不超过 | 30分钟 | 超过30分钟=胎盘滞留 |
| 超时危险 | 产后大出血风险极高 | |

核心原则：**等待自然剥离，切忌强行拉扯。**

### 二、胎盘剥离的征象

| 征象 | 具体表现 | 原理 |
|------|----------|------|
| 宫体变硬变圆 | 子宫收缩变硬，宫底升高 | 胎盘剥离后子宫收缩变小 |
| 阴道少量出血 | 突然一小股鲜血流出 | 胎盘剥离面血管出血 |
| 脐带外露变长 | 原本在阴道口的脐带又滑出一截 | 胎盘下降→脐带被拉出 |
| 宫底按压脐带不回缩 | 一手压宫底，一手轻拉脐带，不感觉有弹性回缩 | 胎盘已脱离宫壁 |

只有出现以上征象，才能确认胎盘已剥离，方可协助娩出。

### 三、胎盘娩出手法

```
确认胎盘已剥离
      ↓
一手按压宫底（向下推）
      ↓
另一手轻接胎盘（顺势托出）
      ↓
旋转胎盘→助胎膜完整排出
      ↓
检查胎盘完整性（最关键一步）
```

### 四、绝对禁止的操作

| 禁止行为 | 危害 | 中医认识 |
|----------|------|----------|
| 强行拉扯脐带 | 脐带断裂→胎盘残留→大出血 | 气血未行，强夺则伤络 |
| 按压子宫强行推 | 子宫内翻→致命 | 暴力伤胞 |
| 未确认剥离就拉 | 胎盘部分撕裂→大出血 | 未离而夺→残瘀留胞 |

中医原则："顺其自然，不可强夺"——胎盘如果实，熟则自落，未熟强摘则伤树。

### 五、检查胎盘完整性

| 检查项目 | 方法 | 异常情况 |
|----------|------|----------|
| 胎盘整体 | 看形状是否完整 | 有缺损→残留 |
| 母体面 | 检查小叶是否齐全 | 缺小叶→残留 |
| 胎膜 | 展开看有无缺损 | 缺一块→残留 |
| 脐带 | 看附着位置和血管 | 边缘附着→可能副胎盘残留 |
| 血管断端 | 大血管是否延续到边缘 | 血管断裂→可能有副胎盘 |

**胎盘残留=产后大出血的头号隐患**——任何缺损都不能放过。

## 第八章 脐带剪断与护理

### 一、延迟断脐（3分钟以上）

| 做法 | 说明 | 依据 |
|------|------|------|
| 延迟断脐（3分钟以上） | 等脐带搏动停止后再剪 | 让更多血液从胎盘回流至婴儿 |
| 不立即断脐 | 胎儿一出来就剪 | 损失约80-100ml血液 |

延迟断脐的好处：

| 好处 | 原理 | 中医认识 |
|------|------|----------|
| 增加血容量 | 胎盘血通过脐带回流至婴儿 | 气血从母体多承接一分 |
| 预防贫血 | 额外铁储备 | 血足则不虚 |
| 减少颅内出血 | 血压平稳过渡 | 气血运行平稳不暴冲 |
| 提高存活率（早产儿） | 更充足的血容量 | 尤为重要 |

### 二、脐带剪断的标准操作

```
胎儿娩出
    ↓
① 先不剪脐带！等3分钟以上（脐带搏动减弱或停止）
    ↓
② 确认脐带搏动已明显减弱或停止
    ↓
③ 用两把止血钳夹住脐带
    ↓
    ┌──── 钳1（近婴儿端）距脐轮约2-3cm
    │
    │    ┌── 钳2（近胎盘端）距钳1约3-5cm
    │    │
    ──●────●──
    婴儿   之间剪断
    ↓
④ 在两钳之间剪断
    ↓
⑤ 婴儿端消毒
    ↓
⑥ 结扎脐带
    ↓
⑦ 包扎脐部
```

### 三、脐带结扎注意事项

| 注意事项 | 说明 | 危险 |
|----------|------|------|
| 结扎要牢固 | 双重结扎或用脐带夹 | 结扎松脱→脐出血→婴儿失血 |
| 位置距脐轮1-2cm | 不能太远也不能太近 | 太远→残端长易感染；太近→伤及皮肤 |
| 不留空隙 | 结扎线紧贴脐带 | 有空隙→血管未完全闭合→出血 |
| 不要挤压脐带 | 结扎前不要挤压华通胶 | 挤压损伤血管→出血风险 |

### 四、烧灼断脐法（传统）

传统做法：剪刀在火上烧红→趁热剪脐带，同时完成切割+消毒+止血。

| 作用 | 原理 |
|------|------|
| 切割 | 高温使组织瞬间凝固→同时剪断 |
| 消毒 | 烧红温度约300-500°C→一切微生物杀灭 |
| 止血 | 高温接触脐血管→蛋白质凝固变性→血管断端被"焊死" |

现代医院已有无菌器械+碘伏+脐带夹替代，但在**偏远地区/家庭紧急接生/野外急救**时，烧灼断脐仍是最安全的办法。

传统中医还有一个独特认识：冷剪刀断脐→寒气随刃入脐→伤阳；烧灼断脐→温热之气伴随→对新生儿阳气有保护作用。（此属传统中医认识，现代无菌操作下无需刻意烧灼，避免烫伤风险。）

### 五、脐部护理

| 天数 | 脐带残端状态 | 护理 |
|------|-------------|------|
| 1-3天 | 残端白色/淡黄，开始干瘪 | 每日碘伏消毒1-2次 |
| 4-7天 | 逐渐变黑干枯 | 继续消毒，保持干燥 |
| 7-14天 | 自然脱落 | 脱落后继续消毒至创面愈合 |
| 脱落后 | 创面可能有少量分泌物 | 消毒至完全干燥愈合 |

脐部护理禁忌：

| 禁忌 | 原因 |
|------|------|
| 脐部沾水 | 潮湿→细菌繁殖→脐炎 |
| 用手抠残端 | 撕裂→出血+感染 |
| 尿布覆盖脐部 | 尿液浸湿→感染 |
| 涂抹爽身粉 | 粉剂吸水后成糊→潮湿→感染 |
| 包裹过紧 | 不透气→潮湿→感染 |

### 六、脐部异常信号

| 异常表现 | 可能问题 | 危险程度 | 处理 |
|----------|----------|----------|------|
| 脐部红肿 | 脐炎 | 紧急 | 立即就医 |
| 脐部有脓性分泌物 | 脐炎感染 | 紧急 | 立即就医 |
| 脐部有臭味 | 厌氧菌感染 | 紧急 | 立即就医 |
| 脐部渗血不止 | 结扎松脱/凝血问题 | 紧急 | 立即就医 |
| 14天以上未脱落 | 可能感染或异常 | 需评估 | 就医检查 |

判断脐部是否正常的核心三问：**红吗？臭吗？出血吗？**——都没有就不用慌。

### 七、中医对脐部的认识

- 脐为"神阙"——任脉重要穴位
- 脐通冲任——胎儿期气血出入的通道
- 脐为先天之根——胎儿期所有营养经脐而来

剪断脐带=婴儿从"脐供营养"到"口供营养"的切换点=婴儿正式独立生存。

## 第九章 传统分娩注意事项

### 一、新生儿拭口——落地第一件事

```
婴儿娩出
    ↓
❌ 第一件事不是剪脐带
✅ 第一件事是拭口通呼吸道
    ↓
清理口腔黏液/羊水
    ↓
婴儿发出第一声啼哭
    ↓
确认呼吸通畅
    ↓
然后再处理脐带
```

#### 拭口技法（裹指法）

| 步骤 | 做法 | 要点 |
|------|------|------|
| 准备 | 用洁净软布或纱布**裹在食指上** | 不用棉签（太细推不动黏液），不用手指直接抠（指甲伤黏膜） |
| 伸入口腔 | 裹布食指轻伸入婴儿口腔 | 动作轻柔，不要刺激咽部引发呕吐 |
| 擦拭顺序 | 先两侧颊内→舌面→上颚→最后咽部附近 | 从浅到深，把黏液/羊水擦出 |
| 翻转布面 | 擦一遍后翻转布面用干净面再擦 | 避免把擦出来的又推回去 |
| 观察 | 婴儿是否发出啼哭 | 啼哭=呼吸道通畅=肺开张 |

> ⚠️ 拭口的关键不是"抠"，而是"裹指轻擦"——用裹了软布的手指把黏液轻轻带出来。用力过猛→损伤口腔黏膜→感染入口。

### 二、去胎毒——需要修正的传统做法

传统说法：新生儿要喝黄连水/金银花水去胎毒。

| 传统做法 | 现代建议 |
|----------|----------|
| 喂黄连水/金银花水 | ❌ 新生儿胃肠娇嫩，苦寒伤脾胃 |
| 少量蘸取点口 | 🟡 相对温和，但仍需谨慎 |
| 让婴儿尽早吸吮母乳 | ✅ 初乳有轻泻作用→自然排胎便排毒 |

**初乳就是最好的"去胎毒药"**——初乳含免疫球蛋白+轻泻成分，能帮助排胎便+建立免疫。

### 三、浴儿法——不要急着给新生儿洗澡

| 时间 | 做法 | 原因 |
|------|------|------|
| 出生后不要立即洗澡 | 用干软毛巾擦干血污即可 | 新生儿体温调节差→洗澡→散热→低体温 |
| 出生6-24小时后 | 可用温水擦拭身体 | 体温稳定后 |
| 出生24-48小时后 | 可以正式洗澡 | 体温调节初步适应 |

浴儿注意事项：

| 注意点 | 原因 | 中医认识 |
|--------|------|----------|
| 水温37-38°C | 防烫伤/受凉 | 温而不烫，护阳气 |
| 先洗头面→再洗身体 | 顺序有讲究 | 从上到下，阳气下行 |
| 脐部绝对不沾水 | 防脐炎 | 脐为神阙，最忌湿邪 |
| 洗后立即擦干保暖 | 防散热 | 腠理开张→风寒易入 |

### 四、裹儿法——襁褓的学问

| 要点 | 做法 | 原因 | 中医认识 |
|------|------|------|----------|
| 上紧下松 | 上身裹紧，下肢留活动空间 | 防惊跳反射+不影响髋关节 | 护阳不束气 |
| 手臂贴身 | 手臂裹在襁褓内 | 新生儿惊跳反射→自己吓醒 | 安神定志 |
| 下肢可屈曲 | 腿不绑直，保持蛙式 | 髋关节发育需要屈曲位 | 顺其天性 |
| 厚度适中 | 比成人多一层即可 | 过热→捂热综合征 | 过暖伤阴 |
| 材质透气 | 纯棉，不用化纤 | 皮肤需呼吸 | 腠理需通 |

"三分寒"原则：新生儿穿衣比成人多一层即可。摸后颈温热无汗=合适。

### 五、挑马牙——最危险的传统做法之一

马牙=上皮珠（Epstein's pearls），牙龈上出现白色/淡黄色小颗粒，完全正常，会自行消失。

**绝对不能挑！** 挑破→细菌进入→口腔感染→败血症→可能致命。

### 六、开奶时机——越早越好

传统说法"初乳脏，不能给婴儿喝"是**错误**的。

| 正确做法 | 时间 | 好处 | 中医认识 |
|----------|------|------|----------|
| 出生后30分钟内 | 让婴儿吸吮乳头 | 最佳开奶时机 | 气血初生，趁势引导 |
| 最迟不超过2小时 | 尽早吸吮 | 刺激泌乳+子宫收缩 | 气机流通，瘀不下滞 |
| 初乳一定要喂 | 黄色浓稠的初乳 | 免疫球蛋白+轻泻排胎便 | 天然去胎毒 |

初乳=婴儿的第一剂疫苗+第一剂通便药。

### 七、救急法——新生儿不啼哭

```
婴儿娩出 → 不啼哭
        ↓
    ① 清理呼吸道（拭口+吸痰）
    ② 刺激啼哭（弹足底/摩擦背部）
    ③ 保暖（擦干+放母亲胸口）
    ④ 以上无效 → 立即新生儿复苏
```

### 八、胎便观察

| 时间 | 胎便特征 | 是否正常 |
|------|----------|----------|
| 出生后24小时内 | 墨绿色/黑色，黏稠，无臭 | 正常胎便 |
| 2-3天 | 逐渐变绿变黄 | 过渡便 |
| 4-5天 | 黄色糊状 | 母乳便 |

| 异常信号 | 可能问题 |
|----------|----------|
| 24小时内无胎便 | 消化道畸形/肠梗阻 |
| 胎便带血 | 需紧急排查 |
| 白色/灰白色便 | 胆道闭锁 |

#### 新生儿排尿观察

| 时间 | 排尿情况 | 是否正常 |
|------|----------|----------|
| 出生后24小时内 | 应有第一次排尿（量少，可能带粉红色尿酸盐结晶） | 正常 |
| 出生后48小时内仍无尿 | — | ❌ 须立即就医 |

### 九、捂热综合征——最容易被忽视的危险

过度包裹→婴儿散热困难→体温升高→高热→大量出汗→脱水→脑缺氧→抽搐→昏迷→死亡或永久脑损伤。

判断冷热的正确方法：**摸后颈**——温热无汗=合适。不要摸手脚（偏凉是正常的），不要以大人感觉判断。

### 十、传统做法总结

| 传统做法 | 是否正确 | 现代建议 |
|----------|----------|----------|
| 落地先拭口 | ✅ 正确 | 同样强调，先通呼吸道 |
| 烧灼断脐 | ✅ 有道理 | 医院用无菌器械替代，紧急时仍适用 |
| 去胎毒喂黄连水 | ⚠️ 需修正 | 初乳就是最好的去胎毒，不必喂草药 |
| 三日方浴 | ✅ 有道理 | 不急洗澡，擦干保暖优先 |
| 襁褓裹紧 | 🟡 部分正确 | 上紧下松，不可过热 |
| 挑马牙 | ❌ 危险 | 绝对不能挑！会自行消失 |
| 初乳不能喝 | ❌ 错误 | 初乳最珍贵，必须喂！ |
| 弹足底刺激啼哭 | ✅ 正确 | 现代医学同样采用 |
| 捂热保暖 | ⚠️ 需修正 | 适度保暖，防捂热综合征 |

## 第十章 产后调养总论

### 零、产后辨证总纲（仲景思路）

《金匮要略·妇人产后病脉证并治第二十一》开篇即提出产后三大病：

> "新产妇人有三病：一者病痉，二者病郁冒，三者大便难。"（JGL-22-001）

- **痉**：产后血虚+多汗+中风→筋脉失养→拘急痉挛
- **郁冒**：亡血复汗→寒多→血虚而厥→头汗出、呕不能食
- **大便难**：亡津液→胃燥→大便坚

三大病的共同根源=**亡血伤津**。但仲景紧接着给出的治法并非一味补虚：

```
产后虽多虚，但不可一见虚就补——

仲景的产后治法谱：
  有实者当祛邪 → 大承气汤（JGL-22-003/007，产后阳明腑实）
  有寒者当温阳 → 当归生姜羊肉汤（JGL-22-004，产后血虚里寒）
  有瘀者当化瘀 → 下瘀血汤（JGL-22-006，干血著脐下）
  有风者当祛风扶正 → 竹叶汤（JGL-22-009，产后中风）
  有热者当清热 → 白头翁加甘草阿胶汤（JGL-22-011，产后热利）
  有郁者当和解 → 小柴胡汤（JGL-22-002，产后郁冒）
  有气滞者当行气 → 枳实芍药散（JGL-22-005，产后烦满不得卧）

总原则：观其脉证，知犯何逆，随证治之（SHL-016）
```

**产后最易犯的错误**：只看到"虚"，看不到"实"和"瘀"。产后确多虚，但虚中夹实、虚中夹瘀最为常见。一味温补→闭门留寇（瘀血不出）；一味化瘀→伤正耗血（虚上加虚）。正确做法是**辨清虚实主次，虚则补之、实则泻之、瘀则化之、寒则温之、热则清之**。

### 零之一、产后急症红灯信号——必须立即就医

> ⚠️ **以下任何一条出现，必须立即就医，不可在家观察等待。** 这些不是"调理"能解决的问题，延误可能危及生命。

#### 产后大出血

| 信号 | 具体标准 |
|------|----------|
| 产后2小时内出血量 | 浸透2片以上产妇卫生巾（约≥500ml） |
| 任意时间出血 | 1小时内浸透1片卫生巾且持续不止 |
| 排出大血块 | 直径超过鸡蛋大小的血块 |
| 出血伴面色苍白/心慌/出冷汗 | 已出现失血性休克先兆 |

**自查方法**：观察卫生巾——1片完全浸透约200-250ml。如果1小时内换的卫生巾每次都完全浸透→出血过多。

#### 产褥感染

| 信号 | 说明 |
|------|------|
| 体温≥38°C持续2天以上（产后24小时后） | 不是"吸收热"——产后24小时内低热为正常吸收热，超过24小时仍发热=感染可能 |
| 恶露有恶臭味 | 正常恶露有血腥味但无臭味，臭味=厌氧菌感染 |
| 腹痛持续加重 | 子宫压痛=宫内感染 |
| 恶露量突然增多+色鲜 | 感染致子宫收缩不良→出血 |

#### 产后子痫先兆

妊娠高血压产妇产后仍可能发生抽搐：

| 先兆信号 | 说明 |
|----------|------|
| 剧烈头痛 | 持续不缓解，与普通产后头痛不同 |
| 视力模糊/眼前闪光 | 颅内压升高 |
| 上腹痛 | 肝被膜牵拉——HELLP综合征可能 |
| 突然浮肿加重 | 尤其面部和手部 |

**有妊娠高血压史的产妇，产后3天内仍须密切监测血压。** 血压≥160/110mmHg→立即就医。

#### 乳腺炎

| 阶段 | 信号 | 处理 |
|------|------|------|
| 早期 | 乳房局部硬块+压痛 | 热敷+按摩疏通+继续哺乳→多数可自行缓解 |
| 进展期 | 硬块+红肿热痛+体温≥38.5°C | **就医**——需抗生素+中药清热解毒 |
| 化脓期 | 红肿处出现波动感（按压有弹性） | **紧急就医**——须切开引流 |

**早期与堵奶的鉴别**：堵奶=局部硬块+轻痛+无发热→热敷按摩可缓解。乳腺炎=硬块+明显红肿热痛+发热→需医疗干预。

#### 新生儿急症

| 信号 | 说明 |
|------|------|
| 呼吸急促/呻吟/口周发青 | 呼吸窘迫 |
| 拒奶+嗜睡+反应差 | 感染可能 |
| 体温<36°C或>38°C | 低体温/感染 |
| 前囟明显隆起 | 颅内压增高 |
| 频繁呕吐（非溢奶） | 幽门狭窄/肠梗阻可能 |
| 皮肤巩膜黄染24小时内出现 | 病理性黄疸——必须立即就医 |

#### 简明记忆口诀

```
出血多、发热久、恶露臭、头痛剧
乳房红热痛、宝宝不吃喝
→ 任何一条 → 立即就医
```

### 零之二、产后发热辨证——生死攸关的鉴别

产后发热不是一种病，而是多种不同疾病的共同表现。**辨错方向可能致命——感染发热须抗感染，补虚退热用于感染则延误治疗。**

#### 产后发热五大类型

| 类型 | 核心特征 | 热型 | 伴随症状 | 治疗方向 | 危险度 |
|------|----------|------|----------|----------|--------|
| 感染发热（产褥感染） | 高热+恶露臭/腹痛 | 弛张热（波动大） | 恶露臭、下腹痛、子宫压痛 | **西医抗感染为首选+中医清热解毒** | 🔴 可致命 |
| 血虚发热 | 低热+面白+心悸 | 低热缠绵 | 面色萎白、头晕心悸、手足麻 | 补血清热（当归建中汤方向） | 🟡 |
| 瘀血发热 | 低热+腹痛拒按 | 午后/夜间热甚 | 小腹痛、恶露少色暗有块 | 化瘀清热（生化汤/下瘀血汤方向） | 🟡 |
| 外感发热 | 发热+恶寒+头痛 | 初起恶寒发热 | 头痛、身痛、鼻塞流涕 | 解表扶正（竹叶汤/桂枝汤方向） | 🟡 |
| 蒸乳发热 | 低热+乳房胀硬 | 产后3-4天出现 | 乳房胀硬、触痛、无红肿 | 通乳散热 | 🟢 |

#### 最关键的鉴别：感染发热 vs 其他

| | 感染发热 | 非感染发热 |
|---|---------|-----------|
| 体温 | ≥38.5°C，持续或反复 | 多<38°C，低热缠绵 |
| 恶露 | **有臭味** | 无臭味 |
| 腹痛 | **持续加重，拒按** | 绵绵隐痛，喜按 |
| 子宫压痛 | **有** | 无 |
| 血象 | 白细胞升高 | 正常或偏低 |

**判断规则**：

```
产后发热 + 恶露臭 → 感染 → 立即就医，不可自行用药
产后发热 + 恶露无臭 + 腹痛喜按 → 虚/瘀 → 中医辨证调治
产后发热 + 乳房胀硬 → 蒸乳 → 通乳即可
产后发热 + 恶寒头痛 → 外感 → 解表扶正
```

> ⚠️ **产后发热超过38.5°C持续1天以上，无论是否伴有恶露臭，均应就医排查感染。** 宁可多跑一次医院，不可在家延误。产褥感染发展快，24小时内可从发热进展为败血症。

### 零之三、产后恶露不绝辨证

正常恶露持续3-4周。超过4周仍未干净=恶露不绝（恶露不净），是产后最常见的迁延问题。

#### 恶露不绝的常见分型

| 证型 | 核心表现 | 恶露特征 | 舌象 | 治法方向 |
|------|----------|----------|------|----------|
| 气虚不摄 | 恶露量多色淡、质稀、无臭 | 色淡红、质稀 | 舌淡苔白 | 补气摄血（黄芪+红枣+升麻方向） |
| 血瘀内停 | 恶露量少色暗、有块、腹痛拒按 | 色紫暗有块 | 舌暗或有瘀点 | 化瘀止血（生化汤/下瘀血汤方向） |
| 血热妄行 | 恶露量多色鲜红、质稠 | 色鲜红、质稠 | 舌红苔黄 | 凉血止血（芩连四物方向） |
| 虚实夹杂 | 淋漓不尽+时多时少 | 时淡时暗 | 舌淡暗 | 补虚化瘀并行 |

**最常见的是气虚+血瘀并见**——产后气虚不摄+瘀血未净，单纯补气则瘀留，单纯化瘀则伤正，须补虚化瘀并行。

> ⚠️ **恶露不绝伴发热+腹痛+恶露臭=产褥感染，必须立即就医，不可自行调治。**

### 零之四、剖宫产中医专项调护

剖宫产率在中国接近50%，其产后调护与顺产有根本不同，不可一概而论。

#### 剖宫产与顺产的中医差异

| 差异 | 顺产 | 剖宫产 | 调护区别 |
|------|------|--------|----------|
| 气血损伤 | 耗气伤血 | **气血俱伤更重**——手术+麻醉+出血三重损耗 | 补益需更早介入但不可过早（须先排气） |
| 肠道恢复 | 自然 | **肠麻痹**→须先排气 | 排气前禁食，排气后从流食开始（萝卜汤助排气） |
| 恶露排出 | 较顺畅 | **宫缩无力→恶露易滞** | 更易发生瘀血发热，须更密切观察恶露 |
| 乳汁 | 较快下来 | **下奶延迟1-3天** | 不可过早催乳→乳未通就催=堵奶 |
| 腹部瘢痕 | 无 | **冲任经脉受损**→远期腹痛可能 | 伤口愈合后艾灸神阙+关元助冲任恢复 |
| 早期活动 | 6-12小时可下床 | **24小时拔尿管后方可下床** | 须有人搀扶，防晕厥 |

#### 剖宫产饮食时间线

| 时间 | 饮食 | 说明 |
|------|------|------|
| 术后6小时内 | 禁食禁水 | 肠功能未恢复 |
| 术后6-24小时 | 先饮少量温水→萝卜汤助排气 | 排气是恢复进食的关键信号 |
| 排气后第1天 | 小米粥、藕粉等流食 | 不吃固体食物 |
| 排气后第2-3天 | 软烂半流食（烂面条、粥+肉末） | 逐步过渡 |
| 排气后第4天起 | 参照顺产第一周食谱 | 但量更少、更烂 |

> ⚠️ **剖宫产后生化汤须排气后方可服用**——排气前肠麻痹未解除，任何口服药物和食物都不可进入。

#### 剖宫产伤口中医调护

| 阶段 | 调护 | 注意 |
|------|------|------|
| 术后1-7天 | 保持伤口干燥清洁，不可浸水 | 不可在伤口周围艾灸（未愈合） |
| 术后7-14天 | 伤口初步愈合，可温水擦浴 | 不可泡澡/坐浴 |
| 术后14天后 | 伤口愈合良好，可开始艾灸神阙、足三里 | 助冲任恢复+健脾胃 |
| 远期瘢痕腹痛 | 艾灸关元+气海+局部温和灸 | 瘢痕组织影响冲任→温通可缓解 |

### 零之五、产后身痛辨证

产后身痛（"产后风"）是月子病中就诊率最高的主诉，需系统辨证，不可一律"祛风"。

| 证型 | 核心症状 | 舌脉 | 治法方向 | 经方/食疗参考 |
|------|----------|------|----------|---------------|
| 风寒束表 | 遍身酸痛+怕风+头痛 | 舌淡苔白，脉浮紧 | 祛风散寒+扶正 | 竹叶汤（JGL-22-009）/桂枝加葛根汤方向 |
| 寒凝经脉 | 关节冷痛遇寒加重+得温则减 | 舌淡苔白润 | 温经散寒 | 当归生姜羊肉汤+艾灸 |
| 肾虚腰痛 | 腰痛如折+膝软+下肢冷 | 舌淡脉沉细 | 补肾强腰 | 杜仲猪腰汤/肾气丸方向 |
| 瘀血身痛 | 痛处固定不移、按之痛甚、夜间加重 | 舌暗有瘀点 | 活血化瘀 | 三七炖鸡/身痛逐瘀汤方向 |
| 湿阻身痛 | 身重困倦+关节酸沉+水肿 | 舌苔白腻 | 健脾除湿 | 茯苓山药粥/薏米水 |

**最常见的误区**：一见产后身痛就用祛风药——产后身痛非皆因风。肾虚、血瘀、寒凝、湿阻各有对应，辨证不准则药不对症。

> 📝 **产后身痛的自我鉴别要点**：怕风+游走痛=风；冷痛+遇寒加重=寒；腰痛+膝软=肾虚；固定痛+按之痛=瘀；身重+水肿=湿。

### 零之六、哺乳期用药安全

> ⚠️ **哺乳期用药，药物可能通过乳汁进入婴儿体内。** 以下原则须严格遵守。

#### 哺乳期禁用/慎用药物

| 类别 | 药物 | 原因 | 等级 |
|------|------|------|------|
| 泻下药 | 大黄、番泻叶、芦荟 | 通过乳汁致婴儿腹泻 | 🔴禁用 |
| 苦寒药（大量） | 黄连、黄柏、龙胆草（大剂量） | 苦寒通过乳汁伤婴儿脾胃 | 🟡慎用，小量短期可 |
| 活血破瘀药 | 三棱、莪术、水蛭、虻虫 | 破血力强→可能通过乳汁影响婴儿 | 🔴禁用 |
| 辛温燥烈药 | 麝香、冰片 | 通窍走窜→影响婴儿 | 🔴禁用 |
| 回乳药 | 炒麦芽60g以上、芒硝外敷 | 抑制泌乳→乳汁减少 | 🟡如需断奶时可用 |
| 解表发汗药 | 麻黄、桂枝（大量） | 发汗→乳汁分泌减少 | 🟡慎用，小量短期可 |
| 安神药 | 朱砂、磁石（重镇） | 重金属→通过乳汁危害婴儿 | 🔴禁用 |

#### 哺乳期安全药物

| 类别 | 药物 | 说明 |
|------|------|------|
| 健脾药 | 白术、茯苓、山药、莲子 | 药性平和，通过乳汁量极微，不影响婴儿 |
| 养血药 | 当归、白芍、熟地（小量） | 养血不伤正，常规剂量安全 |
| 理气药 | 陈皮、砂仁（小量） | 量小安全，理气助消化 |
| 清热药 | 黄芩（9g以内）、金银花（小量） | 常规剂量安全，大剂量慎用 |
| 补气药 | 黄芪、党参、甘草 | 常规剂量安全 |

#### 服药与哺乳的时间间隔

```
服药后1-2小时内乳汁中药物浓度最高
       ↓
建议：服药后2小时再哺乳
     或：服药前哺乳→服药→间隔2小时→再哺乳
       ↓
中药汤剂每日分2-3次服→每次服后间隔2小时哺乳
→ 可将药物对婴儿的影响降至最低
```

### 一、产后三阶段饮食原则

| 阶段 | 核心 | 原则 | 比喻 |
|------|------|------|------|
| 第一周（1-7天） | **排** | 温通不补、清淡易消化 | 清扫垃圾 |
| 第二周（8-14天） | **调** | 调脾胃为主、健脾开胃，脾胃健则补方能受 | 修好机器 |
| 第三周起（15天+） | **补** | 大补气血、填精壮骨 | 装满原料 |

### 二、第一周大补的危害

| 危害 | 机理 |
|------|------|
| 留瘀（闭门留寇） | 恶露未排尽+大补→气血充盈→瘀血被堵在里面出不来 |
| 滞胃（虚不受补） | 产后脾胃虚弱+滋腻补药→运化不了→腹胀纳呆 |
| 堵奶 | 浓汤催乳→乳汁猛增→新生儿吃不完→淤积→乳腺炎 |

### 三、产后坐月子核心原则

| 原则 | 具体做法 | 防什么 |
|------|----------|--------|
| 避风寒 | 不吹穿堂风、不碰冷水、不着凉；夏季可用空调（26-28°C，风口朝上，不直吹人） | 防风寒入关节 |
| 慎洗浴 | 可擦身但避免盆浴、水温要够热 | 防寒湿从下而入 |
| 忌生冷 | 不吃寒凉食物（冰的、西瓜、苦瓜等） | 防寒从口入伤脾胃 |
| 适温补 | 温补气血（红枣、桂圆、鸡肉、鲫鱼） | 补虚扶正 |
| 不过劳 | 不提重物、不久站久蹲 | 防气虚下陷→子宫脱垂 |
| 调情志 | 保持心情舒畅 | 防肝气郁结→产后抑郁 |
| 禁房事 | 产后42天内禁止 | 防邪从阴户直入胞宫→子宫创面未修复→感染→大出血 |

### 四、恶露观察

| 恶露阶段 | 时间 | 颜色 | 性质 |
|----------|------|------|------|
| 血性恶露 | 产后1-3天 | 鲜红→暗红 | 量多，含血为主 |
| 浆液性恶露 | 产后4-10天 | 淡红→淡黄 | 量减少 |
| 白色恶露 | 产后10-21天 | 白色→淡黄 | 黏稠，无血 |

恶露异常信号：

| 异常表现 | 可能原因 | 危险程度 |
|----------|----------|----------|
| 量过多、不停 | 子宫收缩乏力/胎盘残留 | 紧急 |
| 时间过长（>3周） | 子宫恢复不良/感染 | 需就医 |
| 有臭味 | 感染 | 紧急 |
| 突然增多、鲜红 | 晚期产后出血 | 紧急 |
| 颜色紫暗有血块 | 寒凝血瘀 | 需调理 |

寒热辨别口诀：

```
色暗有块 → 寒凝血瘀
色鲜量多 → 热迫血行
色淡量少 → 气虚不摄
```

> 📝 **易错辨析：** 色暗有块≠内热。暗色+血块是"寒"导致血液凝固瘀滞的表现，不是有热。热的特征是色鲜红（热迫血妄行）。寒则凝（水遇寒结冰），热则行（水遇热奔涌），这个规律在恶露判断中同样适用。

### 五、会阴护理——冰敷不可行

**冰敷会阴违反产后忌寒原则。** 会阴是冲任督三脉交汇处，冰敷=在最脆弱的部位引入寒邪，寒从会阴直入冲任。

> ### 🚨 易犯错误：冰敷会阴
>
> 西医习惯产后冰敷会阴消肿，但这一做法**与中医产后忌寒原则直接冲突**：
>
> | 西医逻辑 | 中医逻辑 |
> |----------|----------|
> | 冰敷→血管收缩→减少渗出→消肿 | 产后百节空虚→风寒湿热长驱直入→冰敷=引寒入体 |
> | 局部处理，不考虑全身 | 会阴是冲任督三脉交汇→寒从会阴入→直达冲任→落病根 |
>
> **反思：** 我们刚学完"产后三重开放"（气虚不固+冲任未闭+腠理张开），此时在身体最薄弱处敷冰，等于在最脆弱的时刻、最关键的门户主动引进寒邪。冰敷消肿是暂时的，寒邪入络却可能是终身的。
>
> **更深层分析**：
> - 会阴是任脉起始段、冲脉起始点——产后冲任骤空，此处最虚，冰敷=在最虚处引入最阴寒之物，违背"虚处不可再伤"之基本治则
> - 会阴肿胀的根源是瘀血+组织损伤——冰敷只缩血管（治标），但瘀血因寒凝而更难消散（加重本），属于"治标伤本"
> - 大黄芒硝外敷优于冰敷的本质：大黄活血化瘀（治本）+芒硝高渗吸水（治标），消肿不留邪
>
> **正确方案：** 用大黄芒硝外敷——通过高渗吸水消肿+化瘀改善循环，既消肿又不引入寒邪。

正确方案：

| 阶段 | 首选 | 原因 |
|------|------|------|
| 0-24小时 | 大黄芒硝外敷/常温中药液冷敷 | 清热消肿不引入寒邪 |
| 24小时-5天 | 大黄芒硝外敷 | 化瘀消肿促愈合 |
| 3-5天后 | 温水/中药坐浴 | 活血通络加速修复 |

## 第十一章 产后内服方

### 〇、产后经方正治（《金匮要略·妇人产后病》）

仲景《金匮》专设"妇人产后病脉证并治"一篇（JGL-22），共11条，涵盖产后痉病、郁冒、腹痛、中风、下利等主要证候，是产后辨证的经方根基。以下按原典条文逐一列出：

#### 1. 产后郁冒——小柴胡汤

| 项目 | 内容 |
|------|------|
| 原文 | "产妇郁冒，其脉微弱，呕不能食，大便反坚，但头汗出……大便坚，呕不能食，小柴胡汤主之。"（JGL-22-002） |
| 组成 | 柴胡半斤、黄芩三两、人参三两、半夏半升、甘草三两、生姜三两、大枣十二枚 |
| 功效 | 和解少阳，枢转气机 |
| 辨证要点 | 产后呕不能食+大便坚+头汗出+脉微弱 |
| 注意 | 此为产后血虚+少阳枢机不利之证，非单纯胃虚，健脾和胃法无效时须考虑此方 |

#### 2. 产后阳明腑实——大承气汤

| 项目 | 内容 |
|------|------|
| 原文 | "病解能食，七八日更发热者，此为胃实，大承气汤主之。"（JGL-22-003） |
| 原文 | "产后七八日，无太阳证，少腹坚痛，此恶露不尽。不大便，烦燥发热，切脉微实……宜大承气汤主之。"（JGL-22-007） |
| 功效 | 峻下热结 |
| ⚠️关键警示 | 产后用大承气汤看似骇人，但仲景明示：产后确有阳明实证存在。有实当祛，不可因"产后多虚"而畏攻延误。然须辨证精确：不大便+烦躁发热+脉微实=胃实确据。**此方为峻下之剂，绝非产后便秘常规用药——产后便秘多属津亏肠燥，当用增液润肠法（如蜜煎导、增液汤），不可见便秘就投大承气汤。** 须执业医师核定 |

#### 3. 产后血虚里寒腹痛——当归生姜羊肉汤

| 项目 | 内容 |
|------|------|
| 出处 | 《金匮要略》JGL-22-004 |
| 原文 | "产后腹中㽲痛，当归生姜羊肉汤主之，并治腹中寒疝，虚劳不足。" |
| 组成 | 当归三两、生姜五两、羊肉一斤 |
| 煎法 | 以水八升，煮取三升，温服七合，日三服 |
| 功效 | 温中补虚，养血散寒 |
| 辨证要点 | 产后腹中绵绵作痛（非刺痛、非胀痛）、喜温喜按、面色苍白、舌淡脉细弱 |

**此方是产后虚寒腹痛的经方正治，非单纯食疗方**。当归养血活血、生姜温中散寒、羊肉温补精血，三味药食同源，补而不滞、温而不燥，最宜产后虚寒体质。若寒甚者加生姜量，痛甚者加当归量。

#### 4. 产后气滞腹痛——枳实芍药散

| 项目 | 内容 |
|------|------|
| 原文 | "产后腹痛，烦满不得卧，枳实芍药散主之。"（JGL-22-005） |

| 腹痛性质 | 绵绵作痛，喜温喜按 | 胀满烦痛，卧不安 |
| 核心病机 | 血虚里寒 | 气滞血郁 |
| 治则 | 温养 | 行气 |

#### 5. 产后干血著脐——下瘀血汤

### 一、生化汤 产后化瘀常用方（时方）

> **定位说明**：生化汤是后世时方（清·傅青主女科），非仲景经方。产后化瘀的经方正治参见上方"下瘀血汤"（JGL-22-006）。生化汤化瘀力平和，适用于产后瘀轻+寒象者；瘀重者须用下瘀血汤。

| 项目 | 内容 |
|------|------|
| 出处 | 清·傅山《傅青主女科》 |
| 组成 | 当归24g、川芎9g、桃仁6g、炮姜2g、炙甘草2g |
| 功效 | 化瘀生新、温经止痛 |
| 主治 | 产后瘀血腹痛、恶露不行 |

| 药物 | 作用 | 角色 |
|------|------|------|
| 当归（大剂量） | 补血活血 | 补+行 |
| 川芎 | 活血行气 | 推动血行 |
| 桃仁 | 活血化瘀 | 破瘀 |
| 炮姜 | 温经散寒 | 温煦 |
| 炙甘草 | 调和诸药 | 和中 |

为什么叫"生化"？化瘀→瘀化则新血生，"化"在前"生"在后——旧的不去新的不来。

使用时机：

| 时间 | 是否适用 | 原因 |
|------|----------|------|
| 产后当天 | 可以开始 | 趁早化瘀 |
| 产后1-7天 | 最佳时期 | 排瘀黄金期 |
| 产后7-14天 | 恶露已净则停 | 瘀已尽，不必再化 |
| 恶露已净 | 停用 | 继续用→化瘀太过→出血 |

禁忌：

| 禁忌情况 | 原因 | 处理 |
|----------|------|------|
| 恶露量多色鲜 | 血已多，再化瘀→出血加重 | 先止血再化瘀 |
| 产后大出血 | 化瘀药活血→出血风险更高 | 禁用，紧急就医 |
| 阴虚火旺明显 | 炮姜温燥→助热伤阴 | 减炮姜或去炮姜，加生地。产后出血多、口干、舌红者属此，不可见"产后"就投生化汤 |

**生化汤 vs 下瘀血汤鉴别**：

| 鉴别点 | 生化汤（时方） | 下瘀血汤（经方） |
|--------|----------------|------------------|
| 出处 | 《傅青主女科》 | 《金匮要略》JGL-22-006 |
| 化瘀力度 | 平和（桃仁6g） | 峻猛（大黄三两+桃仁二十枚+䗪虫） |
| 温养力度 | 有（当归24g+炮姜） | 无（纯破瘀不温养） |
| 适用 | 产后瘀轻+寒象 | 产后瘀重（干血著脐，枳实芍药散不愈） |
| 体质要求 | 虚寒可用 | 须有实瘀确据，虚人慎用 |
| 剖宫产未排气 | 肠道功能未恢复→活血药可能加重肠麻痹 | 等排气后再服 |
| 感染发热（恶露臭） | 瘀热互结→单纯化瘀不够，需清热解毒 | 需辨证加味，不可单用 |

> 📝 **生化汤使用要点：** 一般服5-7剂即停。恶露净=瘀已尽，继续服则化瘀太过反而出血。产后第一方不是"补"方，是"化瘀"方——化瘀为的是给新血腾位置，瘀尽即止，不可久服。

### 二、下乳涌泉散 产后缺乳常用方

| 项目 | 内容 |
|------|------|
| 出处 | 清·傅山《傅青主女科》 |

| 功效 | 疏肝解郁、养血通乳 |

产后缺乳两大原因：气血虚弱（产时耗伤气血→无血化乳）+ 肝郁气滞（情志不畅→气机郁滞→乳络不通）。

#### 缺乳的经方病机推演（方向性参考）

仲景虽无专方治缺乳，但从经方病机可推演：

| 缺乳类型 | 病机 | 经方推演方向 | 依据 |
|----------|------|-------------|------|
| 气血虚弱型 | 产时耗伤气血→血海空虚→无血化乳 | **黄耆建中汤**（JGL-07-014）培补中气，中气充则血足化乳 | "虚劳里急，诸不足"——产后虚劳与缺乳同源 |
| 肝郁气滞型 | 情志不畅→气机郁滞→乳络不通 | **四逆散**（SHL-318）疏肝理气，比逍遥散更药简力专 | 产后情志不畅+胸胁胀满=肝气郁结 |

> 上述推演标注"方向性参考"，实际用药须复诊后由执业医师辨证确定。

简易通乳法：

| 方法 | 做法 | 原理 |
|------|------|------|
| 通草鲫鱼汤 | 通草10g+鲫鱼1条煮汤 | 通草通乳+鲫鱼补虚 |
| 王不留行煮蛋 | 王不留行15g煎水+煮鸡蛋 | 王不留行=通乳要药 |
| 丝瓜络煮水 | 丝瓜络30g煮水喝 | 丝瓜络通络下乳 |
| 热敷+按摩 | 温热毛巾敷乳房→从外周向乳头方向按摩 | 温通乳络 |

注意：产后第一周不要催乳（堵奶风险），第二周开始可以适当通乳。

## 第十二章 产后外治法

### 一、艾灸 🏆 最推荐的产后外治法

原理：艾叶温经散寒+火力温阳→最契合产后"虚寒"体质。

产后艾灸核心穴位：

| 穴位 | 位置 | 作用 | 对应症状 | 注意 |
|------|------|------|----------|------|
| 关元 | 脐下3寸 | 补肾固本、温宫散寒 | 小腹冷痛、恶露不下 | ⚠️恶露量多时禁灸（温通活血→出血加重） |
| 气海 | 脐下1.5寸 | 补气培元 | 乏力、气短 | ⚠️恶露量多时禁灸 |
| 神阙 | 肚脐中央 | 温阳散寒、健脾和胃 | 腹冷、腹泻 | |
| 足三里 | 外膝眼下3寸 | 健脾益气、强壮全身 | 乏力、纳差 | |
| 三阴交 | 内踝尖上3寸 | 调补肝脾肾、养血 | 血虚、腰酸 | |
| 肾俞 | 第二腰椎旁开1.5寸 | 补肾强腰 | 腰痛 | |

操作：点燃艾条距穴位2-3cm，以温热舒适为度，每穴10-15分钟，每日1次。

禁忌：阴虚火旺明显者、恶露量多色鲜时、过饥过饱、灸后立即洗澡/吹风。

艾灸和产后忌寒完全一致——不是引入寒邪，而是**温阳驱寒**。

## 第十三章 产后食疗

> **核心原则回顾**：产后三阶段——排（1-7天）、调脾胃（8-14天）、补（15天+），详见第十章。食疗也严格遵循此顺序，不可跨越阶段。

### 一、第一周（排）——温通不补，助排恶露

产后第一周，恶露未净、脾胃虚弱，食疗目标是"温通排瘀"，绝不可进补。

#### 主食疗方

|------|------|------|----------|------|

#### 第一周绝对禁忌

| 禁忌 | 原因 |
|------|------|
| 人参、鹿茸、黄芪 | 大补留瘀——恶露未净时补=闭门留寇 |
| 浓猪蹄汤/浓鸡汤 | 过早催乳→乳汁猛增→堵奶→乳腺炎 |
| 油腻煎炸 | 滞胃——产后脾胃虚，运化不动油腻 |
| 生冷寒凉（西瓜、苦瓜、冷饮） | 伤脾胃阳气+寒凝血瘀 |
| 辛辣刺激（辣椒、花椒过量） | 产后多虚热，辛热助火→口干便秘→影响伤口愈合 |
| 过量红糖 | 红糖活血化瘀，量多或久服→恶露不尽→出血延长。一般产后5天后渐减，7-10天停 |

> 📝 **红糖不是越多越好**：民间"红糖吃到满月"是错误的。红糖活血化瘀力强，产后初期用3-5天助排瘀即可，恶露渐少后就应停用。过久服用→子宫收缩不良→恶露迁延不绝。

### 二、第二周（调脾胃）——健脾开胃，为进补铺路

第二周的核心是"调脾胃"，不是"补"。脾胃是后天之本，脾胃健旺→补方能受，脾胃虚弱→补亦徒劳。

第二周起食欲渐开，可以在健脾框架内吃得丰富一些、味道好一些——**好吃=开胃=脾运化的信号**，但前提是不增加脾胃负担。

#### 主食疗方

| 山药排骨汤 | 鲜山药100g（干品15g）+排骨200g，炖1.5小时 | 健脾益胃、补气养阴 | 脾胃虚弱、纳差便溏 | 山药用鲜品口感好，干品药力更强 |
| 陈皮粥 | 陈皮3-5g+大米50g煮粥 | 理气健脾、降逆止呕 | 胃脘胀满、恶心、食欲差 | 陈皮不宜超过5g，过量则苦燥伤阴 |
| 茯苓山药粥 | 茯苓粉15g+鲜山药50g+大米50g | 健脾渗湿 | 产后水肿、便溏、胃中水声 | 茯苓淡渗利湿不伤正 |

##### 关于番茄牛腩——可以吃

番茄牛腩在第二周是适合的，但要注意：

| 要点 | 说明 |
|------|------|
| ✅ 可以吃 | 番茄煮熟后寒性大减，与温性牛腩搭配，寒热平衡 |
| ✅ 开胃 | 番茄酸甜→开胃生津→正合"调脾胃"之需 |
| ⚠️ 番茄量不宜多 | 每次用1-2个即可，过多则偏凉→脾虚便溏者可能腹泻 |
| ⚠️ 不加辣椒 | 有些人习惯番茄牛腩加干辣椒→产后不宜→纯番茄调味即可 |
| ⚠️ 牛腩炖烂 | 炖1.5小时以上→软烂易消化→硬嚼则增加脾胃负担 |

##### 关于酸菜鱼——不建议

| 问题 | 分析 |
|------|------|
| 酸菜=腌制食品 | 腌制过程中产生亚硝酸盐+盐分极高→产后肾脏负担加重→水钠潴留→水肿加重 |
| 酸菜性味 | 酸涩收敛+咸寒→酸收则气机不畅→产后需要通（排瘀、通乳），不宜收 |
| 鱼本身没问题 | 鱼肉蛋白质好、易消化——问题不在鱼，在酸菜和调料 |
| 正常做法太辣 | 酸菜鱼标配花椒、干辣椒→辛热刺激→伤口愈合受影响+可能通过乳汁影响婴儿 |
| 高油 | 酸菜鱼浇热油→油腻→产后脾胃运化不动 |

**如果实在想吃鱼**，替代方案：

| 替代 | 做法 | 优势 |
|------|------|------|
| 番茄鱼 | 番茄2个+鱼片200g+姜片，煮汤 | 酸味来自番茄而非腌制，温和开胃 |
| 清蒸鱼 | 鲈鱼/鳜鱼+姜葱蒸8分钟+少量豉油 | 原汁原味，蛋白质优 |
| 酸汤鱼（减辣版） | 番茄2个打底+鱼片+少量白醋+不加辣椒，煮汤 | 有酸味开胃但不刺激 |

#### 脾胃调养要点

```
第二周不是"补"而是"调脾胃"——
  脾胃调好的标志：
    ✅ 有饥饿感（知饥）
    ✅ 食后不胀（能化）
    ✅ 大便成形（运化正常）
    ✅ 舌苔不厚（湿浊不重）

  脾胃未调好就进补 → 虚不受补 → 腹胀、上火、堵奶
```

#### 体质辨识食疗

产后并非千人一方，需根据体质选择：

| 体质 | 特征 | 适合食疗 | 忌 |
|------|------|----------|-----|
| 虚寒（最常见） | 怕冷、腹冷痛、恶露色暗有块、面色白、舌淡 | 当归生姜羊肉汤、红糖姜水、红枣桂圆粥 | 生冷寒凉 |
| 气虚 | 乏力、自汗、气短、子宫下坠感 | 山药排骨汤、黄芪炖鸡（少量黄芪10g起） | 过劳、久站 |
| 阴虚内热 | 口干、盗汗、恶露色鲜、手足心热、舌红 | 百合莲子粥、银耳羹、山药粥（不用姜桂） | 辛温燥热（姜、桂、羊肉） |
| 气郁 | 胸胁胀满、叹气、乳汁不通、情绪低落 | 陈皮粥、玫瑰花茶、丝瓜络煮水 | 气郁又堵奶→不宜过补 |

> 📝 **阴虚内热体质的食疗是最容易出错的**：民间习惯"产后喝姜汤、吃羊肉"，但阴虚内热者用这些→助热伤阴→口干便秘加重、恶露不止。此类产妇应当用百合、银耳、山药、莲子等清润之品。

#### 催乳食疗详述

产后缺乳是常见问题，食疗催乳需把握时机：

| 阶段 | 催乳策略 | 原因 |
|------|----------|------|

## 第十四章 产后护理误区

| 误区 | 危害 | 正确做法 |
|------|------|----------|
| 冰敷会阴 | 寒从会阴直入冲任→可能落病根 | 大黄芒硝外敷/中药坐浴 |
| 月子里不能洗头洗澡 | 不卫生→感染→头皮毛囊炎 | **可以洗，但不能随便洗——条件比时间更重要。** 详见下方 |

#### 月子洗头洗澡专题

**为什么老一辈说"不能洗"？——不是迷信，是有中医依据的：**

```
产后三重开放：腠理张开+卫气不固+冲任未闭
       ↓
洗头洗澡 → 水（湿邪）+ 风（风邪）→ 从张开腠理直入
       ↓
风寒湿邪直中经络 → 产后身痛、头痛、关节痛 → 月子病
       ↓
所以"不能洗"的本质=不能让风寒湿邪从张开的腠理进入身体
```

**但完全不洗也有害——不清洁→细菌繁殖→感染风险更高。**

正确做法：**根据产后阶段和身体状态，满足条件后洗，洗法有讲究。**

| 阶段 | 能否洗头 | 能否洗澡 | 条件 |
|------|----------|----------|------|
| 产后1-3天 | ❌ 不洗 | ❌ 不洗 | 腠理大开，最虚最易感邪。擦浴即可 |
| 产后4-7天 | 🟡 可以洗头（满足条件后） | 🟡 可以擦浴/极短淋浴 | 出汗渐止→腠理开始收敛→可谨慎洗 |
| 产后第2周 | ✅ 可以洗头 | ✅ 可以淋浴 | 卫气渐复，但仍须严格遵守洗法 |
| 产后第3周起 | ✅ 正常洗 | ✅ 正常洗 | 身体恢复较好，但仍不可受凉 |

**洗头必须满足的条件（缺一不可）：**

| 条件 | 原因 |
|------|------|
| ① 出汗已明显减少 | 出汗多=腠理仍开→湿邪易入。出汗减少=腠理渐闭→邪难入 |
| ② 室温温暖（≥25°C） | 寒冷环境→腠理因寒收紧后又因热水张开→寒热交替→最易感邪 |
| ③ 无穿堂风、门窗关闭 | 风为百病之长，湿发受风=风寒直入太阳经→头痛身痛 |
| ④ 水温热（40°C以上） | 温水不伤阳气，冷水则寒邪直入 |
| ⑤ 洗完立即擦干+热风吹干 | 湿发=湿邪停留头部→风邪乘虚而入→产后头痛 |
| ⑥ 洗完不立即出门/吹冷风 | 毛孔刚被热水打开→寒风直入→等于主动引邪 |

**洗法要诀：**

```
快：洗头5分钟内完成，不拖延
热：水温40°C以上，室温≥25°C
干：洗完立刻擦干→热风吹干→绝不让头发自然晾干
暖：洗完穿好衣服→不露肩露脚→不吹穿堂风
短：淋浴5-10分钟，不泡澡（产后宫颈未完全闭合→泡澡→上行感染）
```

**用什么水洗——药水优于清水**

产后洗头洗澡的关键不仅是"能不能洗"，还有"用什么水洗"。清水只是清洁，药水则**清洁的同时主动驱寒祛湿**——洗浴从中性操作变为治疗性操作。

| 用水 | 性味 | 功效 | 适用 | 做法 |
|------|------|------|------|------|
| 艾叶水 | 苦辛温 | 温经散寒、除湿通络 | 产后最常用的洗浴水——适合虚寒体质（怕冷、身痛） | 艾叶30-50g，加水2000ml煮沸10分钟，兑入洗澡水/洗头水中 |
| 艾叶+花椒水 | 辛温 | 温经散寒+杀虫止痒 | 怕冷明显、身痛、头皮瘙痒 | 艾叶30g+花椒15g，加水2000ml煮沸10分钟 |
| 艾叶+生姜水 | 辛温 | 温经散寒+解表祛风 | 产后身痛+怕风+头痛 | 艾叶30g+生姜5-6片，加水2000ml煮沸10分钟 |
| 清水 | — | 清洁 | 体质平和或阴虚内热者（艾叶偏温，热体不宜） | 温水即可，不加药 |

**为什么药水优于清水：**

```
清水洗浴 → 清洁，但水湿仍可能从腠理入体 → 被动防御（靠吹干速度）
药水洗浴 → 清洁+温经散寒 → 主动驱邪（药力在腠理张开时顺势进入→驱寒而非引寒）
       ↓
同样是洗，药水洗后身体暖而不凉，清水洗后可能感觉冷
       ↓
这就是民间"用艾叶水洗头不落月子病"的道理
```

**艾叶水洗头的依据**：
- 《本草纲目》载艾叶："煎汤，洗妇人冷痛，及产后受寒腹痛"
- 艾叶纯阳之性，温经散寒是其核心功效
- 产后腠理开→药力从腠理进入→温经散寒→化被动为主动

**注意**：阴虚内热者（口干舌红、恶露色鲜、手足心热）不宜用艾叶花椒水——偏温→助热。此类产妇用温水即可。

**绝对禁止：**

| 禁止 | 原因 |
|------|------|
| 产后1周内泡澡 | 宫颈未闭→水进入宫腔→感染 |
| 洗完头自然晾干或湿发入睡 | 湿邪停留→风邪乘虚→产后头痛 |
| 洗完马上吹空调冷风/穿堂风 | 腠理刚开→寒邪直入→身痛 |
| 用冷水洗 | 寒邪直中→最危险 |
| 大汗时洗 | 大汗=腠理全开→湿邪长驱直入→先擦干汗再洗 |

> 📝 **老一辈的担心是有道理的**——产后腠理张开是客观事实，风寒湿邪从腠理入络也是客观规律。"月子里不能洗"是把这个风险推到绝对，"2-3天就能洗"是把这个问题推到另一个极端。正确的态度是：**承认风险真实存在，用正确的方法规避风险，而不是无视风险。**
| 月子里不能刷牙 | 牙龈感染→牙周炎 | 软毛牙刷+温水刷牙，每日2次。产后牙龈充血，用硬毛刷+冷水→出血→不敢刷→牙菌斑堆积→感染 |
| 捂汗排毒 | 捂热→脱水→中暑→致命 | 适度保暖即可。夏季室温26-28°C为舒适范围 |
| 只喝汤不吃肉 | 营养不全面——汤里主要是脂肪和水，蛋白质在肉里 | 汤肉同食 |
| 产后立刻喝浓汤催乳 | 堵奶+乳腺炎 | 第二周起渐加 |
| 月子里吃大量鸡蛋 | 消化不良+胆固醇高 | 每天1-2个即可 |
| 束腰绑腹带恢复身材 | 压迫内脏+子宫脱垂 | 产后42天后可适度使用 |
| 月子里不能开空调 | 夏天高温→中暑→比受风更危险 | **可以开空调**。设定26-28°C，风口朝上或用挡风板，不直吹人。房间每天通风2次（产妇避开风口即可） |
| 月子里不能看手机/看书 | 伤眼？——没有科学依据 | 可以适度使用。真正伤眼的是长时间不休息→眼疲劳。建议每20分钟闭眼休息，不在暗处看屏幕 |
| 产后必须卧床不动 | 气血不行→肠蠕动减弱→便秘+血栓风险 | 顺产后6-12小时即可下床轻微活动；剖宫产术后24小时拔尿管后可下床。适度活动→气血流通→恢复更快 |

## 附录 阴虚内热经方与时方

### 一、阴虚内热的原理

```
阴（水）少了 → 阳（火）相对偏亢 → 虚热内生
```

不是"火变大了"，而是"水变少了"，同样的火就显得太旺了。

类比：满锅水+小火=温暖（正常）；半锅水+小火=过热（阴虚内热）；治法=加水（滋阴）→温度自然降下来。

虚热不能直接清热泻火——因为火本来没多，把火灭了阳气也伤了。正确做法是滋阴（加水），水回来了温度自然降下来。**但须注意**：滋阴与清热可以并行，并非绝对不可用清热药。仲景黄连阿胶汤即"育阴+清热"并用——阴虚火旺明显时（心烦不眠、舌红脉数），单纯滋阴力缓，须佐清热方能速效。关键是**不可纯清热泻火而不滋阴**，但**滋阴与清热并行**是正确治法。
