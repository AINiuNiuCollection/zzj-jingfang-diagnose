# 真假寒热鉴别规则

> 对应知识库 2.2.3 真假寒热鉴别规则（v2补强，红色拦截，必查项）。
> 依据原典第11条，杜绝阴盛格阳/阳盛格阴导致的致命性治则颠倒。

## 原典依据

**第11条（总纲）**："病人身大热，反欲得近衣者，热在皮肤，寒在骨髓也；身大寒，反不欲近衣者，寒在皮肤，热在骨髓也。"

**第317条（阴盛格阳完整证候）**："少阴病，下利清谷，里寒外热，手足厥逆，脉微欲绝，身反不恶寒，其人面色赤。"
→ 此为真寒假热（阴盛格阳）最完整的四诊组合：下利清谷+手足厥逆+脉微欲绝+面色赤+身反不恶寒。

**第366条（戴阳）**："下利脉沉而迟，其人面少赤、身有微热、下利清谷者……其面戴阳，下虚故也。"
→ 戴阳为阴盛格阳之轻证，面少赤而非满面通红，本质仍是下虚里寒。

**第350条（厥深热深）**："伤寒脉滑而厥者，里有热，白虎汤主之。"
→ 此为真热假寒（阳盛格阴）的核心原典依据：四肢厥冷+脉滑有力，白虎汤清热则厥自回。

## 鉴别要点（四维交叉验证）

### 1. 寒热表象与欲衣情况
- **身大热 + 反欲近衣** → 真寒假热（热在皮肤，寒在骨髓）
- **身大寒 + 反不欲近衣** → 真热假寒（寒在皮肤，热在骨髓）
- 寒热与欲衣一致 → 可能为真寒/真热

### 2. 口渴与饮水情况
- **真热**：口渴喜冷饮
- **真寒假热**：口渴不欲饮，或欲饮热
- **真热假寒**：口渴喜冷饮
- **瘀血口渴**（JGL-17-010）：口燥，但欲漱水不欲咽→为有瘀血，非真寒亦非真热，须别论

### 3. 脉象是否与寒热表象一致
- **真寒假热**：脉沉微、脉沉迟（虽身大热而脉无力）
- **真热假寒**：脉滑数有力、脉沉数（虽身大寒而脉有力）
- 脉象与寒热表象一致 → 支持真寒/真热

### 3.1 烦躁性质鉴别（原典条文对比）
烦躁可见于真寒亦可见于真热，须据条文细节鉴别：
- **阳虚烦躁**（SHL-61）：昼日烦躁不得眠，夜而安静，脉沉微，无表证→干姜附子汤主之。此为阳气暴虚，虚阳外越之烦躁，必伴脉沉微、无实热佐证
- **阳明热烦**（SHL-30）：厥逆、咽中干、烦躁、阳明内结、谵语烦乱→此为热结于里之烦躁，必伴谵语、腹满痛、不大便等实热佐证
- **鉴别要点**：阳虚烦躁夜而安静、脉沉微；热烦昼夜不分、脉有力、多伴谵语腹满

### 4. 小便与舌象
- **真寒**：小便清长
- **真热**：小便短赤
- **舌象参考**（分级处理，见下方说明）：
  - 🔵 **原典舌诊**（一级辅助）：舌上白苔滑→阳虚寒湿内结；舌上燥而渴/舌上干燥而烦→热结伤津；舌黄→里实热；唇痿舌青→瘀血。原典舌诊与脉象同级参考
  - 🟡 **后世舌诊**（二级辅助）：舌淡苔白滑→真寒；舌红苔黄燥→真热。后世舌诊仅作参考，不作为独立辨证依据，须标注"后世补充"

## 红色规则

**寒热真假未明时，禁止仅凭表象定寒热治则，触发智能追问至鉴别信息充足。**

**寒热真假判定须综合四诊，不可据单一指征定论**（SHL-16"观其脉证，知犯何逆，随证治之"——脉证合参互为佐证，禁止以单一症状独断寒热真假）。

## 触发条件

### 需要触发寒热鉴别的情况
1. 出现极端寒热表现：身大热、高热、身大寒、四肢厥冷
2. 寒热表现与欲衣情况矛盾
3. 脉象与寒热表象矛盾
4. 面赤而四肢厥冷（SHL-317 戴阳之象）
5. 大汗出而热不去，兼下利清谷（SHL-353/389"内寒外热"）
6. 脉微欲绝而反不恶寒（SHL-317 格阳特征）
7. 口燥但漱水不欲咽（JGL-17-010 瘀血口渴，非寒热真假但易混淆）

### 不需要触发的情况
- 普通外感（发热恶寒但非极端）
- 无寒热表现
- 寒热表现明确且脉象/渴饮一致佐证

## 追问策略

当寒热真假未明时，按优先级追问最能消歧的鉴别点：

1. **欲衣情况**（第一优先，第11条最直接的消歧信号）："患者虽发热，是否反而想多穿衣服？"
2. **脉象**（第二优先，一诊可判）："脉象是沉微无力还是滑数有力？"
3. **下利情况**（第三优先，消歧极强——有下利清谷→偏真寒，SHL-91/317/389均以下利清谷为里寒铁证）："有无腹泻？大便是否清稀完谷不化？"
4. **饮水情况**（第四优先）："口渴吗？想喝冷的还是热的？漱水不欲咽还是真想喝水？"
5. **小便情况**（辅助佐证）："小便颜色如何？清长还是短赤？"

## 鉴别结论分类

| 结论 | 含义 | 后续治则 |
|:---|:---|:---|
| 真热 | 热证，可清热 | 白虎汤类、承气汤类 |
| 真寒 | 寒证，可温阳 | 四逆汤类、理中丸类 |
| 真寒假热 | 本质是寒，表象有热（一真一假） | 温阳散寒，禁清热 |
| 真热假寒 | 本质是热，表象有寒（一真一假） | 清热泻火，禁温阳 |
| 寒热错杂 | 寒热俱真，存在于不同病位（如上热下寒） | 寒热并用，辛开苦降（如半夏泻心汤SHL-154、干姜黄芩黄连人参汤SHL-359） |
| 寒热真假未明 | 信息不足 | 追问，不定寒热治则 |

> **寒热错杂 vs 真假寒热**：真假寒热是"一真一假"，本质只有一种病性；寒热错杂是"寒热俱真"，寒与热分居不同病位。二者治则完全不同——真假寒热须祛假从真，寒热错杂须寒热并用。

## 注意事项

1. 舌诊分两级处理：
   - 🔵 **原典舌诊**（一级辅助）：仲景原文直接记载的舌象（如"舌上白苔滑""舌上燥而渴""舌黄""唇痿舌青"等，共10项，详见 `dictionary.json` 的 `tongue_classical` 字段）。与脉象同级参考，可纳入辨证主依据
   - 🟡 **后世舌诊**（二级辅助）：如"舌淡苔白滑→寒""舌红苔黄燥→热"等后世系统化舌诊理论。仅作参考，不作为独立辨证依据，须标注"后世补充"
   - 原典舌诊条目清单见 `assets/dictionary.json` → `tongue_classical`
2. 脉证合参，不做简单加权平均，亦不套用后世"舍证从脉/舍脉从证"
3. 脉证不一致时触发多假设追踪，不机械舍一
4. 寒热真假判定须综合四诊，禁止以单一指征独断——SHL-16"观其脉证，知犯何逆"为总纲
