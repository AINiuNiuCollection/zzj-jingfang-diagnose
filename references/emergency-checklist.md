# 急重症判定清单

> 对应知识库 2.2.6 急重症判定清单（v2补强）。
> 第0步"优先排查急重症"须有明确清单逐项对照，命中即优先执行急救治则。
> 所有急重症判定要点、治则均严格基于仲景原典条文，后世病机概括标注"后世概括"。

## 判定规则

1. **急下/急温/可治类**（有明确主方）：命中≥2个判定要点 → 判定为该急重症，优先执行急救治则
2. **死证/危候类**（仲景明文"死"字）：命中≥1个判定要点 → 立即红色预警，提示危候
3. **难治类**（仲景明文"难治"）：命中≥1个判定要点 → 红色预警，标注难治

命中任一急重症 → 强制高亮红色警示，不进入常规辨证流程，报告中标注急重症预警。

> **交叉引用**：真假寒热鉴别参见 `cold-heat-rules.md`，治则禁忌参见 `contraindication-rules.md`（如结胸禁下 SHL-132"下之则死"）。

## 急重症清单

### 一、急下类

#### 1. 阳明三急下证
- **判定要点**：目中不了了睛不和、发热汗多、腹满痛
- **原典依据**：SHL-252/253/254
- **急救治则**：急下之（仲景原文），后世概括"急下存阴"
- **主方**：大承气汤

#### 2. 少阴三急下证
- **判定要点**：口燥咽干、自利清水色纯青、腹胀不大便
- **原典依据**：SHL-320/321/322
- **急救治则**：急下之（仲景原文），后世概括"急下存阴"
- **主方**：大承气汤

#### 3. 下利急下证
- **判定要点**：下利按之心下坚（SHL-374）、下利脉迟而滑（SHL-374续）
- **原典依据**：SHL-374
- **急救治则**：急下之（仲景原文）
- **主方**：大承气汤

### 二、急温类

#### 4. 少阴急温证
- **判定要点**：脉沉
- **原典依据**：SHL-323
- **急救治则**：急温之（仲景原文），后世概括"回阳救逆"
- **主方**：四逆汤

#### 5. 亡阳证
- **判定要点**：恶寒脉微而复利、汗出而厥
- **原典依据**：SHL-385
- **急救治则**：急温之（仲景原文），后世概括"回阳救逆"
- **主方**：四逆汤辈

### 三、急治类

#### 6. 蛔厥
- **判定要点**：吐蛔、时烦时止、得食而呕
- **原典依据**：SHL-338
- **急救治则**：安蛔（后世概括），仲景原文"乌梅丸主之"
- **主方**：乌梅丸

#### 7. 蓄血如狂/发狂
- **判定要点**：如狂、发狂、少腹硬满、小便自利
- **原典依据**：SHL-124/125/237
- **急救治则**：破血逐瘀（后世概括），仲景原文"抵当汤主之""宜桃核承气汤"
- **主方**：抵当汤/桃核承气汤

#### 8. 结胸热实
- **判定要点**：心下痛按之石硬、脉沉紧
- **原典依据**：SHL-135
- **急救治则**：泻热逐水（后世概括），仲景原文"大陷胸汤主之"
- **主方**：大陷胸汤

#### 9. 失血危证
- **判定要点**：吐血咳逆上气脉数有热不得卧（JGL-17-006死证指征）、吐血不止（JGL-17-014）、吐血衄血（JGL-17-017）
- **原典依据**：JGL-17-006/014/017
- **急救治则**：止血（后世概括），仲景原文"柏叶汤主之""泻心汤主之"
- **主方**：柏叶汤/泻心汤
- **危候判定**：命中JGL-17-006（吐血+咳逆上气+脉数有热+不得卧）→ 死证预警

### 四、难治类

#### 10. 脏结
- **判定要点**：脏结无阳证、舌上白苔滑
- **原典依据**：SHL-129/130
- **急救治则**：标注难治，提示转诊
- **主方**：无（难治证，SHL-130"难治"）

#### 11. 下厥上竭
- **判定要点**：厥而无汗、强发汗后动血（口鼻或目出血）
- **原典依据**：SHL-294
- **急救治则**：标注难治，提示转诊
- **主方**：无（难治证，SHL-294"为难治"）

#### 12. 除中证
- **判定要点**：脉迟反能食（胃气败绝反能食）
- **原典依据**：SHL-333
- **急救治则**：标注死证，提示转诊
- **主方**：无（SHL-333"必死"）

### 五、死证预警类

> 以下条文仲景明文"死"字，命中≥1组指征即触发红色死证预警。此类为预后判定，非可救治方案，提示紧急转诊。

#### 13. 少阴死证
- **SHL-295**：恶寒、身蜷而利、手足逆冷 → 不治
- **SHL-296**：吐、利、躁烦、四逆 → 死
- **SHL-297**：下利止而头眩、时时自冒 → 死
- **SHL-298**：四逆、恶寒而身蜷、脉不至、不烦而躁 → 死
- **SHL-299**：六七日息高 → 死
- **SHL-300**：脉微细沉、但欲卧、汗出不烦、自欲吐、至五六日自利、复烦躁不得卧寐 → 死

#### 14. 厥阴死证
- **SHL-344**：发热、下利、厥逆、躁不得卧 → 死
- **SHL-345**：发热、下利至甚、厥不止 → 死
- **SHL-346**：六七日不利、便发热而利、汗出不止 → 死（有阴无阳）

#### 15. 阳明危候
- **SHL-210**：直视、谵语、喘满 → 死；或谵语、下利 → 亦死
- **SHL-211**：发汗多重发汗、亡阳谵语、脉短 → 死
- **SHL-212**：循衣摸床、惕而不安、微喘直视、脉涩 → 死（脉弦者生）

#### 16. 结胸死证
- **SHL-132**：结胸证其脉浮大、不可下 → 下之则死
- **SHL-133**：结胸证悉具、烦躁 → 亦死

#### 17. 下利脉绝危候
- **SHL-362**：下利后脉绝、手足厥冷、晬时脉不还 → 死（脉还手足温者生）
- **SHL-368**：下利手足厥冷无脉、灸之不温、脉不还反微喘 → 死
- **SHL-369**：下利日十余行、脉反实 → 死

#### 18. 吐血死证
- **JGL-17-006**：吐血、咳逆上气、脉数有热、不得卧 → 死

## 执行流程

1. 提取患者核心体征
2. 逐项对照上述清单
3. 命中判定：
   - **急下/急温/急治类**（命中≥2个判定要点）：立即执行急救治则，红色高亮警示
   - **死证/危候类**（命中≥1组指征）：红色死证预警，提示紧急转诊
   - **难治类**（命中≥1个判定要点）：红色预警，标注难治
4. 命中后不进入常规辨证流程，报告中标注急重症预警

## 报告输出格式

```
🚨 急重症预警：[急重症名称]
分类：[急下类/急温类/急治类/难治类/死证预警类]
急救治则：[治则]
建议主方：[方剂]（死证/难治类标注"无·提示转诊"）
原典依据：[条文编号]
命中要点：[命中的判定要点]

⚠️ 此为危急重症，请结合临床实际紧急处理！
```

> **用语说明**：治则中"急下之""急温之"等取自仲景原典原文；"急下存阴""回阳救逆""破血逐瘀"等为后世医家概括，仅作理解辅助。判定要点均取自原典原文。
